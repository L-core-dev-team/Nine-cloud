# @jiuxiao/world：九霄历、天文与星空（表现层）

## 范围与效力

- **只影响画面与声音，不影响规则。** 本包是纯函数、确定性计算，不导入任何规则或权威代码；`apps/api`、P1 规则路径都不得依赖它。
- **世界时间只从权威 `gameMinute` 推导，绝不反向写回**：画面 ⊆ 事实。天亮、入暮、能否看清等规则判定仍以规则常量为准，本包只负责“看起来是什么样”。
- 九霄历、标准子午线、序章地点的经纬度、月亮、星空都是**候选“兼容扩展”**，不是 Canon 1.0 原文；作者批准后才能写进 Canon 或规则。依据见 `docs/design/JX-VISION-02/final/04-天时与山河.md` §1–2，原型见同目录 `lab/astro.py`。
- 星空不使用任何真实星表（HYG 为 CC BY-SA，派生数据须同许可公开），全部按世界种子程序化生成。

## 九霄历与标准时

| 概念 | 定义 |
|---|---|
| 九霄标准时 | 以天衍城观星台子午线为准；`gameMinute` 0 = 第 0 日标准时 00:00 |
| 一日 | 1440 分钟 = 96 刻，1 刻 = 15 分钟 |
| 十二时辰 | 子 = 23:00–01:00，子初 23:00、子正 00:00；丑初 01:00、丑正 02:00；依此类推。每半时辰 4 刻 |
| 一年 | 365.2422 日；年内日序 80 为春分（太阳黄经 0°） |
| 二十四节气 | 太阳黄经每 15° 一个，自春分起：春分、清明、谷雨……秋分（180°）……惊蛰 |
| 序章历元 `PROLOGUE_EPOCH` | 第 0 日 = 年内第 263 日，开局 05:00 时黄经 ≈ 180.58°，节气为秋分；月龄 0 为占位，待作者裁定 |

`worldTimeAt(gameMinute, epoch)` 返回 `{ day, minuteOfDay, hour, minute, ke, shichen, yearDay, yearIndex, solarLongitudeDeg, solarTerm, ruleAnchor }`。

**刻的两种计法**（与 `packages/content/src/rules/prologue-v1.constants.ts` 一致，本包只读复制常量，测试逐项核对源文件）：

- 民用刻 `ke`：自标准时 00:00 起计，0–95。05:00 为第 20 刻，17:00 为第 68 刻。
- 规则镜像 `ruleAnchor.ke`：与规则相同，自 `SAVE_START_GAME_MINUTE = 300`（05:00）起计，规则日以 05:00 为界。`DUSK_START_KEC = 48` 对应 300 + 48 × 15 = 1020，即 17:00（酉初）。`ruleAnchor` 只供显示核对，权威判定仍在规则代码里。
- `gameMinute` 300 → 05:00，卯初。

## 太阳

- 黄经 λ = 2π(d − 80)/365.2422（圆轨道平黄经，不含中心差；九霄历按此定义节气）。
- 赤纬 δ = asin(sin ε · sin λ)，ε = 23.44°（精确式；原型用的 δ ≈ ε·sin λ 与它相差最多约 0.256°，出现在 λ ≈ 36° 附近，二分二至处为 0）。
- 赤经 α = atan2(cos ε · sin λ, cos λ)。
- 地方视时 = 标准时 + 经度差/15°；时角 H = 15° × (地方视时 − 12)。**第一版忽略时差方程**（真实地球全年 −14 至 +16 分钟），即把地方平时当作地方视时。
- 高度 sin h = sin φ sin δ + cos φ cos δ cos H；方位 A = atan2(−sin H, tan δ cos φ − sin φ cos H)，自正北顺时针（实现中两项同乘 cos δ 以避开奇点）。
- 日出日落：cos H₀ = (sin h₀ − sin φ sin δ)/(cos φ cos δ)，h₀ = −0.833°；赤纬取事件时刻的值迭代收敛。超出 ±1 时返回极昼或极夜。
- 地方恒星时 = 太阳时角 + 太阳赤经，月亮与星空共用它，保证三者一致。

**芦花渡（30°N，标准子午线以东 15°）在序章第 0 日**（测试锁定）：

| 量 | 计算值 |
|---|---|
| 日出 | 标准时 04:56:41（296.682 分） |
| 正午 | 标准时 11:00，高度 59.672° |
| 日落 | 标准时 17:02:52（1022.861 分） |
| 昼长 | 726.18 分钟 |
| 日出、日落方位 | 89.78°、269.99° |
| 05:00 / 17:00 的太阳高度 | −0.115° / −0.213° |

这与规则的 05:00 开局、17:00 入暮相差不到 4 分钟。这只是一个地点、一个季节的结果，不是全局规则。

**精度**：相对真实地球，忽略离心率（黄经误差 ≤ 约 1.9°）与时差方程，适合画面，不适合任何规则判定。

## 月亮（候选：九霄有一个月亮）

- 朔望月 29.530588 日；相位角 ψ = 2π · 月龄/29.530588；被照亮比例 k = (1 − cos ψ)/2。
- 月相名：朔、蛾眉月、上弦月、盈凸月、望、亏凸月、下弦月、残月（每 45° 一档）。
- 位置：月亮放在黄道上太阳以东 ψ 处（黄纬取 0），与太阳共用地方恒星时换算。
- **误差**：忽略约 5.1° 的轨道倾角（赤纬误差可达约 5°）、约 ±6.3° 的中心差（黄经误差数度）与约 1° 的地平视差；月出时刻误差可达 20–30 分钟。只用于画面。

## 程序化星空

- 随机数：FNV-1a 64 位散列（字段前置长度）→ SplitMix64 播种 → xoshiro256**，纯 TypeScript BigInt 实现，Node 与浏览器结果逐位相同；不用 `node:crypto`，禁止 `Math.random`。
- 种子 = H(worldSeed, systemName, key)，默认 `systemName = 'starfield'`、`key = 'naked-eye-v1'`；位置、星等、色温各用一个命名子流，互不扰动。
- 默认 6000 颗，星等 −1.5 至 6.5，累积数 N(<m) ∝ 10^(0.5m)（每星等约 3.16 倍）。
- 色温 3000–30000 K，T = 3000 · 10^(u²)（偏冷，中位约 5300 K）；经 Kim 等（2002）普朗克轨迹近似 → CIE xy → 线性 sRGB → 归一 → sRGB 伽马。25000 K 以上外推。
- 星座由内容作者命名，本包不提供。
