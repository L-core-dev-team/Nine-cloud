# 02 · 分版块详细分析

> 每版块含：统计表 → 专业解读 → 对《九霄》的含义。占比分母 N=8。矩阵量表为 1–5 分均值。

---

## 第一版块 · 玩家画像（Q1–Q5）

| 题 | 结果 |
| --- | --- |
| Q1 频率 | 偶尔玩 50%；每天 / 每周 / 每月 / 从没 各 12.5% |
| Q2 经验背景 | 只玩传统文字 50%；玩过 AI 文字游戏 37.5%；都没接触过 12.5%；**酒馆系 0%** |
| Q3 设备 | 仅手机 37.5%；差不多 25%；电脑为主 12.5%；手机为主 12.5%；仅电脑 12.5% |
| Q4 单次时长 | 不固定 50%；其余四档各 12.5% |
| Q5 题材（多选） | 西幻玄幻 / 历史古代 / 悬疑推理 / 看剧情质量 / 恋爱情感 各 37.5%；修仙仙侠、都市校园、武侠 各 25%；科幻末世 12.5% |

**解读**

1. **移动端是入场券，不是加分项。** 75% 的受访者可以或主要用手机游玩（仅手机＋手机为主＋差不多）。任何「先做桌面端再适配手机」的顺序在本受众中都不成立。
2. **会话结构是碎片化的。** 50% 表示时长「不固定，看心情」。这意味着单回合必须**随时可断、随时可续**，且中断不能造成状态损失——这与本项目「存档可恢复优先」的原则一致，并把「断点续玩」从可靠性要求升级为**核心体验要求**。
3. **题材号召力弱于内容质量号召力。** 「说不好，主要看剧情质量」与西幻、历史、悬疑并列最高（37.5%），修仙仅 25%。【推断】本受众把「好不好看」置于「是不是修仙」之上；题材是过滤器，不是发动机。
4. **本版块最大的结构性缺口**：没有任何酒馆系用户。这直接导致第七版块（付费与 BYOK）的数据只能代表「轻量玩家」，不能外推到核心 AI 玩家【待核】。

## 第二版块 · 想玩哪一种 AI 游戏（Q6–Q10）

| 题 | 结果 |
| --- | --- |
| Q6 泛兴趣（多选≤2） | 开放世界 / 角色扮演 / 文字 RPG 各 50%；人生模拟、传统+AI 各 25%；互动小说、经营各 12.5%；**通用平台 0%** |
| Q7 强制单选 | 开放世界 37.5%；**通用平台 25%**；人生模拟、角色扮演、文字 RPG 各 12.5%；互动小说、经营、无所谓 各 0% |
| Q8 视角 | **第一人称代入 75%**；保持距离 25%；上帝视角 0%；没想过 0% |
| Q9 世界生成 | 大致框架＋细节随生成 50%；完整固定世界观 37.5%；越随机越好 12.5%；说不清 0% |
| Q10 最不满意（多选≤3） | **崩人设 75%**；只能干聊天 50%；记不住剧情 25%；套路化 25%；基本没玩过 25%；费用/等待 12.5% |

**解读**

1. **第一人称代入是默认姿态。** 75% 选择「自己扮演主角」，上帝视角为 0。文案人称、存档字段（我的修为、我的关系）与界面语言都应按第一人称设计。
2. **「框架固定 + 细节生成」精确命中现有架构。** 50% 选择中间档，37.5% 要求完整固定，仅 12.5% 要全随机。这与「Canon 固定 + AI 只变化合规分支」的项目决策一致，也说明**无需为「随机性」加大随机**。
3. **Q6 与 Q7 的落差是本版块最有价值的数据。** 「通用平台」在泛兴趣中得 0 票，在强制单选中却拿到 25%——【推断】玩家在「自由联想」时想不起平台，但被逼着选「唯一」时，平台代表了「不会被单一题材绑死」的保险。这是**第二顺位的抽象愿望**，应写入路线图而非 1.x 承诺。
4. **痛点排序给出明确的对手定义。** 「崩人设」（75%）高于「没有玩法」（50%）高于「记不住」（25%）。前两者都是**人物与能动性**问题，而非技术性能问题。【推断】竞品差距首先在「人物可信度」，其次在「行动有后果」。

| 题 | 结果 |
| --- | --- |
| Q13 规则 vs 自由 | 偏自由 37.5%；说不清 25%；差不多 25%；偏规则 12.5% |
| Q14 自由度 vs 稳定 | **愿意 62.5%**；接受一点不稳定但大方向要稳 37.5%；不太愿意 0%；完全不愿意 0% |
| Q15 机制复杂度 | 丰富数值/搭配 62.5%；中等 25%；越简单 12.5%；硬核 0% |
| Q16 失败处理 | **有惩罚但不致命 62.5%**；很轻 25%；严格/永久死亡 12.5%；不要失败 0% |
| Q17 资源排序（平均位次，小者优先） | 玩法系统 2.75（第1名3票）；美术 3.38（3票）；剧情 3.38（1票）；世界设定 3.62（1票）；AI 智能 3.88（0票）；界面 4.00（0票） |

**解读**

1. **本版块出现全卷最反直觉的结果**：修仙品类的招牌系统（修炼突破、装备法宝、宗门经营）兴趣垫底，而叙事结构类（多结局、随机事件、动态世界）居首。【推断】玩家要的不是「养成数值」，是「我的选择在不同方向上开花」。数值系统的正当性来自它能否**制造差异化的后果**，而非深度本身。
2. **自由与稳定的取舍给出了罕见的干净数据**：无人拒绝「为自由牺牲一点稳定」，但 37.5% 划定了红线——「大方向要稳定」。这正是规则引擎的存在意义：**微观允许 AI 发挥，宏观由规则兜底**。建议把「大方向稳定」具体化为可验证承诺（人物不会无故死亡、已得物品不会消失、境界只进不退）。
3. **失败设计画像清晰**：中等惩罚 + 可重来 + 有研究空间的数值。即「允许输，不允许被抹掉」。永久死亡在此受众中是边缘偏好（12.5%）。
4. **Q17 排序揭示两件事**：① 「玩法系统」以平均位次 2.75 居首，与 Q11/Q12 一致；② 「AI 智能程度」平均位次 5/6 且零张第一名票——但 Q18、Q19、Q32 均显示对 AI 能力的高需求。【推断】玩家不把「AI 智能」当作一个可投票的功能名词，他们把它拆散成「能理解我」「记得住」「世界会动」。**对外表达应避免「AI 很聪明」这类自指卖点。**
5. **美术是分裂项**：3 人把它排第一，但平均位次仅第三。【推断】存在一个重视视觉的子群体。结合第六版块（50% 想要立绘与场景插画），美术投入应集中于「人物立绘 + 场景插画」这类直接可见处，而非全案美术升级。

## 第四版块 · AI 的角色（Q18–Q20）

| 题 | 结果 |
| --- | --- |
| Q18 AI 主要职责（多选≤2） | 生成随机任务/事件/世界变化 62.5%；**理解输入并变成行动 62.5%**；NPC 像活人 25%；写剧情对话 12.5%；少管规则 12.5% |
| Q19 聪明程度阶梯 | 理解自由输入并给合理结果 37.5%；世界自己运转 25%；说不清 12.5%；记住每个人物 12.5%；记住前后剧情 12.5%；**写出通顺故事 0%** |
| Q20 AI 主动制造意外 | 可以但别太频繁 62.5%；很喜欢 25%；不太喜欢 12.5%；完全不想要 0% |

**解读**

1. **本版块是对产品架构最直接的一次背书。** 玩家把 AI 的首要职责定义为「把我的话变成游戏行动」与「驱动世界变化」——这恰是 ActionIntent 解析与事件/世界演化两个模块。传统认知里「AI 文字游戏＝AI 会写」的假设（写剧情 12.5%、通顺故事 0%）被明确否定。
2. **期待档位集中在「理解」与「世界」两层**，而非「记忆细节」或「文笔」。注意这与第五版块的高一致性得分并不矛盾：玩家**默认**记忆应该存在（卫生因子），而把显式期待放在「它懂我」上。
3. **意外需要节流阀。** 62.5% 要求「别太频繁」，无人完全拒绝。【推断】正确形态是**低频、高铺垫、可追溯**的突发事件——例如由世界事件链触发，而非每回合随机掷骰。

## 第五版块 · 长期记忆与一致性（Q21–Q24）

**Q21 一致性在意矩阵（均值，n=8）**

| 排名 | 子项 | 均值 |
| --- | --- | --- |
| 1 | 长存档逻辑一致 | 4.50 |
| 2 | NPC 独立认知不越界 | 4.25 |
| 2 | 世界记住我做的事并反应 | 4.25 |
| 2 | 不玩时世界也在变 | 4.25 |
| 5 | NPC 能记住过去的事 | 4.12 |
| 5 | 事实不被随便改掉 | 4.12 |
| 5 | 世界事件长期影响剧情 | 4.12 |
| 8 | NPC 主动提起旧事 | 3.88 |

| 题 | 结果 |
| --- | --- |
| Q22 记忆 vs 成本 | 愿意接受一些代价 75%；非常愿意 12.5%；不愿意 12.5%；只能接受很小代价 0% |
| Q23 记性打折方式 | **会忘但不会记错 50%**；可记错误传更真实 37.5%；少 NPC 但记得清 12.5% |
| Q24 NPC 独立动机/背叛 | 很期待 50%；可以但要铺垫 50%；不太想 0%；无所谓 0% |

**解读**

1. **全卷最强的需求信号出现在这里**：八个子项均值全部落在 3.88–4.50 的窄带内，无一项低于 3.88。【推断】一致性不是「某类玩家」的需求，而是**全体基线需求**。它同时意味着：任何「为省成本牺牲一致性」的捷径都会被感知。
2. **「不玩时世界也在变」得到 4.25**，与「长存档一致」并列高位——玩家既要世界活着，又要世界不乱。这正好对应此前讨论的方案：**离线推进默认关、可开关、游戏时间设上限、离线黑名单（不发生死亡/失窃/任务失败）**。数据支持该方案的保守取向。
3. **Q23 支持遗忘/误记分期**：50% 明确选择「会忘但不会记错」，仅 37.5% 接受误记。【推断】误记的「真实感」收益小于其「AI 在耍我」的风险，1.0 只做遗忘是稳妥决策。
4. **Q24 的 100% 接受率里藏着条件**：「可以，但要有合理铺垫」占一半。【推断】NPC 背叛/利用必须是**剧情生成物**（有动机链），不能是系统随机事件。这与「模型不发明 Canon、事件有因果链」的规则一致。

## 第六版块 · 界面与操作（Q25–Q27）

| 题 | 结果 |
| --- | --- |
| Q25 界面形态（多选≤2） | **文字＋立绘＋场景插画 50%**；文字＋可折叠状态栏 37.5%；动态界面 25%；传统 RPG 界面 25%；**纯文字聊天 0%** |
| Q26 操作方式 | 打字＋按钮结合 50%；主要打字 25%；主要按钮 25% |
| Q27 配置接受度 | **能接受但要有一步步教程 62.5%**；尽量简单填一两次 12.5%；完全能接受 12.5%；完全不想配 12.5% |

**解读**

1. **「纯文字聊天界面」得票为 0。** 这是对产品差异化方向的有力确认：玩家不希望《九霄》长成一个聊天框。结合 50% 想要立绘与场景插画，现有「山门画布 + 阅读面 + 候选水墨素材」的资产方向与需求吻合。
2. **「可折叠状态栏」37.5% 说明信息要「可查」而非「常驻」**。与 Q11 中「建造洞府 / 宗门经营」兴趣偏低互证：玩家要轻量的状态感知，不要管理负担。
3. **混合输入（50%）验证零配置序章的双通道设计**：按钮与自然语言必须并存，而不是先按钮后解锁。
4. **配置接受度的真实结构是「可配置，但必须被引导」**：62.5% 的选项自带「一步步教程」前提。【推断】配置流程的失败模式不是「太复杂」，而是「没有反馈」。分步引导 + 每步可验证（连接测试）是刚需。

## 第七版块 · 付费与 AI 模型（Q28–Q31）

| 题 | 结果 |
| --- | --- |
| Q28 可接受模式（多选） | **一次性买断 75%**；免费基础＋自备 AI 50%；广告换额度 25%；平台按量 25%；自己填 API 12.5%；订阅 12.5%；都不接受 0% |
| Q29 自备模型真实想法 | 愿意弄但不想多花钱 37.5%；希望开发者直接提供 25%；了解并愿意 12.5%；不懂 12.5%；都不想 12.5% |
| Q30 费用 vs 记性 | **折中 62.5%**；说不清 25%；多花钱要好记性 12.5%；便宜但记性差 0% |
| Q31 买断价位 | **1–30 元 50%**；31–68 元 37.5%；只有免费 12.5%；69–128 元 0%；128+ 0%；不买断 0% |

**解读**

1. **买断偏好压倒性（75%），且价位锚点极低**：全部落在 68 元以内，众数区间 1–30 元，69 元以上为 0。【推断】本受众把《九霄》的心理账户归类为「买断制独立游戏」，而非「订阅制服务」。
2. **为记忆付费的意愿有限**：Q30 中 62.5% 选择折中，仅 12.5% 愿意多花钱。结合 Q22（75% 愿意接受一些代价），正确的读法是：**玩家愿意接受「慢一点、晚一点」，不愿意接受「贵很多」**。记忆系统的工程目标应是**单位一致性的成本下降**（分层检索、廉价摘要、按需升档），而非堆上下文。
3. **「希望开发者直接提供，我出钱就行」占 25%**，加上「愿意弄但不想多花钱」37.5%，构成「引导式配置 + 低成本代供」的需求基本盘。纯 BYOK 自助仅 12.5%——但必须再次强调：**本次样本酒馆用户为 0，此数字不能用于否定 BYOK 路线**【待核】。
4. **订阅制在此受众中接近失效（12.5%）**。若未来引入订阅，需绑定「平台代供 AI 额度」而非单纯解锁功能。

## 第八版块 · 未来期待（Q32–Q35）

| 题 | 结果 |
| --- | --- |
| Q32 期待方向（多选） | **更完整的 AI RPG 玩法 87.5%**；**支持玩家自制/导入/分享游戏卡 75%**；更多世界与官方剧本 37.5%；修仙做深、保持轻量、通用平台 各 25% |
| Q33 通用平台看法 | **感兴趣，但先做好《九霄》本身 50%**；很期待平台 37.5%；无所谓 12.5%；不太需要 0% |
| Q34 只保留一个 | 多世界多剧本、剧情与 AI 写作、角色养成与人物关系 各 25%；修炼战斗、纯文字轻量 各 12.5%；**长期记忆与世界一致性 0%** |
| Q35 最担心 | 见 03 号文件主题编码（收费/割韭菜 3 人次；大锅炖、AI 味、无目标感、跑路 各 1 人次） |

**解读**

1. **「更完整的 AI RPG 玩法」以 87.5% 成为全卷最高的多选题项**——高于「把修仙做深做透」（25%）三倍以上。这与第三版块「修仙系统兴趣垫底」互相印证：【推断】玩家期待的是**这套 AI 世界引擎的完成度**，而不是某个题材内容的堆量。
2. **游戏卡自制/导入/分享（75%）是第二个强信号**，但 Q33 显示 50% 的人要求「先把《九霄》本身做好」。【推断】正确序列是：**先以《九霄》验证世界引擎与格式 → 再开放卡片格式**。这与「先修仙、后抽象平台」的项目原则一致，并给出了玩家侧的佐证。
3. **Q34 揭示本卷最重要的洞察之一**：「长期记忆与世界一致性」在「只能保留一个」中得票为 0，尽管它在 Q21 中均分最高。再次确认其**卫生因子**属性：它是使能条件，不是差异化卖点。若资源冲突，一致性投入不能砍（会一票否决），但营销叙事应围绕「多结局 / 角色 / 高光时刻」展开。

## 第九版块 · 开放想象与推荐意愿（Q36–Q41）

- 推荐意愿取值 [8, 9, 5, 4, 8, 5, 7, 5]，**均值 6.4 / 10**；≥8 分 3 人（37.5%），≤5 分 4 人（50%），呈双峰。【推断】概念层面获认可，但「愿意替它背书」的比例尚不足半数——与「怕被收割」的担忧一致。
- 开放题逐条原文与主题编码见 `03-开放题原文与主题编码.md`。
- Q41 收到 3 份有效联系方式（内测候补），已脱敏处理，明细仅存于 `raw/`。
