## 二、四项设计裁决的数据支持

1. **微观自由 + 宏观稳定**：Q14 无人要求完全确定，37.5% 要求大方向稳定 → 规则引擎保留，AI 分支放开。
2. **失败 = 可恢复惩罚**：Q16 62.5% → 有代价、可重来、不抹档。
3. **1.0 只做遗忘、不做误记**：Q23 50% vs 37.5% → 遗忘可接受、误记有争议，分期正确。
4. **离线推进保守化**：Q21「不玩时世界也在变」4.25 与「长存档一致」4.50 并存 → 默认关 + 可开关 + 游戏时间上限 + 离线黑名单。

## 四、给两位作者的三个讨论题

1. **修仙系统的定位**：数据指向「修仙数值系统服务叙事多样性」。是否同意把「修炼/装备/宗门」从「核心循环」降级为「叙事后果的载体」？（影响 S3 规则表的设计重心）
2. **营销主线**：一致性不做卖点，改以「多结局 / 人物 / 峰值时刻」为主叙事。是否同意？
3. **平台化时点**：Q32 有 75% 想要游戏卡自制/导入，但 Q33 有 50% 要求先做好本体。是否把「卡片格式」列为 2.0 的第一项，而 1.x 仅做格式预留（不做承诺）？
