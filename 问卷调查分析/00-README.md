## 方法说明

1. 单选/多选题统计频次与占比（占比分母为 N=8）。
2. 矩阵量表题计算各子项均值（1–5 分）并排序。
3. 排序题计算平均位次（数值越小优先级越高）与第 1 名票数。
4. 量表题（0–10）报告取值分布与均值。
5. 开放题逐条保留原文，再做主题编码（见 03 号文件）。
6. 以 Q2「经验背景」为分组变量做交叉分析（A 酒馆自配 / B 酒馆现成卡 / C 玩过 AI 文字游戏 / D 只玩传统文字 / E 都没接触过）。

## 局限与阅读须知（重要）

1. **样本量极小（N=8）**。所有百分比波动极大（1 份即 12.5 个百分点），本报告结论只能作为**方向性信号**，不能作为统计推断。
2. **便利样本**。受访者以发起人的朋友、同学为主，非目标玩家总体的概率抽样。
3. **关键人群覆盖缺失**：8 人中 **A（酒馆自配模型）与 B（酒馆用现成卡）均为 0 人**。这意味着本次数据**完全无法回答**「核心 AI 玩家（SillyTavern / RisuAI 用户）怎么看 BYOK、记忆成本、上下文管理」这类问题——而这恰是产品最需要验证的人群。
4. **修仙题材偏好偏弱**：本样本中仅 25% 选择修仙仙侠题材，低于西幻玄幻 / 历史古代 / 悬疑推理 / 恋爱情感（各 37.5%）。样本对题材的代表性有限。
5. **量表标签错配**：矩阵量表题两端标签被平台默认渲染为「绝不可能 / 极有可能」，与题目说明（1 分＝完全没兴趣）语义不一致，可能轻微影响打分口径。该缺陷已在创建时记录，属已知偏差。
6. **隐私**：Q41（联系方式，选填）收到 3 份有效联系方式。**本文件夹所有分析文档均已脱敏**，原始联系方式仅存在于 `raw/answers-28047242.json`。该文件含个人信息，建议按「私密」层级保管，不得进入任何公开仓库或发行包。
