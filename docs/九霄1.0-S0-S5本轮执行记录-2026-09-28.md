## 本轮实际完成

### S5：本地场景与画质切片

- 新增固定场景清单 `packages/content/src/scenes/manifest.ts`。场景 ID 限定为山门、野外、宗门/城镇、战斗/异变；位置只通过精确别名映射，模型或存档文本不能提供任意资源地址。
- 新增 `/settings/graphics`。用户可预览四个场景 ID，并设置自适应、电影光影、极致、高清、均衡、省电、标清档，30/60/90/120 FPS 目标、渲染比例、动态分辨率、氛围雾、粒子、省电和减少动态效果。
- 新增全站 `SceneAtmosphere` 局部 WebGL 2/WebGL 渲染。WebGL 初始化、着色器、缓冲区分配失败或运行中丢失上下文时切换到独立 Canvas 2D；两种画布都不可用时保留原页面静态背景。启动时验证必需缓冲区、属性和 uniform；失败时不把未初始化的上下文报告为 WebGL。GPU 粒子采用独立 `POINTS` pass，避免在每个屏幕像素上重复遍历粒子。粒子 pass 会改写 WebGL 上下文级的顶点属性绑定，因此每次全屏绘制前显式恢复底图缓冲区；浏览器回归逐次确认底图 draw 仍绑定底图数据。用户关闭雾、水光和粒子后，渲染器只绘制最后一帧并停止 `requestAnimationFrame` 循环；再次开启会恢复。画布按画质档设置总像素预算；2D 后备把比例限制在 80%、粒子限制在 24 个，避免 GPU 故障后仍沿用极致档负载。浏览器帧间隔采样显示为采样值，不冒充 GPU 计时。
- 修正自动画质的设备估计：未知显存不再按高性能设备处理。修正减少动态效果和页面隐藏/恢复时的动画循环停启；重复调节设置会取消旧循环，避免叠加渲染。
- 增加点击后启用的本地合成流水氛围声和音量控制。界面明确说明它是合成声，不是经作者审核的瀑布实录。刷新页面不会偷偷自动播放。
- E2E 已验证桌面和移动模拟视口均实际编译为 WebGL 2，并观测到粒子独立点绘制调用；还分别注入 WebGL 上下文丢失、着色器编译失败、WebGL 禁用和 Canvas 禁用，确认按层级退到 Canvas 2D 或静态背景。极致档故障注入确认 Canvas 2D 画布比例不会超过 80%；像素预算纯函数另有单测。画质/FPS 设置持久化、省电锁定 30 FPS；系统与应用级减少动态效果都会停止动态层采样，应用级偏好跨路由生效。雾水开关会隐藏对应装饰层，粒子开关和省电模式会关闭花瓣效果；省电模式会冻结全站 CSS 动画与过渡，包括山门按钮光效。关闭最后一类氛围效果后绘制循环停止，恢复后重新启动，场景预览不会泄漏到其他路由。

这仍不是四个正式游戏场景。当前仅山门拥有既有审核图；野外、宗门/城镇、战斗/异变只有固定身份和程序化氛围参数，页面仍映射共用山门底图。缺少三类正式海报、移动裁切、场景局部动画、作者选定环境声与资产权利记录。档位影响的是本地氛围层负载，不能据此宣称游戏级实时光追、WebGI、神经渲染、AI 超分或持续 120 FPS。

3. Bird 逐条核对 Canon、地点、物品与人物引用，并在同一规则摘要上签复核。两位作者记录规则版本和 SHA。
4. 工程依已签表实现纯规则 reducer，再由游客端与 API 共用；补重复幂等键、非法状态、回放相等、失败不部分写入和 100 回合长局测试。规则未签时保持 `RULES_NOT_READY`。

### C. S4：Canon 双人来源门禁与记忆接入

1. Bird 在私有环境冻结原图批次，交付每图 ID、SHA-256、OCR、冲突和校对记录；原图与密钥不上传公开仓库。
2. 按现有“先搁置 182 条 OCR”决定继续留作备忘。收到原图后，再由 Bird 与 LYL 对照图像逐条核验，分清 OCR、肉眼复核、编辑补全和 Canon 裁定；这些证据不得合并成一句“全部审核”。
3. 两人对每条拟发布内容的同一 SHA-256 摘要在发布器支持的回执格式分别批准。`confirmed` 或 `author_delegated_adjudication` 状态不能替代双人回执。无图、哈希不符、摘要变化的条目必须拒绝发布。
4. 工程从批准回执生成仅含 approved 条目的运行包，并加入内容版本 pin、游戏内来源说明与检索来源过滤测试；未批准的 34 条候选不进入玩家端。
5. NPC 记忆只消费已批准规则结算产生、且观察权限允许的 DomainEvent；日志持久化和回合事务原子提交后，再验证重复事件、断线恢复、两种记忆隔离和叙事重试。

### D. S5：正式美术、音频、设备与安全边界

1. LYL/Bird 为山门、野外、宗门/城镇、战斗/异变分别提交桌面海报、手机裁切、循环运动方案、环境声与资产来源/授权说明；只保留固定 manifest ID。现有山门图复用须核实适用范围和授权。
2. 每个场景明确允许的地点/时间/事件映射与静态失败海报，内容作者签收后工程再接入。不得让模型返回文件路径、URL 或 HTML。
3. 作者选定的水声/环境声需本机试听并记录采样率、响度、循环点、授权、音量上限和静音操作；合成噪声不能代替实录验收。
4. 完成可玩回合链后，再在目标手机、平板、集显笔记本和桌面 GPU 上连玩至少五分钟；记录机型、浏览器、分辨率、设置、每秒帧率分位数、温度/功耗观察、资源失败回退与输入流畅性。模拟视口不算真机证据。
5. 媒体生成需要玩家确认的成本/等待/取消 UI、任务幂等和资源删除记录；扩展必须在受限隔离源中运行并实测拒绝读 Key、同源存储、外联和写入 DomainEvent。当前这些模块尚未实现。

### E. S6 后端账号与云同步的启动条件

当前 S6 尚无认证/存档业务路由。开始写入可登录 UI 前，LYL 需确定邮件发件域、验证码服务商、隐私文本与数据删除口径；B/工程需确定部署环境、密钥保管、备份/恢复责任和日志保留策略。具体实施顺序：

1. 先确认游客/登录可同步的数据类型、冲突三选项、本地分支策略、注销及删除后备份的保留时限。
2. 将真实 OTP 服务替换成本地 Mailpit 测试；验证码哈希入库、尝试和发送限速、重放拒绝、过期失效均要有集成测试。
3. 认证中间件解析出受信任 actor ID 后，才开放逐对象鉴权的存档 API；请求必须含 `expectedRevision`，冲突返回而非覆盖。
4. 用两个用户账号验证互读/修改均拒绝；断网队列、冲突分支、导出、删除、指定版本恢复分别做端到端证据。
5. 生产密钥只放目标部署的 secret store。不得为“继续进度”临时开放无身份存档 API。

Docker 服务链本地复验不依赖 Docker MCP；当前 Codex 会话未暴露 Docker MCP 工具。若后续必须在 MCP 中管理容器，需要在桌面应用配置一个可用 Docker MCP 服务后，再单独实测工具调用。不能以 Compose 成功推断 MCP 已就绪。
