# 《九霄》1.0 S1 工程基线

> 2026-09-23。本文描述当前代码能做什么及如何复核。S1 是工作区和共享契约，不是公测产品，也不代替 G1 的两作者验收。

## 交付边界

`apps/web` 是 React/TypeScript/Vite 的工程预览页，只显示“山门尚未开启”和契约版本。没有建角、世界、存档、模型、付费等虚假按钮。旧单 HTML 留在 `outputs/` 供玩家继续本地试玩和迁移比对。`apps/api` 只有 Hono `/health` 与统一 404；没有对外开放存档或认证接口。`packages/db` 有 PostgreSQL 表定义与生成迁移，但当前 API 未连接数据库。`packages/domain` 对全部候选行动返回 `RULES_NOT_READY`；作者未签规则表前不会提交事件。

共享 `packages/contracts` 用 Zod 校验 `ActionIntent`、三态 `Decision`、`DomainEvent`、`SaveEnvelope`、世界最小状态和错误码。`schemaVersion`、Canon、规则、记忆策略与修订号分开记录。候选行动的载荷是接口草案；S3 必须用作者签署的玩法表审查其种类与字段。S1 不能从这些类型推断任何已经可玩的内容。

## 全新克隆复核

前提：Node 24、pnpm 11.19、Git。运行：

```powershell
pnpm install --frozen-lockfile --registry https://registry.npmjs.org
pnpm license:check
pnpm typecheck
pnpm test
pnpm build
pnpm test:integration
pnpm test:e2e
```

浏览器端 `pnpm dev:web`，API 端 `pnpm dev:api`。打开 `http://127.0.0.1:5173` 与 `http://127.0.0.1:8787/health`。`test:e2e` 在 390×844 和 1366×768 检查工程预览与 HTTP 健康端点；Windows 优先使用本机 Edge，CI 使用已安装的 Playwright Chromium。`pnpm build` 生成 Web、API 和迁移 schema 产物的同一 Git SHA 清单。构建产物在 `dist/`，不提交仓库。

`pnpm` 11 默认阻断依赖安装脚本。`pnpm-workspace.yaml` 只允许 esbuild 运行必要的二进制安装脚本；新增有构建脚本的依赖需单独审查。许可证检查当前只接受 MIT、Apache-2.0、BSD-3-Clause、ISC、MPL-2.0；这是自动筛查，不代替发行时的署名与法律审查。

## 本地容器

复制 `.env.example` 为本机 `.env`，自行填入 `POSTGRES_PASSWORD`。`docker compose up --build` 预期启动 PostgreSQL、测试邮件服务和 API；数据库映射到本机 5433，邮件页面 8025，API 8787。容器中的 `DATABASE_URL` 由 Compose 生成。API 当前不依赖数据库，因此 `/health` 只证明进程可用，不证明数据库查询或迁移成功。迁移由 `pnpm --filter @jiuxiao/db db:generate` 生成，已有初始 SQL；实际执行需运行数据库后再做 `db:migrate`。生产环境的凭证、备份和高可用不由本地 Compose 代表。

本机验证时 Docker CLI 存在，`docker compose config --quiet` 通过；Docker Desktop Linux daemon 未运行，因此**容器启动、数据库连接和 SQL 执行未实测**。[GitHub CI 首次运行](https://github.com/L-core-dev-team/Nine-cloud/actions/runs/35863425763)在提交 `efb7e24` 上通过；CI 不含数据库容器集成测试。不能把配置解析或 CI 通过当作数据库验收。

## S1 验证记录与后续门禁

| 检查 | 当前记录 | 局限 |
| --- | --- | --- |
| `pnpm install` | 固定依赖与锁文件安装完成 | 只测本机与当前镜像源 |
| `pnpm typecheck` | 五个工作区项目通过 | 不证明运行时规则 |
| `pnpm test` | 旧原型 28 核心 + 54 AI 回归；新契约/域/API 单测 | 旧回归含合成与内嵌材料，不代替真机 |
| `pnpm build` | Web、API、schema 可构建 | 发布流水线与部署尚未演练 |
| `pnpm test:integration` | `/health` 与未开放路由检查通过 | 无数据库或账号测试 |
| `pnpm test:e2e` | 手机/桌面工程预览与 API 通过 | 无真实玩家任务 |
| `pnpm license:check` | 当前 80 个条目属于五类已列许可证 | 发行署名仍待检查 |
| Docker Compose | 配置解析通过 | daemon 未运行，服务未启动 |
| GitHub CI | `efb7e24` 的 `verify` job 通过 | 不含数据库容器与玩家流程验收 |

G1 前半仍需作者 B 在全新克隆与 CI 复核，并由作者 A 确认预览中没有对玩家误导的入口。S2 才迁入首页、建角、世界、游戏和 AI 设置；S0 的旧功能对照表是逐项验收清单。旧版 `build_v1.py` 与 `build_worldbook_ui.py` 继续保留，不再是新版构建入口。
