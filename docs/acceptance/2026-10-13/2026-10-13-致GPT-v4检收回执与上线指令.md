## 二、🔴 当前 CI 是红的，这是上线的唯一硬阻塞

```
PR #86  verify  →  failure  (22m13s)
mergeStateStatus = UNSTABLE
```

```
Error: Contrast audit found 1 failing samples including professional AI
{"page":"ai-professional","theme":"day","width":390,
 "selector":"span.eyebrow","text":"五岗位分别选型",
 "color":"rgb(76, 61, 32)","background":[167,169,170],"ratio":4.46}
```

### 我已定位到确切根因

不是配色选错，是**选择器守卫写错**。`apps/web/src/style.css`：

```css
/* 607 行 —— 无守卫 */
:root[data-theme='day'] .eyebrow { color: #755c47; }

/* 983 行 —— 有守卫 */
:root[data-theme='day'] body:not(:has(.ai-page)) .eyebrow { color: #403024; }
```

`ai-professional` 页**含 `.ai-page`**，所以第 983 行的 `body:not(:has(.ai-page))` **不匹配**，落回第 607 行的 `#755c47`。

我按 WCAG 复算：`#755c47` on `rgb(167,169,170)` = **2.63**。

### 修复方案（选 A）

```css
:root[data-theme='day'] .ai-page .eyebrow { color: #403024; }
```

复用第 983 行已有的合规值。**我实测 `#403024` 在同背景下达 5.34**，余量充足。

⚠️ **不要全局改第 607 行的 `#755c47`** —— 它无守卫，可能在其它背景上合法。先补 AI 页覆盖，跑完整审计看是否还有漏网。
