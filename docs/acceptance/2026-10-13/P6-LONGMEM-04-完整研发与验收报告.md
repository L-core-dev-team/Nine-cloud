## 原文与原子提交

保存端把未经裁剪、换行转换或摘要的原始 UTF-8 正文作为 BLOB；正文 SHA256 与包含全部身份/模拟快照的 canonical JSON 摘要用于完整性核验。读取使用严格 UTF-8 解码并保留正文开头 BOM。长中文、CRLF、空白和 emoji 测试按 Buffer 逐字节比较。

scope 是 owner/save/branch 的摘要；同 scope/source 唯一、同 scope/idempotency 唯一。BEGIN IMMEDIATE 下校验既有来源和请求后写入整行，正文、revision、生成版本、快照与幂等身份在同一 SQLite 事务提交。相同结果 duplicate，不新增；任意正文/来源差异明确冲突；已有记录损坏则拒绝加载和重提覆盖。SQL UPDATE/DELETE 触发器辅助防覆盖，但本地文件管理员可删除触发器或改写文件，摘要也不是签名。

测试钩子仅用于注入 after-begin/after-insert/before-commit/after-commit 中断。提交前终止无可读结果；提交后应答丢失保留结果，按同键重试 duplicate。真实子进程硬杀不会执行应用清理 finally。并发竞争只有一个新结果，其他要么同结果 duplicate，要么明确冲突；锁超时后可重新打开/重试，不以覆盖原文解决竞争。

数据库初次建表与初始化不是生产 migration；未知已有 schema 明确拒绝，不改写其版本。尚未实现在线版本迁移、生产备份工具、跨主机事务、通用事件 outbox 或多叙事版本发布模型。

## 磁盘闭环与权限

原文、来源 Source 元数据、整条来源 ACL 快照和合成实体 registry 均存盘。写入进程退出后，新读取进程不加载历史正文 fixture，只从数据库恢复并核对整个 Source 对象的 canonical 根摘要。单独读取冻结查询计划不会恢复剧情正文。

DiskRecall 固定 owner/save/branch 和 revision。每个 audience/as-of 视图在索引构建前移除未来/未授权来源；占位回合只有空内容，不带隐藏 sourceId 或正文。后继未知时移除失效时间与替代来源，NPC ACL 输出只保留当前 NPC。原文入口再次查磁盘 SHA/身份及同样的权限和范围，不能通过直接 sourceId 绕过检索过滤。

合成 registry 的 maxTurn 预先声明，来源每个回合至多一条；这不是生产未知长度游戏或同回合多生成版本的完整模型。未来正式接入必须区别规则回执和叙事 attempt/publication，并使用真实身份认证、P4/P5 与逐段授权。

旧原文 corpus 有 7 个 world-event 标签缺少 confirmedBy/规则事件绑定。保存端保留原始标签，检索事实视图排除这些标签的权威资格，正文仍可作为原文证据；不补造事件、不改旧数据、不把叙事提升为世界事实。三种规模各出现同样 7 个标签，审计合计 21，不是 21 个独立语料缺陷。已确认复杂语料没有此类标签，因此此修正不改变已完成复杂组的事实准入。

## 规模与真值

1000 回合两类语料原样复用。复杂组来自十地交错剧情，含物品多次转手、同名/别名、更名、谣言澄清、关系变更、约定兑现、交织伏笔、NPC 差异知情；原文组含衣着、声音、气味、动作、对白及授权负例。

3000/10000 回合以 `floor((旧回合-1)*(新总回合-1)/999)+1` 单调伸展原千回合节点，同步变换 query、事实有效期、别名建立时间、范围和游戏时钟，保留原始 sourceId、全文、事实值及关系链接。空缺增加有独立批次和事件的巡检来源，实体独立，不与旧角色/物品混并。

旧题已解封，本轮均为公开兼容测试；不是新的独立盲测。原千回合是固定结构的合成剧情，扩展回合也是数值/场景模板，不是 10000 个同等语义复杂的新剧情。正文每组只约 1.7–1.8 MiB，因此不能外推到每回合数千字的真实大型存档。未来仍需未知问题、多样长正文和真实逐段权限语料。
