## 预览玩法与运行规则

- 正式发布构建仍执行媒体授权门禁；`JIUXIAO_RELEASE_CHANNEL=preview-1` 单独启用已获准的本地玩法、双记忆、摘要和离线演化界面。稳定发布默认边界不变。
- 云端运行使用既有已签首段内容及规则，不编造额外修为、突破或 NPC 数值。只读 `rules.mjs` 由宿主安装；预览批准文件同时绑定文件 SHA-256、原签语义 SHA-256、版本和有效期。缺失、篡改、过期仍拒绝加载。
- 原 P1 审阅插件默认加载路径在 production 下仍关闭。本次预览走独立批准的宿主加载器，不修改原批准摘要或旧签署记录。
- 没有服务端付费模型凭据时，云端首段使用已有规则事件对应的确定性叙事；玩家自己的模型配置仍只保存在本机。

## 邮箱登录

本次使用现有 Hono 邮箱验证码服务和腾讯云 SES API，模板 62795（真实只读接口已核对通过，变量 code）。修复 TC3 签名的换行规范、SignedHeaders 字段和 Region 请求头。不会同时启用原生邮箱认证与 Supabase Auth 两个凭据提供方。保留数据库中的账号、owner 和身份历史；手机号和短信额度继续关闭。

Pages 中继显式启用邮箱路由。三个自有域名仅在请求 Origin 与当前网站完全一致时转为 API 的统一批准 Origin；任意外部 Origin 不会被改写为可信来源，仍由 API 拒绝。

## 数据政策

依本次双作者直接授权，预览沿用既有拟定配额：每账号 20 份云存档、单份 1 MiB、合计 10 MiB，回收站 30 天。政策版本 `preview-1-data-20261014.v1`，有效至 2026-12-31。当前实际主机备份任务保留 14 天、目录 700 / 文件 600；没有将旧拟定的 90 天冷备写成现状。永久账号删除继续关闭。

网页隐私说明已按实际部署修正：境内 API 使用境外 Supabase 托管业务数据库，邮箱验证码经腾讯云发送；不再把未核验的提供方合同或日志关闭写成既成事实。私有配置仅在 ignored 的 deployment/api.private.env、deployment/runtime 和服务器对应目录中。
