## 时间意图与原文检索改动

旧 `/现在|当前|截至/` 会在「出现在哪里」的「现/在」间匹配。新 `intent.ts` 使用中文词法分段，并先消费出/体/表/呈/重/再等动词的「现+在」结构；覆盖出现、体现、表现、呈现、重现、再现和引号内「现在」等表达。历史、当前和普通查询分开判断；显式回合和游戏时间范围继续使用既有参数过滤，不从任意自然语言日期擅自推算游戏回合。

类型化事实检索通过包装原 HardenedIndex 复用，没有修改旧引擎。包装屏蔽旧子串时间开关，在确有当前时间意图时显式启用；有结构化支持时保留原事实状态与历史链，不将谣言改成确认事实。

无结构化支持的原文查询使用另一条离线路径：先按时点、整条来源 NPC 授权、显式实体约束过滤，再结合原句二元字面片段及外貌、气味、声音、动作、对话、环境属性词汇评分。人物、地点与物品约束共同生效；同名无唯一身份拒绝猜测。正文可没有 facts，也可有与查询无关的结构化事实。

原句保留引号和标点，返回 sourceId、回合、UTF-16 起止偏移、原文全文 SHA256、证据类型和 authority。原文标为 `original-prose-only`，说法标为 `unverified`；新原文路径不生成事实标签或答案。结构化路径保留原 fact IDs 和状态。`original()` 恢复入口按相同时点与权限重新读取模拟来源。

整句超预算时保留遗漏来源 ID，不截断或改写正文。最多八条来源、每条最多三句，是有限候选策略，不是任意问题的完整证明。最新叙事描述只证明该段原文内容，不自动证明世界当前状态。

## 来源相关性、成本与耗时

新留出四预算的必要来源召回 91.43%、来源准确率 96.97%、无关原文片段字节 / 整个上下文字节约 1.08%，平均历史上下文估算 Token 为 32.22，最大 98。新开发来源准确率 94.59%、该字节冗余比例约 1.96%，不能把满分称为零冗余。旧 60 题来源准确率 88.61%、平均估算 Token 122.87，保持 P6-02 行为。

新原文片段很短，四档预算均不形成约束，因此质量和成本相同；本轮没有据此证明 512 足以覆盖长篇真实剧情。额外边界测试使用超长原句验证 512 遗漏、1024 可容纳的真实预算行为。

2048 档旧引擎新留出平均估算 Token 26.86，新引擎 32.22：新引擎返回更多有效原文，并非全指标都减少成本。旧引擎必要来源召回为零，低成本不能视为完成任务。

Token 仅 `ceil(UTF-8 bytes/2)` 估算，不是真实 tokenizer、已证明上界或 API 账单，不含系统提示、查询、输出。延迟为本机单进程顺序样本，有 JIT/GC 波动，不是生产 SLO；索引构建时间在每个 run 单列。结果保存了所有引擎、题集和预算的来源准确率、冗余、漏检、成本与耗时，不能用这里的局部表替代原始结果。

## 六个真实留出失败

四预算均为候选阶段漏检，不是预算压缩丢失。没有借失败改答案或继续调参。
