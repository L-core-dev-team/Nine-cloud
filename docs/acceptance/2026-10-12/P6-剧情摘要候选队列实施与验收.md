# P6 剧情摘要候选队列实施与验收（2026-10-12）

## 结论

在 `codex/gameplay-dual-memory-loop-20261011` 上补齐了本机 DEV-only 的 P6 摘要重建队列，并将其接入候选玩法页。验收代码提交为 `fbfd248c20552bf7aafac453e6b4f467b444db07`，父提交为 `060e0a47072fff1c4880c2c91f0cb39be3c070e8`。

这关闭的是**本机候选队列工程缺口**，不代表 P6 阶段签收、生产集成、Mem0/UwU 适配完成或摘要质量通过产品评测。

## 实施范围

- 只从已接受的玩家可见规则回执建立摘要来源；不读未提交自由文本、NPC 私有记忆或完整事件负载。
- 任务 ID 固定绑定存档、记忆模式、策略哈希、修订区间、来源内容哈希、生成器版本和 prompt 版本；重复请求幂等。
- IndexedDB 队列按 Continue / Forgetting 分库，只保存来源 ID、修订范围与哈希，不保存输入原文。运行时从最新权威候选档案重读来源，并核对原输入哈希。
- 队列支持租约、过期租约恢复、最多 3 次失败重试、错误码脱敏、每次运行的工作量/并发限制和生成前费用报价检查。费用额度默认为 0；候选页只启用成本为 0 的本机抽取式适配器。
- 摘要产物固定为 `approvalStatus=pending`。未经审核不会进入叙事上下文。剧情摘要来源标记为玩家可见，不会成为 NPC 授权记忆或事实来源。
- 候选页显示摘要草稿、修订区间、来源数及待审状态；可恢复尚未完成的持久化任务。

## 未关闭事项

- 没有真实 Mem0-compatible / UwU-style adapter 的安装、数据隔离和对照评测；没有预注册的 held-out 记忆质量集或人工盲评。因此不能比较其事实召回、错误归属、摘要遗漏、延迟、Token、存储或维护成本。
- 费用上限由每次 queue run 的 quote 与额度控制，默认额度为 0；没有接入外部计费服务，也没有实现跨多次运行的持久化日预算账本。外部收费适配器仍未接线，不能把本候选队列描述成生产费用结算系统。
- 摘要草稿还没有作者审核/拒绝工作流，也没有进入正式 PlotChronicle 存储或生产 NarrativeContext。
- 新的本机候选代码仍受 DEV-only 门保护；没有部署、合并 `main` 或完成 P6 双作者阶段签收。
- 生产主机 `/api/auth/guest` Pages 代理问题仍按 2026-10-11 公网复核记录保持开放，本次没有重新部署或改变线上服务。
