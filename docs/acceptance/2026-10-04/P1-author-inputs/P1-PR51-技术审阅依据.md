## 3. 需 Bird 判断的三点（我无法代替）

### ① NLU-11 `utterance` 内否定 —— ✅ **已验证，不是缺陷**

`action-parser.ts:129-132` 有专门守卫，注释即为此写：

```ts
// A direct quote addressed to an NPC is speech content, not an instruction
// to the game. Negation inside that quote must not suppress the talk action.
const containsSpeech = matches.some(match => match.template.kind === 'talk');
if (!containsSpeech && (NEGATION_OR_CONDITION.test(text) || UNRESOLVED_REFERENCE.test(text))) {
```

「对岑九说：不要去望气台」会先匹配到 `talk` 模板 → `containsSpeech=true` → **跳过**否定/指代拒绝 → 判「完整 talk」。**行为与盲标表 NLU-11 的期望一致。**

**额外发现（`:277`）**：模板自身的 `prefix` 也不允许以否定/指代词开头，否则 `P1_NLU_TEMPLATE_INVALID`。这防止有人注册一个「不要去…」模板来绕过拒绝——防御到位。

**残留风险（低）**：守卫依赖「先成功匹配 talk 模板」。若某句同时可能匹配 `talk` 与其他动作，`containsSpeech` 仍为 true，否定检查被跳过。需确认模板集下不存在这种歧义句。**建议加一条回归测试。**
