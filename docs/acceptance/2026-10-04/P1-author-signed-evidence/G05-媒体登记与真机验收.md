## 3. 真机验收（媒体齐备后进行）

**设备要求**：至少 iPhone Safari 一台 + 目标 Android 一台。**桌面 Chrome 模拟视口不能替代。**

### 3.1 记录表

| 字段 | 说明 |
| --- | --- |
| 设备型号 / 系统 / 浏览器版本 | 必填 |
| 网络条件 | WiFi / 4G，标实测速率 |
| 电源状态 |  plugged / 电池 |
| 画质档 | 极致 / 高清 / 均衡 / 省电 / 标清 |
| 冷启动到首屏可交互 | 目标 ≤3 秒 |
| 连续运行时长 | ≥15 分钟 |
| 帧时间 / 内存峰值 | 实测 |
| 温升 / 耗电趋势 | 趋势即可，**不可测项写「不可测」** |
| 横竖屏切换 | 不崩溃、不重载 |
| 断网 / 媒体 404 | 必须回落静态海报 |
| 省流量 / 减少动态 | 生效且任务可完成 |

### 3.2 判定线

| 项 | 判定 |
| --- | --- |
| 冷启动 | ≤3 秒（真机） |
| 连玩 | ≥15 分钟不崩溃、不卡死、不丢档 |
| 媒体失败 | 100% 回落静态，**不黑屏** |
| 降级 | 省流量 / 减少动态开启后首个任务仍可完成 |
| 发热 | 记录趋势；明显烫手需记为问题项 |

### 3.3 铁律

**桌面模拟视口的数据一律不得填入本表。** 这是 G-05 最常见的拖延点——用模拟数据签了字，事后一核就作废，整轮返工。
