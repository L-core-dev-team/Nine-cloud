## 四、复算方式

在仓库根目录运行（Python 3.10+）：

```powershell
python docs/acceptance/2026-10-04/P1-author-signed-evidence/tools/hash_artifacts.py `
  --repo-root . `
  --output-dir $env:TEMP\jiuxiao-digests `
  --source-media-root "D:\九霄 WEB\九霄素材-水墨古风"
```

输出目录必须显式指定；脚本默认不覆盖已有结果，除非加 `--force`。没有源素材目录时可加 `--skip-media`，但这只复算 Canon 和仓库中可见的派生素材，不能声称重算了全部 148 项。

## 五、建议的使用顺序

1. **等待外部主体的事项**：G-06 运营主体书面审批；G-05 权利来源和许可范围证据的核验。SHA-256 复算不能替代这两项。
2. **可并行的技术验收**：G-08 来源与价格逐条核验；G-09 用真实 Key 的人工探针（Key 只从环境变量读取，探针输出不得包含密钥、提示词或模型正文）。
3. **规则与记忆**：G-03 数值已由已签规格记录；G-04b 分类归属仍按签署记录核验。PR #45 的 reducer 是合成实现，未接入生产 API，也不等于 G1 运行验收。
4. **G-04a 不重签**：保留现有作者回执，修正发布器对已签回执的校验/制品绑定；门禁通过前维持 `receiptsComplete=false`。
5. **最后做 G-02**：固定同一候选 SHA、部署和 CI 后，由 LYL、Bird 分别走查并留证。
