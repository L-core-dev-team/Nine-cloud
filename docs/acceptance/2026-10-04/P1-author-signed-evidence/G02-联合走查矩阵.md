## 4. 独立性要求

| 规则 | 说明 |
| --- | --- |
| 两人**分别**走 | 不可同时进行、不可互相看结果 |
| 各自记录 | 浏览器、视口、动作、结果、证据文件 |
| 结论只有三种 | 通过 / 阻断 / **有依据的正式淘汰** |
| 「页面存在一个按钮」 | **不算通过** |
| 不同机器或不同时间 | 避免环境偶然性 |
