# JX-UI-E-01 · 读屏与真机核对清单

**用途：** 本会话运行在 Linux 容器里，没有屏幕阅读器，也没有实体手机，所以下面这些项目**都没有做过**。清单给出可以照做的步骤和按代码推出的预期结果，由有设备的人逐项填写“结果”栏。

**预期从哪里来：** 名称、角色和顺序都取自当前代码里的可访问名称（`aria-label`、标题层级、`role`）。如果实测与预期不同，以实测为准并登记缺陷。

**建议组合：**

| 读屏 / 设备 | 浏览器 | 为什么 |
|---|---|---|
| NVDA 2025+（Windows 11） | Firefox、Chrome | 国内桌面用户最常见的组合 |
| VoiceOver（macOS 15） | Safari | 竖排、`writing-mode` 和 `<dialog>` 的读法与 Chromium 不同 |
| VoiceOver（iOS 18，iPhone 13 及以上） | Safari | 安全区、软键盘、`100dvh` |
| TalkBack（Android 14） | Chrome | 低端机的模糊与透明效果性能 |

## 三、真机

| # | 设备 / 设置 | 操作 | 预期 | 结果 |
|---|---|---|---|---|
| 21 | iPhone Safari，竖屏 | 进入单人会话，点输入栏 | 软键盘弹出后输入栏仍可见，正文不被顶栏遮挡 | |
| 22 | iPhone Safari，横屏（844×390 级别） | 同上 | 顶栏为 48px 紧凑态，输入栏不出视口 | |
| 23 | iPhone 刘海 / 灵动岛 | 首页与底部导航 | 内容不进安全区；底部导航不被手势条遮住 | |
| 24 | Android 中低端机 | 首页、大厅来回切换，进入书阁 | 场景压暗与模糊的过渡不卡顿（主观判断即可，附机型） | |
| 25 | Android | 人物志与成卷（竖排）的横向滚动 | 竖排手卷可以手指横向拖动；不会误触返回手势 | |
| 26 | Windows 高对比度（强制颜色） | 首页、人物志题签、成卷朱批 | 文字可读；题签保留边框；朱批不丢失 | |
| 27 | 系统“减少动态效果” | 首页、入卷、落印、成卷 | 浑天环不描画；正文不展开；不落印、直接进入；成卷不淡入 | |
| 28 | 系统“降低透明度” | 首页、大厅、卡库 | 玻璃面变为不透明底色，文字对比不下降 | |
| 29 | 浏览器字号 200% | 人物志、世界书工作台、成卷 | 不出现横向滚动；按钮文字不被截断 | |
| 30 | 首次访问、未缓存 | 首页 | 记录 LCP；字体切片按需下载，题字在字体到达前不应闪成别的字形太久 | |
