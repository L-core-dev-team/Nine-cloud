# JX-UI-E-01 · 读屏与真机核对清单

**用途：** 本会话运行在 Linux 容器里，没有屏幕阅读器，也没有实体手机，所以下面这些项目**都没有做过**。新设计已于 2026-11-24 部署到正式站 <https://play.jiuxiaogame.cn/>，可以直接在真实设备上照做。每一项都写了网址、操作和按代码推出的预期，结果栏留给测试的人填写。

**预期从哪里来：** 名称、角色和顺序都取自当前代码里的可访问名称（`aria-label`、标题层级、`role`）。如果实测与预期不同，以实测为准并登记缺陷。

**正式站能测什么：** 原生《九霄》的首页、大厅、本机 1.0 预览玩法（不登录即可新开一局）、世界设定、存档管理、画面设置、账号与云档、AI 设置都能测。**角色卡模式在正式站没有开放**，下面标“本机”的项目需要在开发环境里用 `pnpm dev:cards` 测（合成模型，不连真实 AI）；“成卷”还要开构建开关 `VITE_JX_NOVEL_MODE=1`。

**测试前：** 用无痕／隐私窗口打开，或先清掉站点数据，这样“没有存档”的初始状态和预期一致。正式站会把存档写进这台设备的浏览器，测试数据只留在本机。

## 零、怎样打开读屏

| 读屏 / 设备 | 开关 | 最常用的几个手势或按键 |
|---|---|---|
| **NVDA**（Windows 10/11，免费，<https://www.nvaccess.org/download/>）配 Chrome 或 Firefox | 安装后 `Ctrl + Alt + N` 启动；`Insert + Q` 退出 | `H` 下一个标题，`1`/`2`/`3` 按级别跳标题；`D` 下一个地标；`B` 下一个按钮；`Tab` 下一个可聚焦控件；`Insert + 空格` 在“浏览模式”与“焦点模式”间切换；`Insert + F7` 列出所有链接、标题和地标 |
| **VoiceOver**（macOS）配 Safari | `Cmd + F5`（或连按三下 Touch ID） | `VO` = `Ctrl + Option`。`VO + →` 读下一项；`VO + U` 打开转子，左右切换“标题／地标／表单控件”；`VO + 空格` 激活 |
| **VoiceOver**（iPhone）配 Safari | 设置 → 辅助功能 → 旁白；建议先在“辅助功能快捷键”里设成连按三下侧边键开关 | 单指左右轻扫逐项读；双击激活；两指转动打开转子，选“标题”后上下轻扫跳标题；两指上滑从头读 |
| **TalkBack**（Android）配 Chrome | 设置 → 无障碍 → TalkBack；或同时长按两个音量键 3 秒 | 单指左右轻扫逐项读；双击激活；三指轻扫或“上滑再右滑”打开阅读控件，切到“标题” |

不熟悉读屏时，先在首页练一分钟“逐项读”和“按标题跳”，再开始填表。
