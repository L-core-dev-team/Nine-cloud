## 数据、来源与独立答案

基础数据连续 200 回合，每回合都有来源 ID、游戏时间/分钟、人物、地点、物品、原文、事件 ID、事实与历史链接。25 个关键场景覆盖初遇与远期重逢、约定及兑现、伏笔及揭晓、身份伪装、相似人名、物品多次转交、关系变化、事实失效、秘密、感官细节、矛盾说法与虚构事件负例。日常回合没有规则事件时保留空事件/事实数组。

## 检索与预算方案

近期基线按时间倒序选取来源；历史方案使用预计算中文双字特征、实体别名、通用意图与动作约束，并在多阶段问题中追溯历史链接。两者共享时点、权限过滤、证据格式和预算打包，最终对照取消额外条数上限。Recall@8 是排名指标，不限制返回来源数。初轮诊断的 8 条上限已记录，不与最终结果混为同一实验。

NPC 来源先过滤再排序；沿链接追溯时再次过滤，不允许借元数据链接取得未授权原文。玩家档案不受 NPC 权限过滤影响。这里模拟的是整条来源授权，未调用或重写 P4/P5 算法。正式 grant、遗忘曲线、分页修订和分支继承未在本轮验收。

最终复核进一步封住元数据泄漏：未经授权的后继来源不能使 NPC 得知事实何时失效，也不能通过替代事实 ID 或历史来源 ID 暴露隐秘交接。NPC 的 `current` 指最新获准知识，而非保证世界最新状态。没有事实标签的叙事原文可按明确实体与文字匹配返回，保持事实数组为空；不把感官描述升级成权威事实。补充对抗历史中有两位同名苏禾，缺少唯一别名或实体 ID 时拒绝猜测；同标签的四次交接按事件 ID 与查询时点分别复验。

只打包完整原始来源，不截断不确定性标签，不生成剧情答案。与问题直接相关的确认事实有优先权，历史变化和关键伏笔通过来源链接保留。预算不足会列出遗漏来源并声明证据不足；目前的保守判断会因额外候选未装下而误拒答，这也是失败。

预算 512/1024/2048/4096 仅计 `context` 历史证据字段，包括来源头、原文和事实状态。诊断 JSON 的候选/证据数组存在重复表示，不能整体送模型后仍声称在此预算内。

**全部 Token 值是估算：`ceil(UTF-8 历史证据字节数 / 2)`。没有目标 tokenizer，没有真实 API Token 或付费模型使用，不是经过证明的上界。** 本轮不能据此保证真实模型预算和账单，也不统计系统提示词、当前输入或输出。

## 失败与原因

复核新增边界测试修复前为 1 PASS / 2 FAIL，原始失败见 `review-boundaries-before.log`：检索器跳过没有事实标签的原文；NPC 从未授权交接的失效日期推知后续变化。保留断言修复实验实现后，加上同名人物对抗测试，完整实验为 22/22 PASS。原始证据与答案未重写。新测试日志由 PowerShell 原样捕获，可能使用 UTF-16LE；JSON 与 Markdown 是 UTF-8，字节清单保留实际编码。

首轮历史 4096 为 52 PASS / 8 FAIL，涉及 Q02/Q19/Q25/Q36/Q43/Q45 的词面漏检，以及 Q50/Q52 的权限边界误答。前者由自然文本与元数据谓词匹配不足造成；后者虽未泄露被禁止来源，却错误把允许读取的购买/托管来源当作后续转交或购买知情证据。已修正谓词前缀、实体与动作约束，原始记录仍在 `initial-evaluation.json`。

最终低预算失败：

- 512：Q10 缺 s010，早期铜铃刻痕未装入伏笔链；Q18 缺 s120，遗漏玉佩中间持有人；Q23 缺 s200，遗漏关系恢复；Q42 缺 s025，遗漏最初伪装说法。这 4 项没有被短摘要或猜测替代。
- 512：Q20/Q34/Q49 必需来源已齐，但额外候选被预算截掉，保守 `enoughEvidence=false`，均计 FAIL。
- 1024：Q20/Q23/Q49 同样因过宽候选与保守判定误拒答，计 3 FAIL。历史时序本身正确不能覆盖拒答缺陷。
- 2048/4096：60 题没有上述完整性失败，但相关性冗余仍未解决。后续应改进意图收窄与分阶段证据完整性判定，须保留本答案集并增加独立表达变体/隐藏测试，不能靠调整答案提高分数。

## 500/1000 扩展实测

已实际生成两档历史并执行全部四预算、两策略、60 题，连同 200 档共 1440 次查询。答案时点保持原标注，扩大语料不允许穿越历史时点，因此主评测质量与 200 档一致。

另外执行了 48 次末回合压力探针：每档、每预算、每策略各 3 题，分别追溯初遇赠物、四段归属链、三段伏笔链。500 和 1000 档的历史 512 均为 1 PASS / 2 FAIL，1024/2048/4096 均为 3 PASS / 0 FAIL；近期基线各档均为 0 PASS / 3 FAIL。完整探针来源、遗漏、耗时和预算占用见 `evaluation.json.stress`。

扩展只增加日常干扰记录，核心复杂事实仍是 25 个场景，不能外推到千回合复杂真实剧情、未标注原文抽取或实体数量持续增长的表现。没有真实 LLM、生产旅程或数据库压力测试。

最终三档机器结果在 `review/evaluation.json`。历史策略的索引创建耗时范围分别为 200 回合 1.67–2.25 ms、500 回合 4.33–5.05 ms、1000 回合 8.55–14.74 ms；1000 回合查询 p95 为 0.114–0.285 ms。本次新增原文无事实标签用例只验证带明确实体和关键词的检索，不能外推为任意叙事自动抽取。

## 后续正式接口建议与停止点

- P3：只读提供稳定原文来源 ID、回合、时钟、分支、规则事件/回执关联与原文完整性；不以叙事文字生成权威世界事实。
- P4：提供指定 NPC、存档、分支、修订时点的冻结授权读取及分页接口；生产适配不能依赖本实验的整条来源授权列表。
- P5：提供指定时点的可召回结果及策略版本，不删除玩家原始剧情档案；本轮没有模拟真实衰减参数，也没有改生产算法。
- 正式 P6：另行评审原文抽取、来源不确定性、时间限定事实及适配器边界；选定目标 tokenizer 后重新跑预算，并增加真实或经授权脱敏历史与隐藏问题。

本轮无需合作者介入才能运行独立实验。正式集成才需要以上接口确认与新的授权。主线、S 冻结成果和其他工作位均保持原状；仅推送独立分支交审，完成后停止主动施工。
