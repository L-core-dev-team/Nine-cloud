## 检索与预算处理

复用第一阶段数据接口和不可更改的 `assess` PASS 口径，第一阶段 `HistoryIndex` 原样作为基线。强化实现先过滤查询时间与模拟来源授权，再匹配稳定实体和事实谓词；人物共现不再直接等同相关证据。来源审计区分直接证据、必要背景、弱关联和无关内容。长期伏笔沿授权历史链接补齐原始片段，关系变更支持明确的相邻阶段。未知行动、同名歧义或未来别名拒绝猜测。

上下文保留完整原文句子与 UTF-16 偏移、sourceId、turnId、事实值、类别、当前/历史/未证实状态；完整来源留在 ranked 原始结果。压缩的是重复元数据和不相关句子，不改写原文或创建摘要事实。原文偏移专项测试通过；不等于已证明给模型的语义完全无损。

NPC 的 current 表示最新获准知识；世界已有但 NPC 未知的后继不会借失效时间、替代事实 ID 或来源链接泄漏。所有过滤仍是独立模拟，不修改 P4/P5。授权单位为整条来源；原叙事可能带有“某 NPC 不知道某交接”的作者说明，本轮来源 ID 泄漏指标不能证明这种段内语义说明完全安全。

Token 均为 **ESTIMATE：ceil(UTF-8 历史证据字节数/2)**，无目标 tokenizer，非真实 API Token，亦非已证明上界。不含系统提示词、玩家问题和输出。基线/近期策略打包整条来源，强化检索摘取完整句子，两者使用同一字节估算，但上下文格式不同，改善同时来自筛选及打包，不能全归因于排序。

## 原始失败与根因

原 60 题 512 档：Q10、Q18、Q23、Q42 分别缺 s010、s120、s200、s025，均为原整条来源预算不足；强化摘句后所需来源齐全。Q20、Q34、Q49 已有全部必要证据，却因额外弱关联候选没有进入预算而被拒绝；强化先收窄支持谓词，三题不再误判。1024 档的同三项误判也消除。逐题前后结果保留原始选中来源、遗漏、事实与上下文。

复杂开发 512 档原版漏掉 20 道完整归属/关系链，涉及 40 个必要来源；强化四档均找回。冻结版原模型在交织伏笔上不认识倒装的“揭晓…交织伏笔”链意图；强化支持“交织”链并返回两个早期印记和揭晓来源。冻结身份问题的低预算缺证据/过度谨慎也得到改善。

**最终未解决：F0-prose～F9-prose，四档各 10 个 FAIL。** 例如 F0-prose 问“栖潮埠潮印封签原文的温杉气味出现在哪里？”，正确来源 s141。检索器将“出现在哪里”中的连续字符“现在”误匹配为当前状态意图，随后当前事实筛选要求有活动事实，纯原文来源没有事实标签，被排除。原文存在且词匹配成立，失败发生在语义筛选，不是预算或权限不足。来源缺失后系统返回证据不足，没有猜测气味；但事实保护目标仍未达成。

该发现来自最终留出集，已原样交付，源码停留在终测前提交。下一轮如修复，必须引入新的未知评测题，不能重复使用这一组宣称盲测。更一般的未标注原文召回、自然语言意图边界与人工支持分类仍待验证。

原 60 题仍有 9 个额外返回来源（涉及 Q08、Q13、Q31～Q34），主要是刻痕含义与刻痕、身份说法与确认事实的过宽谓词匹配。它们影响精度但没有改变标准答案。无关来源、未授权秘密、未来状态、不能支撑问题的共现文本均不应放入后续模型上下文。
