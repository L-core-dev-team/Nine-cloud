## G-03 / G-04b：作者正式规则与记忆语义

负责人：LYL 提供六类规则的条件、费用、状态变化、失败/边界/反例、九境五域映射和版本；两作者签同一规则摘要。工程不替作者填写数值。

LYL 已于 2026-10-03 更正九境次序为“炼体→炼气→筑基→结丹→元婴→化神→合体→大乘→渡劫”。同日验收更正版及派生显示已更正；Bird 须复核旧来源覆盖与“化神前尝试合体”的拒绝反例。尚缺的规则值和正式版本仍按本节签收。

部署负责人依 `deployment/README.md` 安装只读本地规则模块并配置 TURN_RULES_MODULE。模块提供 ActionRuleProvider/version、initialState、事件观测授权和 NPC 策略；不是浏览器或 AI 传来的代码。

配置 TURN_RULES_MODULE 本身不代表作者批准。当前 `AUTHOR_RULES_GATE` 仍为 `BLOCKED_BY_OWNER` 且规则版本为空，API 启动时不会导入该模块，合法 `POST /api/turns` 请求在读取存档前返回 `503 RULES_NOT_READY`。只有门禁开放并且模块版本与签署版本完全相同时，运行时才可加载规则。

操作：打开批准的游戏网址 `/turns` → 登录 → 创建权威新局 → 选择六类行动并提交 → 核对回执、变化、拒绝/澄清 → 主动生成叙事 → 取消/重试 → 刷新或关页恢复。Pass：结果符合签署规则，重复/叙事重试不再扣费或推进，NPC 只获得授权观察且不影响别的存档。Fail：规则未加载仍结算、费用或结果与签署表不同、AI 改写状态。记录规则摘要、候选身份、样例和两人结论到唯一清单 G-03/G-04b。

## G-05：媒体权利与实际手机

素材预览批准不等于发布许可。权利方给四场景最终图/动态素材/声音的授权凭证、用途和文件 SHA-256；缺项继续 procedural/poster/静态降级，不能伪造剩余视频或环境声。

操作：在同候选固定四场景依次切换，启用/关闭声音、换横竖屏、低画质/省电，断网及媒体失败后检查静态降级。使用自己的 iPhone Safari 和目标设备，填写 `DeviceTestRecord.json` 中型号/系统/浏览器/质量/省电、帧时、可测内存、温度、耗电、网络、时长、恢复证据；不可测项标不可测，不用桌面视口数据替代。Pass：权利与指纹匹配，两作者接受真实观感/稳定性，失败能恢复。Fail：未授权媒体发布、黑屏、无恢复或伪造性能。填唯一清单 G-05。

## G-06 / EXT-01：真实生产资源和数据政策

目前未提供已部署的公开 HTTPS API Base URL，状态 `PUBLIC_API_BASE_URL_PENDING`。正式客户端不能使用 localhost。本任务只交付 Auth API，Pages 部署由另一任务负责。

负责人提供：公网 HTTPS 后端/访问权、PostgreSQL、发件域与 SMTP 凭据、私有 AUTH_SECRET、准确前端 Origin、批准数据政策和冷备处理。密钥只设服务端私有环境，不发聊天或 Git。政策须包含版本/期限、双方真实批准、快照配额、软删保留、冷备清除依据；缺失/到期禁止生产写入和相关破坏性操作。

操作顺序见 `deployment/README.md`：固定镜像 → 迁移 → SMTP 不发信预检 → HTTPS smoke → 本人邮箱验证码实际到达 → 登录/Session → 账号 A/B 云档拒绝互读 → CAS/离线恢复 → 邮箱旧/新双验证 → 导出 → 关闭/经批准的永久删除 → 隔离库恢复/镜像回滚。正式前端由 Pages 任务配置真实公开 API URL 与跨域 include，配精确 Origin、Secure cookie；手机隐私限制下需实际验会话。

Pass：真实邮件到达、同一部署 SHA/Schema/policy 可追溯，账号隔离和恢复成立，在线删除及冷备策略分别有证据。Fail：SMTP 接受冒充收件箱到达、默认 localhost、政策只填一个版本名、软删除冒充永久擦除。外部冷备/法律保留/运营主体与事故联系人由责任方落实。填唯一清单 G-06/EXT-01，保存脱敏部署记录。

候选中的回收站过期清理只处理本地未受信档，且须经到期判断和数据库删除回执。运行前先用 `scripts/api-retention.mjs` 的预览模式查看数量，再在已批准政策和备份流程下执行有限批次；核对删除数、保留中的正式游戏档与回滚证据。新增迁移和断言须在同一候选 CI/隔离库通过后，才可记工程复验完成。
