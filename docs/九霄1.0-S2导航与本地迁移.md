**状态：S2 局部工程切片可复现；G1 未签收，不能称 S2 完成**
**复审分支：`codex/jiuxiao-s0-s2-audit`**
**更新日期：2026-09-24**

## 1. 阶段目标

S2 只处理玩家从首页到游戏入口的连续路径。它不提前伪造 S3 的规则结算，也不把未审核资料发布为世界书。

本阶段交付四件可复现的事情：

1. 山门首屏以“九霄”为主，只提供“进入世界”；进入后在 `/lobby` 选择“新开一局”、续档、世界设定或 AI 设置。
2. 建角页承载旧原型中的十个字段，并保存未完成草稿。
3. 新建角色后生成版本化本地存档，刷新页面后仍可继续进入同一局。
4. 菜单提供原文备份、旧档导入和 JSON 导出，失败时不改写已有存档。

## 3. 导航契约

| 路径 | 唯一职责 | 当前行为 |
| --- | --- | --- |
| `/` | 山门入口 | 突出“九霄”，左上角为短句；点击“进入世界”才进入任务选择 |
| `/lobby` | 选择去处 | 有档时显示继续游玩；另可新开一局、阅读世界设定或打开 AI 设置 |
| `/new` | 完成建角 | 显示十个原型字段；草稿写入浏览器本地；最多三项天赋 |
| `/world` | 阅读审核状态 | 明确显示 Canon 尚未发布，不展示待核 OCR |
| `/game/:id` | 查看本地局 | 显示角色、地域、回合和待规则状态；提供世界设定与导出入口 |
| `/settings/ai` | 配置 AI 候选值 | 恢复“青鱼推荐配置”名称和五岗位列表；不谎称连接测试已完成 |

入口分为两步：山门视觉页负责进入；山门内的任务页负责续档、开局和查阅设置。品牌短句和“九霄”不再重复。晴昼/夜色偏好存于本机浏览器，不进入存档。新用书法字样采用 Ma Shan Zheng 网页子集，并随源附带 OFL 许可文件。沉浸按钮使用双层描边和冷月色光晕；这属于 CSS 界面反馈，不宣称实现华为原生光效。

## 4. 本地迁移行为

### 4.1 导入前备份

用户选择 `.json`、`.txt` 或 `.html` 文件后，浏览器先下载一份原文备份，命名为 `九霄-导入前原文备份-时间戳.txt`。备份发生在解析之前。解析失败时，现有 `localStorage` 存档不改写。

### 4.2 当前可识别格式

- 本项目导出的 `{ format: "JIUXIAO_SAVE", version: 1, save: ... }` JSON；对象必须含可识别旧档字段。
- S0 记录的原型 JSON：支持 `id`、`name`、`turn`、`world.location`、`player`、`messages` 等常见字段映射。
- 纯文本或 HTML：去除脚本、样式和标签后保留为一条历史消息，角色字段使用文件名和默认地域。浏览器拒绝超过 32 MiB 的文件。该路径只保证原文保留，不宣称恢复旧版本全部语义。

### 4.3 明确未完成项

本阶段保留 `localStorage` 作为兼容来源，并将当前局镜像到 IndexedDB；检测到旧 `jiuxiao_v1_library` 时，用户点击按钮后先下载原文备份，再通过校验迁移，旧键不会删除。JSON 导入会在预览中列出全部顶层字段；真实私档样本已在隔离 E2E 中验证字节备份和 payload 深度相等。仍未完成迁移中断恢复、跨标签冲突选择、云端 `expectedRevision` 和完整多局管理。

AI 设置实现了三种候选档、五岗位启用状态、Model ID、Base URL、页面内存 API Key、Temperature、TopP、最大 tokens、超时、显式连接测试许可、调用记录保留天数、旧配置迁移许可、档案周期和上下文消息数。推荐档只填候选，不带入密钥。设置通过 E2E 检查，但真实服务商连接、真实 Model ID/权限和费用未验证；当前仅实现 OpenAI Chat Completions 兼容协议，不能据此宣称所有服务商可用。旧版功能均按 LYL 的确认保留于产品范围，但游戏规则、世界资料检索、剧情读层往返等能力仍待分阶段实现。

同理，导入后的状态统一标为 `pending_rules`。它不会直接写入权威世界事实，也不会触发模型调用。

## 6. 阶段门禁

S2 的工程证据已经形成，但 G1 仍不能标记为公开通过。原因是：

1. 真实样本只覆盖 LYL 提供的一个 JSON 导出，旧档边界与丢失恢复矩阵仍不完整。
2. 多存档列表、跨标签竞争和迁移中断恢复仍待实现；实有用户功能需按对照表持续迁移。
3. `/world` 当前仍是未发布 Canon 的说明页，世界搜索、来源引用和游戏内阅读层尚未实现。
4. AI 已有本地设置界面，但真实 Model ID 校验、用户授权后的真实 API 测试与各服务商兼容仍需单独验收。
5. 本次未启动 Docker 服务；当前 Windows 报告 WSL 未安装，数据库/API 集成不能计为实测。

因此本次更新修复了 S2 已发现的数据预览与任务层级问题，但仍不能关闭 G1。LYL 已确认功能保留方向；剩余代码项由 B 按路线完成。Bird 提供 OCR 原图后才启动内容审核；真机任务在可玩切片稳定后执行，不将其伪装成当前通过。
