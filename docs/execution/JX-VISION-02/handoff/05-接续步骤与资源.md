```bash
TEST_DATABASE_URL=postgresql://postgres:postgres@127.0.0.1:5432/jiuxiao_test pnpm test:integration
```

## 6. Teleport（可选）

依据官方文档 <https://code.claude.com/docs/en/claude-code-on-the-web>（“Move tasks between terminal and cloud”）。

- **命令**：在本地仓库目录里运行 `claude --teleport`，从列表里选这次会话；或者运行 `claude --teleport <session-id>`。
  - 在云端会话里输入 `/teleport`，会直接打印带 ID 的命令。
  - 本会话的地址是 `https://claude.ai/code/session_01UT1aoYGEtYtLan2nHHEUfE`。
- **前提**：
  - 本地是同一仓库的检出，不能是 fork；
  - 工作区干净；
  - 会话分支已推送；
  - 本地 CLI 用同一个 claude.ai 账号登录（`claude auth login`），API key 方式不行。
- **限制**：
  - 已被自动压缩的早期对话不会带过来，只带摘要；
  - 迁移是单向的；
  - 原生 Windows 上是否可用，文档没有明说，需要实测。
- **分支**：会话登记的分支是 `claude/pensive-ritchie-kef9p0`，已经合并完毕。Teleport 之后**必须** `git switch claude/jx-exec-r1`。
- **结论**：Teleport 只是锦上添花。本交接包的设计前提是**不依赖**它。
