## 还不能替作者或合作者宣布通过的关口

- 用户本人对原图、历史补充的停用处理及剧情草案的最终审阅与产品签字。这是人类决定；逐图 OCR、目视核对与自动测试都不能伪装为逐字签收。
- 合作者把 `retrieveCanon` 与 `buildCanonPromptContext` 接入真实回合，并证明旧档版本、规则事件、两种记忆和 NPC 知情隔离。当前作者分支没有改这些代码。
- 四类场景的真实资产、来源许可、手机裁切、声音和弱动效／加载失败回退，以及长线九境五域路径和真机连续游玩。
- PR 审查、合并与完整 CI。PR 可合并不等于已入游戏，更不等于公测封版。

内容包自检命令为 `node scripts/build-canon-runtime.mjs`、`node scripts/test-worldbook-final.mjs`，作者侧私有核查另用 `node scripts/test-worldbook-review.mjs <private-review-dir>`。对原设新增或更正，须写入来源、决策和版本记录后再生成运行包，不能直接改生成的 JSON。
