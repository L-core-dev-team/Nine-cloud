# 《九霄》世界书 Canon 1.0：作者侧交付

本分支仅提交世界书数据包、构建脚本与审核记录。游戏页面、场景、AI 请求和存档逻辑由合作者的开发分支继续维护；本分支未改动这些文件。

## 内容与来源

- 182 个旧编号已逐条核对去向：179 张原图及配对转写，另 3 条按用户原先指定排除。
- 179 张原图均对应正式条目的来源引用；原001是章节目录，放在 `documentOutlineSourceRefs`，其余正文页附于相应条目。
- 正式版有 33 个条目：世界概述 1、地域 6、势力 16、体系 10。原060—061 的无标题正文单列为“修仙基础”，不猜原图标题。
- 原图哈希、逐图独立 OCR 比对、旧编号去向及残缺片段保存在作者侧私有审核资料中；玩家运行版不带这些内部字段。仓库中的来源登记仅保留来源 ID、类型和审核方法。
- 已按用户授权裁定原088 的阶数笔误、圣火教别名、原120→118及原173→174跨图衔接；修复原165→164正文被来源标记截断的问题，并按已有作者裁定保全原051、原052、补005的天工阁匠师等级细节。裁定记录在 `canon.registry.json` 的 `decisions` 中。

## 审核边界

182 个旧编号均已有裁定去向。179 张原图和 28 张补图逐张经过**从图片重新运行的独立 Windows OCR**，再与已有逐图转写交叉核对；独立 OCR 四字片段覆盖率低于 85% 的 18 张原图、3 张补图均已直接查看，未发现新的实质性转写矛盾。补004为无关开发截图，仍排除于世界书；补026因 OCR 识字异常也直接查看。私有 `image-by-image-review-20260925.json` 逐张记载方法和素材哈希，旧 182 条各有独立去向。23 张原图此前已有定点视觉复查记录。

这构成作者委托的**逐图独立 OCR 交叉核对与差异复核**，不能表述为作者本人把 179 张全部逐字目视签收。`reviewSummary.imageByImageIndependentOcrCrosscheckComplete` 为 `true`；`reviewSummary.imageByImageVisualVerificationComplete` 仍为 `false`。合作者审查时不应再报告“182 条全未审核”，也不应报告“全部原图人工目视终审完成”。

原图截断、无法辨认的部分不编成硬设定。正式内容中的省略号表示缺口，不为缺失文字赋予设定效力；54 处无法恢复的片段留在私有审核资料。只有标题而缺可靠正文的“经济体系”不作为正式条目发布，“经济与物价参考”有独立正文，正常保留。

## 供合作者接入

- 正式、无内部来源资料的运行数据：`packages/content/src/canon-runtime.json`。
- 带版本、来源引用、裁定与真实审核状态的作者侧登记：`packages/content/src/canon.registry.json`。
- 查询、按场景选取、形成 AI 只读上下文：`packages/content/src/index.ts`。
- 运行数据由 `node scripts/build-canon-runtime.mjs` 从登记生成；`node scripts/test-worldbook-final.mjs` 检查条目来源、179 张图的去向、逐图 OCR 审核状态、运行版隔离和关键正文。

接入游戏时请调用 `retrieveCanon` 选取相关条目，再通过 `buildCanonPromptContext` 提供给 AI；不要将作者侧登记中的来源和审核字段塞入剧情提示词，也不要让 AI 的回合输出回写正式 Canon。本分支未自行改动合作者的游戏接入代码。
