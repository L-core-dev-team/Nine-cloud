## 存储与执行边界

非密钥配置由 `safeConfig` 保存到当前来源的 sessionStorage `jx10_ai_config_v2`；读取时 `readConfig` 校验并限制数字范围。旧配置只在用户开启迁移并主动点击后由 `migrateLegacy` 载入表单，不删除旧配置、不自动调用。API Key 仅保留页面内存，不写入新配置、存档或日志。以下“生效”仅指设置页短连接测试，不表示游戏回合调度已接入。

## 本轮解析修复

- 忽略 Gemini `thought=true` 以及带明确非文本类型的内容块；Responses 只读取 message 输出项（兼容端点省略 type 时保留旧行为）。仅含思考内容时不再通过正文非空判定。
- 兼容端点即使返回 HTTP 200，只要含非空 error 字段就拒绝作为成功回复；不显示原始错误内容。
- token 统计只接受非负安全整数；缺失、负数、小数、字符串、无限值和溢出值保持未知，服务商明确报告的 0 保留。
- 不修改游戏规则、Canon、角色或存档，也不开放新的游戏 AI 调度。

验证：Web 11 个测试文件、96 项测试通过，Web TypeScript 检查和 Vite 构建通过；现有 `tests/e2e/foundation.cjs` 在 390px/1366px 通过。新增案例覆盖四协议错误封套、八类非法 token、明确零用量、思考与正式文本分离。其余历史自动化证据须查看对应提交的 CI，不以本记录代签。
