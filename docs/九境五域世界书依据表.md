# 九境五域：世界书依据表

本表是作者侧从 Canon 1.0 抽出的**原设约束**，供合作者制定玩法规则时核对；不直接充当行动结算表。具体移动距离、修炼耗时、成功概率、等级数值和跨域通行条件，原图没有给出，不能由本表冒充原设。

原稿明确将**合体期排在化神期之前**，且以元婴后期突破合体、合体后期突破化神。不得用其他修仙作品的常见顺序替换。结丹期页顶被裁断，旧转写额外补出的“气态灵力压缩为液态灵力”没有图像依据；正式版以原078可辨的“液态→固态”突破过程为准，裁定见 `canon.registry.json`。

## 给规则与剧情的边界

- Canon 可以约束境界先后、已记载的突破条件及地域归属；AI 叙述不能自行更改这些事实。
- 原图仅给出描述性风险时，规则引擎不得把它当作已确定的百分比、消耗量或必然结局。
- 角色是否成功突破、跨域移动及其状态后果，应由合作者的权威规则与事件结算；世界书只提供设定依据。
- “凡阶”在不同原稿中有不同口径：资源品级段将其置于黄阶之下，功法品阶段将凡、黄、玄、地、天并列。两者分属不同分类，未获新证据前不强行统一为一套通用等级。
