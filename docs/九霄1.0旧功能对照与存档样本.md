## 可复现的入口故障

```powershell
node scripts/audit/legacy-navigation.cjs 'D:\九霄_WEB_1.0_空白版.html' 'D:\九霄 WEB\outputs\九霄WEB-1.0\九霄_WEB_1.0_空白版.html'
```

Edge 无痕上下文、无预置存档，视口分别为 1366×768 和 390×844。两版启动均显示 `#game.active`、`#landing.hidden`，并提示玩家“点击新开一局”，没有直接给出开局表单。经游戏底栏点 `#dockNew` 后，旧版姓名输入框顶端为 506/507px，现版为 1091/989px；现版在两种视口均不在首屏。点 `#dockWorld` 后，旧版世界资料顶端为 513/514px，现版为 1099/1053px。两版此次均无页面脚本错误。这只是空档、两个视口、浏览器文件打开方式的复现，不能外推到真实设备或所有旧档。

导航脚本使用本机 `playwright` 包和 Edge 可执行文件；新机器运行前须安装 Playwright，并按本机浏览器路径调整脚本。脚本断言上述故障仍可复现，因此修复版不应作为它的 `current.html` 输入；S2 应编写面向新路由的新验收测试。

源码还显示 `#enterGameTop` 直接调用 `showGame()`，即使 `current()` 为空；`#dockNew`、`#dockWorld` 都调用 `home(page)`。`home(page)` 切换标签但不滚动到目标；`work/jx-motion.js` 另添加“进入世界”视觉入口。把这些行为合在单页，会使多个入口指向相似区域，也使“进入世界”与“新开一局”的任务含义混在一起。S2 要以清晰路由修复，不以继续叠加浮层掩盖。

## 存储格式与样本边界

`work/v1.js` 当前库键为 `jiuxiao_v1_library`，外层为 `{version:1, active, saves[]}`。单档至少包括 `id/name/created/updated/turn/messages/player/npcs/world/items/events/stm/ltm/facts/actions/legacy/supplements/pending`；`validateSave` 对结构、时间、ID 和部分引用做校验。恢复键是 `jiuxiao_v1_library_recovery_*` 与 `_recovery_latest`；草稿键按档 ID 生成。旧单 AI 配置在 `sessionStorage.jx1_config`；五岗位配置在 `sessionStorage.jx_ai_config`。真实值可能含密钥，审计只列键名，绝不导出值。

`tests/fixtures/legacy/native-v1-empty.json` 与 `legacy-chat.json` 是合成样本。前者验证 v1 原生包的结构，后者验证旧对话 JSON 与三块附加原文。两份样本不覆盖大量旧档差异，也不能证明真实私人档迁移成功。S2 须再建立匿名边界样本：损坏 JSON、重复 ID、未知数量物品、未完成 `pending`、超限、跨标签冲突和中断恢复。若作者提供真实旧档，仅在本地记录文件路径与哈希，并经允许后做脱敏测试；不得提交原文。
