## 三、修复应达到的行为

- **规则已确认到修订 8：** 保留原结果和失败记录；释放的是玩家继续行动的阻塞。新的免费行动使用新键和 expectedRevision=8，按规则推进。
- **旧键重读／重复提交：** 读取原回执与叙述状态，不重扣资源、不重结算、不再请求模型。相同键但内容变化继续按原冲突契约拒绝。
- **模型出站后结果未知：** 保留未知状态、费用预留和原键，不自动补发。只要规则回执已可靠确认，可独立进行后续免费行动。
- **规则本身未确认：** 先通过既有恢复入口核对，不能仅凭 UI 回合数猜测已提交，也不能换键重演旧行动。
- **正文来源：** 已保存的模型首答不可覆盖。本地补充正文须标为本地生成，不能伪装成供应商回复。
- **玩家提示：** 用简单文字说明“行动已生效，AI 正文暂未取得，可用免费正文继续”等实际状态，避免把修订号、账本和内部错误术语塞进剧情。

保留现有世界规则、数值、提示词和文风。无需增设审核签名链或人工确认关卡。
