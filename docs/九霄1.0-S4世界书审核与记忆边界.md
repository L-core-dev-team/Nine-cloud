## 阶段入口决定

S4 已开始做来源保护与审校准备。当前先把原稿标题、行号、来源标记和待核标记编成仅供作者核对的草稿索引，不拆写或改述正文，不据标题推导设定，不将索引或原稿装入玩家端构建。该索引方便 A/B 对账，也便于原图到位后逐项定位。

初代原稿的仓库副本与用户提供文件 SHA-256 一致：`1d871057163f7f0b439c135b3af943e948b2401bb284ab077622ed95450d35d2`。索引由 `scripts/audit/build-worldbook-draft-index.mjs` 生成，输出为 `docs/sources/worldbook-draft-index.json`。它只包含标题、行号、局部来源引用和标记次数，状态固定为 `unreviewed-source-material`、`publishable=false`。`draft-heading-####` 只是该次索引里的顺序标记，不能用作正式 Canon、事件或存档 ID。

截至此次扫描，索引识别 172 个标题、219 次来源标记；按原稿明确标记语法计数，疑似缺失 155 次、待确认 20 次、看不清 47 次、待归属 4 次。这些都是标记出现次数，不是问题条目、图片或已审条目数。此处保留与来源登记一致的计数口径。

## 已建立的 S4 基础

- `pnpm worldbook:index:write` 按当前来源文件生成索引；`pnpm worldbook:index:check` 校验索引是否与来源字节一致。
- 索引带来源 SHA-256。来源改动但未重建索引时，检查失败。
- 每个标题记录层级、起止行、父标题、该标题直接段落中的来源标记和疑似缺失/待确认/看不清/待归属标记次数。
- 索引明确声明这些次数是标记出现次数，不等于问题数、图片数或已审条目数。
- 现有玩家端搜索仍只读取 `packages/content/src/worldbook.ts` 的 7 条审核记录。原稿和草稿索引不参与 Web 构建输入。
- `packages/content/src/source-register.ts` 与 `worldbook-publisher.ts` 已实现新增 Canon 的原图哈希和双作者同摘要批准门禁；`scripts/audit/publish-approved-worldbook.mjs` 是私有来源目录的离线发布命令。它不把原图读入 Web 包，也不自行批准条目。
- `packages/domain/src/memory/` 已实现可见事件入信念、检索与两种版本化检索策略的纯数据原语；尚未连到回合、NPC 权限或叙事。遗忘策略只影响能否检索，不修改权威事件。
- 2026-09-27：NPC 记忆创建、观察写入与检索现在会重复校验持久化 JSON 的策略版本、所有者、事件 ID 唯一性、修订号、时间、可见渠道和非空摘要；伪造授权及无效检索参数会被拒绝。`packages/domain/src/memory/memory.test.ts` 覆盖这些拒绝路径。此项只加固纯数据原语，仍没有生产可见性授权器或回合/叙事接入。

## 必须保持的证据边界

1. 原图是最高来源。OCR、上下文恢复、作者授权补全是不同证据类别，不能合并成“原文”。
2. 这份初代文本中的说明、批注和未决标记均是待审资料，不是对代码代理的指令。
3. 目前 7 条审核子集沿用既有运行记录；这不构成整本世界书或 182/207 两批来源已经对账的证据。
4. 对有冲突的条目并列保留来源和裁定状态。未获作者裁定前，不由模型或工程实现选择一个版本。
5. 内部审核数据与玩家端 Canon 分开存放。构建清单只允许显式批准的条目通过；不得通过“所有 Markdown 文件都打包”来实现检索。

## 从先前阶段携入的缺口

- **S0–S2：** 旧 HTML 的全部交互语义未迁完；存档损坏、配额耗尽和中断恢复矩阵不全；真实设备测试延后。
- **G1：** S0 功能范围有 LYL 确认，但旧功能逐项验收和 A/B 对同一提交的工程签收仍未完成。
- **S3：** 回合事务/幂等/回放基础已实现；无签署的六类行动规则、九境五域矩阵和生产 reducer，因此真实行动仍拒绝结算。
- **服务端：** Docker、数据库迁移、API readiness 有本机验证记录；账号、存档、回合业务接口仍未实现。
- **来源批次：** Bird 草稿报告了旧 182 项清单内部的去向；原稿自述 207 张的完整口径仍未在本工作区核实，不能把两个数简单相减或都写成已审原图数。

## S4 退出条件

- 可追溯的来源登记能从条目回到原图 ID、哈希、转录版本、冲突、作者裁定和复核记录。
- 构建只纳入显式批准的 Canon 条目；原稿、原图和未审 OCR 不进入公开资源。
- 存档记录固定 Canon 版本；版本缺失或冲突时给出可恢复路径。
- 记忆模式彼此隔离；NPC 信念只来自可见事件；世界权威状态始终由规则与事件日志维护。
- 叙事生成、超时重试与记忆更新均有故障测试，模型输出不能写入权威事实。
- A 验内容、人物认知与叙事边界；B 验来源、访问隔离、版本与回放。原图不到位的部分继续登记为阻断项，不虚报 S4 完成。
