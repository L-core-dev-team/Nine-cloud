**分支：** `codex/jiuxiao-s0-s7-hardening`

**判定：** 工程可独立完成的加固、候选素材接入和本机验证已完成；阶段总体尚未达到签收条件。

## 一、范围和结论

本轮处理了 S6 云存档 HTTP 路由的安全挂载边界、S7 权益账本基础、用户提供视觉素材的派生与页面映射，以及端到端测试暴露的搜索状态串扰和测试选择器问题。原始素材只读；派生物进入站点候选目录。没有把图像当作世界设定，也没有把额度账本包装成支付系统。

S0–S7 不能整体宣告完成。最主要的硬门槛仍是：旧功能逐项行为等价和双作者签收；六类玩法规则签署；Canon 双人同摘要批准；素材授权与作者验收；真实身份、邮件和云存档安全链；以及 S7 商业策略与运营依赖。当前没有 G1/G3 签收。

## 三、本轮改动与证据

### 代码与素材

- `apps/api/src/routes/saves.ts`：提供依赖注入式云档路由；只从注入的可信会话读取 owner，不接受客户端传入的所有者字段；请求体按流读取并在超过 1 MB 时取消，UTF-8/JSON 和 schema 均校验，revision 冲突有明确结果。`apps/api/src/app.ts` 仅在同时提供服务和认证 resolver 时挂载。生产入口当前没有提供 resolver，所以路由不开放。
- `apps/api/src/services/entitlement-ledger.ts`、`postgres-entitlement-ledger.ts`：额度发放、扣减与一次性全额退款的领域/数据库实现。金额和支付明确不在此服务职责中。
- `packages/db/src/schema.ts`、`packages/db/drizzle/0001_s7_entitlement_ledger.sql`：账本表、约束、索引及阻止更新/删除既有流水的数据库触发器；Drizzle journal/snapshot 已更新。
- `apps/web/src/candidate-atlas.ts` 和 `apps/web/public/scenes/candidate/`：54 个派生候选文件，总计 11,634,283 字节；清单保存源路径、源 SHA-256、输出 SHA-256、尺寸及来源状态。原素材目录未作为 Git 内容加入。
- `apps/web/src/main.tsx`：正文 Canon 搜索和图鉴搜索分离，切换栏目不再串用同一查询条件；图鉴和建角预览复用候选插画。
- `apps/web/src/scene-media.ts`、`graphics-settings.ts`、`routes/GraphicsSettings.tsx`、`scenes/SceneAtmosphere.tsx`、`packages/content/src/scenes/manifest.ts`：固定场景映射、移动/桌面裁切选择、可选静音视频与静态回退；视频默认关闭，尊重减少动态效果和省流量设置。
- `tests/e2e/foundation.cjs`：校正到新候选海报资源；验证图鉴分类、地域切换、图片实际加载、移动/桌面、AI/本地存档以及退化路径。原 E2E 与页面中两个相互独立的搜索条件已覆盖。

## 四、人工输入与具体完成步骤

### A. LYL 与 Bird：旧功能、玩法和发布门禁

1. 打开 `docs/九霄1.0旧功能对照与存档样本.md`，以旧 HTML 实际界面逐行走查。每项记下旧入口、新入口、输入、成功结果、失败提示、取消结果、刷新后恢复和存档影响。不要用按钮数量相同代替行为等价。
2. 对不迁移功能写明原因、替代动作和旧档兼容方式。所有保留功能须有可重复验收步骤；由 LYL 和 Bird 分别确认同一个提交 SHA，再将确认记录写回交付文档。此步骤通过后才申请 G1 签收。
3. 一起签署 `docs/九境五域玩法语义矩阵.md` 中六类行动规则。每类明确前置条件、状态字段、资源消耗、成功与失败条件、生成事件、重复请求行为及中断恢复。工程随后实现确定性 reducer，并对本地/服务端跑同一组用例。
4. 世界设定逐条核对来源和内容摘要。双方对相同 SHA 的 Canon 条目给出审批/退回记录；只有有双人回执的正文进入玩家运行包。把 182 张 OCR 原图继续当作后续资料，等 Bird 提供时再建私有审核流程，不先行假设它们已审。

### B. LYL 与 Bird：视觉、来源与声效

1. 按配套[素材名称与页面映射](九霄素材名称与页面映射-2026-09-28.md)逐组确认场景、地域预览、图鉴和装饰的用途；确认最终文件而不是只确认生成提示词。
2. 对每个准备进入公开站点的文件补来源、工具/生成记录、作者权利与商业分发许可。项目方确认授权前，候选文件只用于私有开发预览；生成图片不代表自动取得商用权。
3. 审核各设备裁切和四场景风格一致性，决定哪些海报成为正式图。当前山门和野外两条视频均无音轨；提供或签收可分发的瀑布/环境声文件并标注来源、循环点、音量和静音默认值。

### C. 项目负责人：S6 身份和数据政策

1. 明确邮件发送域/服务商、账号删除、档案与调用记录保留期、备份周期及隐私告知；确认哪些富存档字段允许云端存储。
2. 技术实现统一游客 `SaveEnvelope` 与剧情、历史、附件、旧档归档的版本合同；密钥、OTP 和敏感正文不得随档案上云或进日志。
3. 接入真实身份后，才把 resolver 注入 API 并挂载云档路由；通过两账号互读拒绝、断网队列、冲突分支、导出/删除、迁移回滚和恢复演练。此前接口保持关闭。

### D. 项目负责人：S7 是否包含商业化

1. 决定 1.0 是纯 BYOK/免费公测，还是包含任何付费权益。若暂不付费，保留账本作为技术底座但不展示商店或货币功能。
2. 若计划收费，先确定运营主体、币种/价格、退款和纠纷规则、服务商成本核算口径、支付渠道与真实沙箱账号，再实现验签、幂等通知、退款反向流水、账单对账、风控和数据导出。
3. 完成前述决定后补业务 API、后台任务和端到端测试；当前 S7 账本不能用作支付验收凭据。

### E. 产品可运行后的设备验收

在可部署版本具备后，选实体 Android 手机、iPhone/iPad、平板、集显笔记本和桌面浏览器。按开局至任务结束、断网恢复、低功耗、省流量、减少动态效果逐条留证；测 LCP、INP、CLS、内存与长时动画帧率。模拟浏览器通过不替代此门槛。

## 五、提交与保管边界

- Git 仅纳入源码、测试、文档及 `apps/web/public/scenes/candidate/` 派生物。`九霄素材-水墨古风/` 是用户原始目录，必须保持未跟踪、不改名、不搬移、不整体提交。
- `.env`、真实密钥、私人 OCR 原图、未脱敏存档不进入提交。素材清单中的 SHA-256 仅用于追溯，不代表内容许可。
- 本轮变更推到功能分支不等于合并 `main`，也不等于阶段通过。PR、阶段签收和公测发布都需要后续独立审查。
