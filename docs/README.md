## 状态用语

- **现有/已核实：** 可在当前源码或运行流程复现。
- **计划/目标：** 方案提出，尚未实施或尚未验收。
- **待核/阻断：** 缺少来源、原图、商户、外部专业结论或测试证据。
- **内部通过：** 私有环境达到明确测试门槛，不等于公开发布。
- **公开通过：** 双作者对同一版本签署，且外部运营条件和生产验收齐备。
