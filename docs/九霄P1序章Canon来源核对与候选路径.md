# 《九霄》P1 序章 Canon 来源核对与候选路径

**性质：** P1 输入来源审查及 A 的锚点决定记录。新增剧情是已登记的 author-original 候选，不是活动 Canon、规则签署或运行时内容。
**核对基线：** 现有 Canon 条目来源核对始于 PR #31 的 `37063ca5dd03cb40cd71bd5466a09f4941aa259c`；P0 A/B 契约审阅目标为 `0360185549154ee4267e6054500bc20afafab225`。新原创输入见[作者原创输入登记](九霄P1序章作者原创输入登记-2026-10-03.md)及 `canon.registry.json.authorOriginalIntakes`。活动 Canon 条目未改变。
**用途：** 记录现有来源能支持的事实、不能推出的剧情字段、A 已选择的开场锚点，以及仍须通过 S 轨规则和 Canon 门禁的部分。

## 核对结论

现有 Canon 能提供世界、地域、宗门制度和若干场景锚点，但不能单独支撑一个完成版序章任务。尤其缺少具体玩家起点、任务实例、NPC 身份与动机、物品、阻碍对象、成功/合法失败条件、状态初值和奖励。把这些补成剧情会构成新增作者内容，不能由工程或模型从 Canon 推导。

登记册当前 `activeVersion` 为 1.0，现有 34 条运行条目标记为 `confirmed`；登记册的批准模式是 `author_delegated_adjudication`，并声明 OCR/来源核对不等于作者本人逐页签收。A 已选择昊天剑宗、试剑崖教学锚点、任务殿后续来源锚点，并提供外门弟子晨课试炼的原创候选输入。该输入留在独立的 author-original intake 中，不加入活动 `entries` 或 `canon-runtime.json`。最终 Canon 发布回执仍按 S 轨 G-04a 处理。本表不关闭 G-04a。

## 候选开场锚点评估

### 选项 A：昊天剑宗任务殿

这是现有来源中最直接支持“接取首个任务”的锚点：登记内容说明任务殿发布任务，也是弟子获得贡献与历练的途径。但来源同时区分外门和内门；明确写出内门弟子开始接取任务。若采用此路径，作者必须决定新档角色是否已经满足相应身份条件。不能把“进入世界”自动等同于内门弟子。

它仍需要作者提供具体任务、发布者或接洽角色、玩家可见目标、关联地点、失败恢复、物品/奖励和钩子。Canon 只给出任务类别，不给出这些实例。

### 选项 B：昊天剑宗试剑崖

来源明确有每日切磋，因此可作为观察、交谈或训练战斗的候选场景。它不要求把首回合安排到妖林，也不必由系统虚构妖兽。现有条目没有指定对手、训练目标、胜负代价、道具或任务奖励。因此它适合作为经作者补写的教程场景锚点，不能直接称为已存在的首个任务。

### 选项 C：洪荒妖林外围

Canon 给出外围妖兽等级范围和适合历练的修士境界，但没有“安全新手区”的承诺，也没有具体遭遇实例。当前无法从来源验证一次战斗是否低风险、可恢复且不违背初始角色能力。若作者仍选此路径，须先提供角色基线、遭遇对象和可恢复的失败设计；不能从先前聊天中的“受伤灵狐”示例直接建立世界事实。

## 工程建议与作者裁决边界

**建议先评估选项 B 作为首屏后的教学场景锚点，选项 A 作为首个可领取任务的来源锚点。** 这是一项工程推断，不是 Canon 结论。两者是否属于同一地点、能否移动到达、由谁引导，以及新档角色是否有接任务资格，均未由现有条目确定。

要让序章覆盖移动、观察、交谈、使用物品和战斗，最小作者输入应补齐：

1. 选择场景锚点及新档身份/权限；若地点或人物为新增内容，明确标记为作者原创并给出稳定 ID。
2. 确认一个任务目标及至少一条可继续的合法失败路径；任务结果不能只由叙事描述。
3. 指定物品、用途、数量/归属初值和合法使用结果；这些字段及数值需与签署规则一致。
4. 指定现场 NPC 的身份、目标、与玩家的关系起点、所知来源和不能知道的内容；目前没有可直接挪用的引路人物。
5. 指定地点/场景连接与观察对象；地域正文不能替代空间图和移动规则。
6. 为无模型模式提供可核对的确定性文本与结尾钩子；BYOK 只改善叙述，不改变事务结果。

第 2、3 项规则值必须依赖 S 轨 G-03 的作者规则表；Canon 条目最终取舍须遵循 S 轨 G-04a。P1 只引用这些跨轨前置条件，不在 P 轨复制或关闭 S 轨缺口。
