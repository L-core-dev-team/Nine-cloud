# 九霄 WEB

> **世界书进度更正：** 原图与逐图文字已交付并经过拼接和部分作者审核；旧 182 条 OCR 清单仍未全部转成游戏 Canon，不能表述为“素材未提供／文字完全未审核”。详见 [世界书核验状态更正](docs/世界书核验状态更正.md)。

《九霄 WEB》是修仙 AI 文字 RPG 的私有开发仓库。仓库保留可运行的单 HTML 试玩原型，并逐阶段建设 1.0 工作区。

> **当前状态（2026-09-29）：** `apps/web` 已包含首页/世界入口、建角、游戏与存档界面、世界书浏览、五岗位 AI 设置、本地档案与旧档导入、场景和画质控制。它仍是工程预览，不是完整可玩公测版：权威玩法规则未签署，行动结算保持关闭。API 有健康/就绪端点和待认证的云档服务基础；生产入口没有接入登录或挂载云档路由。权益账本不等于支付。代码目录见[项目结构地图](docs/项目结构地图.md)；已销账缺陷与全部现行缺口见[阶段缺口与人工交接清单](docs/九霄1.0阶段缺口与人工交接清单-2026-09-29.md)，技术取舍与验证范围见[全仓复核报告](docs/九霄1.0全仓复核与技术选型-2026-09-29.md)。

## 仓库结构

| 路径 | 内容 | 维护规则 |
| --- | --- | --- |
| `docs/` | 现状记录、设计记录、长期路线与 1.0 执行文件 | 从[项目结构地图](docs/项目结构地图.md)了解目录；从[文档索引](docs/README.md)区分当前状态与历史快照 |
| `work/` | 当前单 HTML 原型源码、构建工具、测试、资源、OCR 辅助材料 | 见 [工作区说明](work/README.md)；脚本可能会改文件 |
| `outputs/` | 原型 HTML、测试页面、历史记录、世界书与交付材料 | 见 [产物区说明](outputs/README.md)；不要手改生成 HTML |
| `.github/` | GitHub 维护配置 | 发布和分支规则以 GitHub 实际设置为准 |
| `apps/` | React/TypeScript Web 预览、Hono API | 页面和本地体验已有实现；权威回合规则、认证与生产云同步仍未完成 |
| `packages/` | 共享运行时契约、fail-closed 规则入口、内容和数据库定义 | 只有已签玩法规则才能启用结算；数据库结构不代表线上业务已开放 |
| `scripts/`、`tests/` | 基线审计、构建清单与合成样本 | 不放私档、密钥和未审原图 |
| `PRODUCT.md`、`DESIGN.md`、`SECURITY.md` | 产品与设计约束、安全边界 | 以新版总方案和阶段证据判断完成状态 |

现有原型构建大量使用固定相对路径。1.0 迁移完成之前，不要为视觉整齐擅自移动它们。新分层应用按 [AI 执行清单](docs/九霄1.0分阶段实施与AI执行清单.md)逐阶段建立。

## 本地与私有材料

本地工具和视觉审查目录保持原位，不进入发行包。世界书原图、临江仙存档、OCR 转写和调用记录按私有资料处理；已有文字拼接与部分作者裁定，不代表所有缺口已解决。尚未转成正式 Canon 的资料不得作为玩家可见世界事实。不要把真实密钥写入仓库。

## 原型构建说明

当前原型开发源码位于 `work/`。`python work/build_v1.py` 构建基础试玩产物；`python work/build_worldbook_ui.py` 会另行处理世界书 UI。目前两条脚本路径尚未统一为新的 1.0 构建流水线。构建、验包和存档恢复脚本可能覆盖输出，执行前先核对目标路径和 Git 状态。

## 1.0 工程预览

需要 Node 24 与 pnpm 11.19。全新克隆运行 `pnpm install --frozen-lockfile`、`pnpm build`、`pnpm typecheck`、`pnpm test`、`pnpm test:integration`、`pnpm test:e2e`。集成测试要求独立、可丢弃的 PostgreSQL `TEST_DATABASE_URL`；缺失时命令会明确失败。CI 会启动一次性 PostgreSQL 并先执行迁移。本地用 `pnpm dev:web` 打开 `http://127.0.0.1:5173`；使用 `docker compose up --build -d` 启动开发数据库、迁移、API 和 Mailpit。直接运行 `pnpm dev:api` 时，需先设置可连通的 `DATABASE_URL`。服务入口和验收步骤见[服务链配置与验收](docs/本地服务链配置与验收.md)。新构建不会覆盖 `outputs/` 里的旧试玩产物。
