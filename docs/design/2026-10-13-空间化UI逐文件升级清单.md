## 1. 设计约束

方向：东方山门和阅读内容保持主体；晶莹玻璃表达功能层，光在操作时回应。保留“九霄”书法、“修途自此启程。”、现有山门资源、读取存档和昼夜切换。普通正文、世界资料、设置表单保持稳定底色。

主应用沿用 `LiquidGlass`；Regular 给导航/菜单/文字浮层，Clear 给丰富图像上的少量入口。网页折射近似与原生材质不同，须持续说明。新的局部参数先放开发样板对照，验收后再替换正式功能表面。

首帧标题与按钮可见可用；装饰渐入不挡输入。只用真实正在发生的操作显示等待文案。界面颜色不能授予修为、证明模型成功或代替规则结果。AI 素材标识、隐私、费用及失败后果保留准确说明。

## 4. 材质与动效的实施判据

| 项目 | 目标与判定 |
|---|---|
| 背景透射 | 同一控件后的图像/滚动内容变化能真实影响材质；不是运行时加载静态玻璃图片 |
| 光学层次 | 边缘聚光细而不连续粗白；正文轮廓不受位移影响；记录每个实际启用 SVG 的表面 |
| 明暗环境 | 调节背景遮罩/语义文字色，不能全部用白字或一个透明度；Clear 在明亮复杂背景重新检查 |
| 文字 | 普通文字至少 4.5:1、大字至少 3:1；动态背景需取最不利位置，像素取样不能等同全面 AA 认证 |
| 几何 | 功能层轮廓圆润、边距与内层圆角协调；触控区域沿用至少 44px，视觉缩放不缩小实际可操作范围 |
| 动作 | 建议反馈 120–180ms、局部进入 240–400ms，明确属性的 transition；不是全站统一 `transition: all` |
| 稳定 | 非等待状态没有持续循环形变；减少动态停止装饰而不隐藏内容或破坏交互状态 |
| 光感 | hover/focus/press 都有反馈，键盘不用鼠标坐标才能辨识焦点；不追光整个阅读区 |
| 高级回退 | 无 SVG/无 backdrop-filter/降低透明度/强制颜色都有完整功能；Safari 与 WebKit 未测就明确写未测 |
| 低成本 | 不增加大场景或视频默认加载；新滤镜表面数、重绘面积与输入响应成本有对照记录 |

这些时间和材质目标是下一轮建议，不是当前代码的统一参数；具体视觉值须在同一场景的原型对照中决定。

| 场景 | 证据 | 不得替代 |

| 夜/昼、明亮复杂图、纯色、滚动图文 | 正式页与样板同尺寸截图，表面/文本/滤镜状态记录 | 不能用样板截图证明正式组件全部合格 |

| 鼠标/键盘/触摸、菜单打开关闭、按压释放、切页 | 实际交互断言或录屏，光感停止与焦点返回检查 | 不能只看静态图判断动效稳定 |
| 减少动态/降低透明度/提高对比度/强制颜色/禁滤镜 | 偏好模拟、computed style 和完成主要旅程 | 偏好模拟不等于所有浏览器系统设置实测 |
| 冷/暖加载、同机同场景 SVG 开关、连续滚动/输入 | 资源体积/请求，Long Task、输入响应和帧调度对照 | rAF 调度不等于绘制 FPS，不能保证手机 45fps |
| Chrome/Edge、Firefox/WebKit（可用时） | 写明实际引擎、版本和运行范围 | User-Agent 伪装不能充当 Safari/鸿蒙真机 |
| 真规则/登录/跨档/长局/恢复 | 玩法分支整合后独立联合验收 | mock 回执不能证明生产持久化或真实模型投递 |
