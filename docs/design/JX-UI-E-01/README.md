## 一、一页摘要

**北极星：仰观九霄，俯读人间。**

《九霄》有三种观看姿态，对应三层界面：

| 层 | 姿态 | 页面 | 一句话 |
|---|---|---|---|
| 灵境 | 仰 | 首页、大厅、角色卡库、人物志 | 抬头看一个世界：山门、云海、浑天环、月洞门。华丽集中在这里 |
| 书阁 | 俯 | 单人会话、群聊、原生游玩、世界设定正文 | 低头读一页书：正文是唯一主角，背景退场，动效只做状态过渡 |
| 案头 | 执 | 世界书管理、AI 设置、存档、账号、画面设置 | 坐在案前执笔：清楚、高效的现代工具 |

**两个签名图形**，严格限定位置：

- **浑天环**：极细香槟金铜环与刻度，出现在首页题字背后、真实 AI 生成时的等待指示、地点铭牌装饰线。它把"九霄（天）"和"精密（器）"连在一起，取代廉价的发光法阵。
- **月洞门**：园林圆形门洞，框住大厅三处去处的场景。延续现有"月下入界山门"母题。

**一套签名色系**：群聊角色按国画颜料色区分——石青、石绿、朱砂、藤黄、胭脂、赭石、花青、月白。

**色彩职责只有一条规则：一种颜色只做一件事。** 灵玉青 = 可以操作；香槟金 = 仪式；星雾紫 = 只在天空里；朱印 = 只做品牌印记。

**字体三声部**：题字（马善政楷书，只写"九霄"等几个字）、书卷（自托管思源宋体，正文与标题）、案头（系统无衬线，按钮和表单）。

**工程原则**：保留 React/Vite；复用 `GameShell`、`LiquidGlass`、`SceneAtmosphere`；新增语义 Token 层（`data-jx-layer` 切换三层）与 CSS `@layer`；展示组件与业务逻辑分离；测试锚点有合同；界面上每个数据都要指得出真实字段。

## 三、待道主确认的决定

以下是本方案中属于品牌或范围层面的选择。**每项都给出推荐；道主不回复时，执行者按推荐执行。**

| 编号 | 决定 | 推荐 | 备选 | 影响 |
|---|---|---|---|---|
| D-1 | 界面交互强调色 | **灵玉青 `#79CFC4`**；桃粉退为场景美术与角色色"胭脂" | 保留桃粉为交互色，灵玉青退为场景冷光 | 修改 `PRODUCT.md` 中"粉晶高光"的品牌承诺 |
| D-2 | 首页"九霄"题字方向 | **竖排**，如立轴题款 | 保持现有横排 | 首页构图 |
| D-3 | 顶栏长品牌句"踏月过山门，天地任君行。" | **移到首页与页脚**，顶栏只留印章与题字 | 保留在顶栏 | 顶栏宽度与移动端空间 |
| D-4 | 自托管思源宋体 | **采用**（切片加载）。Windows 阅读质量显著提升 | 继续依赖系统字体 | 首屏字体体积增加，须控制在 150 KB 内 |
| D-5 | 大厅"本机最近打开" | **采用**，新增本机 `localStorage` 键 `jx_recent_v1`，不涉及存档 | 不做，大厅只显示本机存档 | 角色卡会话能否出现在大厅 |
| D-6 | 小说阅读模式 | **本期实现只读部分**，放在功能开关后默认关闭；AI 润色与导出只做概念稿 | 全部只做概念稿 | 工作量约增加一个里程碑 |
| D-7 | 3D 浑天仪 | **本期不做**，用 SVG | 做为首页"电影"档的懒加载可选效果 | 引入 Three.js 与性能风险 |
| D-8 | 设计源文件工具 | **Penpot**（开源免费） | Figma 免费版 | 无费用差异 |
