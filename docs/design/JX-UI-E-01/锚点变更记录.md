## 未改动、但按新设计保留的既有契约

为避免削弱既有断言，以下旧契约被保留下来，设计做了相应取舍：

| 契约（测试） | 设计上的取舍 |
|---|---|
| 首页主入口“进入世界”、读取存档按钮的可访问名与玻璃滤镜参数（`foundation`、`game-shell`、`liquid-glass-production-guard`、`design-acceptance`） | 主入口文案保留“进入世界”，做成灵玉色玻璃而非实色按钮；无存档时保留“读取存档 / 当前没有旧档” |
| 大厅标题“选择去处”、按钮“新开一局”“继续游玩”“跳过设置”“作品简介”“阅读世界设定”“管理存档”“角色卡模式”（`foundation`、`first-play-ux`、`card-availability` 等） | 月洞门与工具行沿用这些名称 |
| 所有页面背景保留所选场景海报（`foundation`） | 案头层不改纯色，改为约 90% 画布色遮罩下的极淡场景 |
| 世界设定分类筛选共用一块 `blur(12px)` 玻璃托盘，手机端返回条与托盘 -4px 外扩（`game-shell`） | 保留托盘，只去掉托盘描边以免双重边框 |
| AI 专业编辑器视觉冻结（`foundation`，冻结颜色，开放字体与间距） | 只改该编辑器的字体（D6），颜色与其余属性不动；新加的中文排版属性显式排除该区域 |
