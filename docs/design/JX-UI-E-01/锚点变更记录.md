## 未改动、但按新设计保留的既有契约

为避免削弱既有断言，以下旧契约被保留下来，设计做了相应取舍：

| 契约（测试） | 设计上的取舍 |
|---|---|
| 首页主入口“进入世界”、读取存档按钮的可访问名与玻璃滤镜参数（`foundation`、`game-shell`、`liquid-glass-production-guard`、`design-acceptance`） | 主入口文案保留“进入世界”，做成灵玉色玻璃而非实色按钮；无存档时保留“读取存档 / 当前没有旧档” |
| 大厅标题“选择去处”、按钮“新开一局”“继续游玩”“跳过设置”“作品简介”“阅读世界设定”“管理存档”“角色卡模式”（`foundation`、`first-play-ux`、`card-availability` 等） | 月洞门与工具行沿用这些名称 |
| 所有页面背景保留所选场景海报（`foundation`） | 案头层不改纯色，改为约 90% 画布色遮罩下的极淡场景 |
| 世界设定分类筛选共用一块 `blur(12px)` 玻璃托盘，手机端返回条与托盘 -4px 外扩（`game-shell`） | 保留托盘，只去掉托盘描边以免双重边框 |
| AI 专业编辑器视觉冻结（`foundation`，冻结颜色，开放字体与间距） | 只改该编辑器的字体（D6），颜色与其余属性不动；新加的中文排版属性显式排除该区域 |


## 第二轮：可见文字与结构的变化（测试断言未改）

这些改动没有触及任何测试文件里的断言；列出来是为了让依赖页面文字的人知道哪里变了。

| 位置 | 之前 | 现在 | 仍然成立的既有锚点 |
|---|---|---|---|
| 卡库“已保存卡片”每张卡的说明 | `名字 · 编号前 8 位 · 新版本` 一行 | 名字一行；下面一行“初版／修订版”和会话数；完整编号移到名字的提示文字 | `li` 里仍含角色名（`card-ui-s2-real` 用 `hasText` 过滤） |
| 卡片“查看”对话框 | 资料列表 + 解析数据 + 编辑表单 | 人物志抽屉：封面区、目录、分章正文、修订区；解析数据收进“查看解析资料” | 对话框名“角色卡资料详情”、“关联资料：”文字、“导出 V2/V3/PNG”按钮名（`aria-label`）、“角色名称”“新版本角色描述”“场景”等标签、“保存为新版本”、“关闭资料面板” |
| 卡片显示名的回退顺序 | 卡片名 → 导入文件名 → 编号 | 卡片名 → 解析出的角色名 → 导入文件名 → 编号 | 详情接口不带 `name` 时不再显示文件名（真实流程录屏中发现） |
| 世界书管理 | 一列：书目行 `文件名 · 编号 · 状态`、替换表单、选中后的编辑区 | 三栏工作台：书目 / 条目预览与修订 / 全局设置；书目行把状态拆成单独一行 | 区域名“世界书管理”、“查看与创建新版本”“启用全局／关闭全局”“创建世界书新版本”“替换全局世界书”、标签“名称”“条目 JSON”“替换已启用世界书”“替换为”、状态文字“全局启用” |
| 替换下拉的选项文字 | `文件名 · 编号` | `文件名（编号）` | 选项的 `value` 不变（`card-ui-s2-real` 读取的是 `value`） |
| AI 设置页 | 页首直接是设置方式选择 | 页首多一段“两套 AI 的区别”，位于专业编辑器之外 | 专业编辑器冻结样式指纹不受影响（新元素不在 `.ai-page` 子树内） |
| 角色卡会话顶部 | “返回卡库” | 构建开关 `VITE_JX_NOVEL_MODE=1` 时多一个“成卷”按钮；默认关闭时与之前一致 | “返回卡库” |
