# 02 · 页面规格

本文件逐页规定布局、组件、状态和**数据契约**。数据契约是本任务的生命线：界面上每个数字、名称、状态都必须能指向真实字段；字段不存在时，按"缺失时"一列处理，不得用假数据或推测填充。

字段名以 2026-11-22 的 `main@f1fe6ea` 与 PR #119 `9c0724f` 为准（`apps/web/src/storage.ts`、`apps/web/src/card-import-client.ts`、`apps/web/src/routes/*`）。执行时若字段已变化，以届时代码为准并在验收记录中注明差异。

线框图里的方框只表示区域，不代表一定要画边框。

### 数据契约

| 界面元素 | 来源 | 缺失时 |
|---|---|---|
| 继续行旅：名称、地点、回合 | `LocalSave.name`、`.location`、`.revision` | 显示"开始第一次行旅" |
| 相对时间 | `LocalSave.updatedAt` | 不显示时间 |
| 横幅场景图 | `sceneForLocation(location)`（`@jiuxiao/content/scenes`）对应的已批准海报 | 默认山门海报 |
| 本机最近打开 | **新增纯前端记录**：本机 `localStorage` 键 `jx_recent_v1`，只存 `{kind, id, label, openedAt}`，上限 8 条；读写失败时整块不显示 | 不显示该块 |

          点击立轴 → 右侧滑出人物志（P04），宽 min(720px, 60vw)
```

- 立轴卡：2:3 竖幅图像，玄青金属 1 px 外框，圆角 4 px；名称在图下方，书卷字体 18 px；第二行为该卡的会话数（若可得）。
- 悬停/聚焦：卡片上方出现一道柔和顶光（径向渐变，从卡片顶部中心向下），卡片上移 4 px。这是"收藏馆射灯"的意象，替代常见的整卡发光。
- **缺图占位**：取名称首字，书卷字体 600 字重，置于按名称哈希选取的矿彩淡墨晕染上（见 [01 §8](01-设计总纲.md#8-图标与插画)）。
- **群聊建立**：点击"选择多位，建立群聊"进入选择模式，立轴左上角出现复选标记，底部浮出操作条"已选 3 位 · 建立群聊"。数量上限与校验沿用现有代码。
- **导入**：主按钮打开导入抽屉（右侧 / 移动端全屏），保留现有全部字段与步骤：文件类型、选择文件、权利确认复选框"我确认有权上传并使用此文件。"、上传并核对、核对结果、作为新卡或已有卡的新版本、来源、备注、附件绑定。**【定】这些字段一个都不能删，确认复选框文案不得改动**（测试与合规依赖）。
- 导入记录、已保存卡片的删除、下载原文件、加载更多均保留。

### 图像加载策略

`CardItem` 没有头像地址。现有接口 `original(importId)` 返回原始文件字节；PNG 卡片可以由前端解码出图像。

- 只为进入视口的卡片请求原文件（`IntersectionObserver`），并发 ≤ 3。
- 解码后用 `createImageBitmap` + Canvas 缩为 ≤ 360 px 宽的缩略图，在内存中以 LRU 缓存（≤ 40 张）。
- 原文件 > 2 MiB 或解码失败时，使用首字占位，不重试。
- JSON 卡片没有图像，直接用首字占位。
- **【定】不新增后端缩略图接口**（属于后端变更，需另行授权）；不把缩略图写进 IndexedDB 或存档。

### 数据契约

| 界面元素 | 来源 | 缺失时 |
|---|---|---|
| 名称 | `CardItem.name`，否则 `parsed.name` | "未命名角色" |
| 图像 | `original(import_id)` 的 PNG 字节 | 首字占位 |
| 会话数 | 由 `sessions()` 按 `card_id` 计数 | 不显示 |
| 标签筛选 | 仅当列表返回的 `parsed.document` 已含标签时在前端筛选 | 只提供现有搜索，不做筛选 UI |
| "已收 N 位" | `cards()` 已加载条数；有"加载更多"时写"已加载 N 位" | — |

**【定】** 不显示热度、评分、下载量、推荐（无数据来源，且 ADR-0004 排除社区功能）。

### 状态

| 状态 | 表现 |
|---|---|
| 服务未开放（现状 D8） | 一个单环浑天空态图形 + "角色卡模式当前未开放。" + 次要按钮"返回大厅"。按钮使用标准次要按钮样式 |
| 未登录 | 说明"角色卡与账号绑定，请先登录。" + 主按钮"登录" |
| 空库 | "还没有角色卡。导入一张 PNG 或 JSON 卡片开始。" + 主按钮"导入角色卡" |
| 加载中 | 6 张立轴骨架（静态浅色块，不闪烁扫光） |
| 加载失败 | 错误文字来自 `cardError()` + "重试" |

- **版本与来源**：`CardItem.parent_id` 链、`metadata.source`、`metadata.notes`、`metadata.links`。

### 建立会话弹窗

│ ┌ 白芷 ……                                        ┐ 本机  待上传 │
│                                                              │
│ 待上传与冲突（若有）                                            │
│ 导入存档   导出全部                                             │
│                                                              │
│ 危险区（折叠）：注销账号 / 删除云端数据                            │

```

- 每份存档一张"档案匣"，右上角来源标记：本机 / 云端 / 待上传 / 冲突（来自现有 `cloud-sync` 状态）。
- 删除：危险按钮 → 确认对话框写明"删除后无法恢复。如需保留，请先导出。"并提供"先导出"按钮；确认按钮文字"删除存档'林青'"。
- 冲突处理沿用 `.save-conflict-actions` 现有选项与语义。
- 账号生命周期（注销等）放入默认折叠的危险区，保留现有全部步骤与确认。
- 人机验证区块（`aria-label="人机验证"`）保留；WCAG 2.2 3.3.8 无障碍认证的符合情况须在报告中如实记录，**不得为符合而改动认证逻辑**（属账号安全，需另行授权）。

## P11 · 移动端适配总则

移动端不是桌面的缩小版。本节是所有页面在 `compact` 与 `medium` 断点的共同规则。

| 主题 | 规则 |
|---|---|
| 导航 | 灵境层底部导航 4 项；书阁、案头层无底部导航 |
| 正文 | 书阁层正文占满宽度，左右各 20 px；字号默认 17 px |
| 输入栏 | 固定底部；`padding-bottom: max(12px, env(safe-area-inset-bottom))`；软键盘弹出时随 `visualViewport` 上移，输入框与提交按钮始终可见 |
| 焦点不被遮挡 | 键盘或滚动使焦点元素进入底部输入栏/顶栏下方时，`scroll-padding-block` 保证其可见（WCAG 2.2 2.4.11） |
| 抽屉 | 一律为底部弹层，三档高度（40% / 75% / 全屏）；必须有关闭按钮与 Esc 关闭；**拖拽手柄必须有点击替代**（WCAG 2.2 2.5.7） |
| 弹窗 | 原生 `<dialog>`；内容超高时内部滚动，按钮区固定在底部可见 |
| 触控目标 | ≥ 44×44 px（项目既有标准，高于 WCAG 2.2 2.5.8 的 24 px） |
| 旋转 | 横屏手机：书阁层隐藏顶栏标题，只保留返回与设置；正文行宽限制在 38em |
| 滚动 | 页面级只允许一个纵向滚动容器；不允许横向滚动（标签栏除外，且需可见滚动提示） |
| 文字缩放 | 200% 缩放下无内容丢失；行宽与输入栏仍可用 |

**必测宽度：** 360、390、430、768、1024、1440、1920 px；另测 390×844 横屏与 768×1024 横屏。

## P12 · 小说阅读模式「成卷」（概念与可选实现）

**层：** 书阁的深度形态。

### 定位

把已经存在的会话历史，以书籍形式重新排版阅读。它是**只读视图**，不生成新内容。

### 可以进入可用产品的部分（真实功能）

| 能力 | 实现 | 前提 |
|---|---|---|
| 沉浸阅读 | 隐藏顶栏、输入栏、信息栏，只留正文；Esc 或轻点顶部退出 | 无 |
| 章节划分 | 确定性规则：按地点变化（原生游玩）或每 10 回合（角色卡）分章；章名为"第一回　芦花渡"或"第一回（第 1–10 回合）" | 只用已存字段 |
| 目录 | 左侧抽屉列出章节，点击跳转 | 无 |
| 书籍排版 | 首行缩进 2em、可选两端对齐、玩家行动以楷体小字插入为"批注" | 无 |
| 日夜阅读 | 复用阅读偏好 | 无 |

上线方式：先放在功能开关后（默认关闭），在开发样板路由中完整可用，经道主审核后再决定是否开放入口。

### 只能是概念稿的部分（不得出现在可用产品中）

- AI 自动生成章节标题、润色成小说文本：没有对应接口，且会调用真实 AI。
- 导出为 EPUB / PDF：任务书 E 明确"如不存在正式内容生成或导出接口，不得在可用产品中伪装已有该功能"。若后续要做纯前端 TXT 导出，需单独授权。
- 注释、人物关系注解：需要数据来源。

概念稿放在设计源文件与 `/__design` 样板路由中，页面上标注"概念稿，未实现"。
