## 反复出现的主题

1. **材质与分层是第一关注点**：液态玻璃、玻璃态、新拟态、黏土风都在回答同一个问题：界面用什么材质、分几层，才能让屏幕有纵深，同时又不干扰阅读。
2. **克制、留白、"设计隐身"**：苹果的"设计隐身"、Claude 的"工具的谦卑感"、拉姆斯的"少，却更好"、MUJI 的"空"、华为的"东方留白"反复出现，被 AI 串成一条"内容优先"的主线。
3. **东方美学重在转译，而不是堆砌**：华为一节明确主张提取"留白、气韵、写意"，不堆砌山水、水墨符号；侘寂被归入视觉平面一类。这是本组中与《九霄》最直接相关的观点。
4. **把光当作一种语言**：华为的"光为核心视觉符号"、全息光场、液态玻璃的边缘折射，都把"光"作为表达连接和层级的手段。
5. **长文本阅读的排版**：Claude 一节（出版级排版、行高与字距、超量留白）与瑞士网格、超极简文字排版前后呼应，对应游戏中大量剧情阅读的需求。
6. **工具选型的全链路**：设计（Figma）→ 动效（GSAP、Rive、Lottie）→ 3D（R3F、Babylon.js）→ 资产（Substance、glTF Transform、Draco）→ 下一代图形（WebGPU）。作者在寻找一张超出 Three.js／WebGL 的完整能力地图。
7. **AI 回答的共同毛病**：三段回答都偏好"分类 + 标签 + 绝对化形容"（如"天花板""远超""完全""全面支持"），自造了若干术语（"Claude 美学（行业通称）""物性论""扩散熔解美学"等），几乎不给出处、版本号和年份；还有个别过时信息（如 Adobe XD）和谱系颠倒（如"液态玻璃是玻璃态的分支"）。

## 最需要对照官方来源核实的 10 条主张

1. **"华为沉浸光感"到底是什么**：它对应哪个 HarmonyOS 版本、哪项官方设计能力，官方怎么描述（光束、星芒，还是玻璃材质）。回答没有给任何出处（19 号图）。→ 华为开发者联盟 HarmonyOS Design 文档。
2. **Liquid Glass 的官方分层与适用范围**：苹果是否要求玻璃只用于浮在内容之上的导航／控件层、避免用于内容层；截图中"背景层—玻璃层—内容层"的排序是否与官方相反（18 号图）。→ Apple Human Interface Guidelines（Materials）、WWDC25 相关讲座。
3. **Liquid Glass 的可读性与可调节性**："始终保持通透且不干扰阅读"是否成立；苹果在后续系统版本中加入了哪些透明度或着色选项（18 号图）。→ Apple 系统发布说明、辅助功能文档。
4. **圆角是"完全一致"还是"同心"**：苹果新设计系统中硬件、控件、图标圆角之间的关系（18 号图）。→ Apple HIG、WWDC25 讲座。
5. **"Claude 美学"的实际视觉特征**：配色是"米白、浅灰、淡靛蓝"，还是暖米白加陶土橙；这个说法是否真是"行业通称"；"直接发源于瑞士国际主义"有没有依据（19、22 号图）。→ Claude 实际产品界面、Anthropic 品牌资料。
6. **WebGPU 的浏览器支持现状**："主流浏览器已全面支持"是否成立；各浏览器在各平台（Windows、macOS、Linux、Android、iOS）分别从哪个版本默认开启（27 号图）。→ MDN、caniuse、各浏览器的发布说明。
7. **Adobe XD 的现状**：是否已进入维护模式、是否还能购买（25 号图）。→ Adobe 官方帮助页。
8. **Godot／Unity 的 Web 导出限制**：Godot 4 Web 导出的渲染器限制、包体大小、C# 支持、跨源隔离要求；Unity Web 平台的 WebGPU 状态（24 号图）。→ Godot 与 Unity 官方文档。
9. **Filament 与 Nannou 的 Web／WebGPU 支持**：Filament 的 Web 版是否支持 WebGPU、包体多大；Nannou 是否真能导出 WebGPU Web 应用（24、27 号图）。→ 两个项目的 GitHub 仓库与文档。
10. **压缩与动效工具的量化说法**：Draco"压缩 70%–90%""主流引擎原生支持"；Rive"性能远超 Lottie""可导出前端组件"；Framer"可直接导出网页"（26 号图）。→ Draco、Rive、Framer 官方文档，并在目标设备上实测。
