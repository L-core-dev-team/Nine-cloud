# 九霄 Markdown 制度冲突矩阵（VISION 02 开放宪章对照，只读审计）

- 审计对象：研究工作区，分支 `docs/vision-02-claude-research` @ `fe171ff`；345 份受跟踪 Markdown（全量清单见同目录 `md-inventory.md`）。未修改、未提交、未推送任何仓库文件。
- 对照基准：`AGENTS.md`、`CLAUDE.md`、`DESIGN.md`、`PRODUCT.md`、`docs/design/JX-VISION-02/README.md`、`05-claude-master-brief.md`、`07-creative-critique-protocol.md`（均全文阅读）。
- 判定口径：**冲突** = 以现行时态规定旧审美或旧技术（“克制”、固定旧色/旧构图/旧材质、签名图形配额、只准某框架、性能先于视觉、只改视觉壳），且会被后来者当成现行规则。**不算冲突**：Canon/世界书事实、作者签署、安全、许可、隐私、数据完整、测试诚实、可读/可操作/可恢复/降级与无障碍要求、历史验收原文——宪章明确保留这些。
- 读取深度：设计、工程、流程、宪章文件为“全文”或“规范句全文扫描+标题”；历史报告、验收记录、Canon 产物、实验报告和生成内容为略读（逐文件见 `md-inventory.md` 的“读取深度”列）。关键词全仓检索覆盖了全部 345 份。

## 0. 结论速览

1. 真正还“裸露”的现行冲突只有 **14 处文件**（下表 A 组）：它们没有 2026-11-25 效力声明，正文仍以现行口吻规定旧视觉或旧技术，或把读者导向已被取代的方案。
2. GPT 已给 17 份文件加了统一的“2026-11-25 设计效力更新”顶部声明（B 组）。声明已足以中和其冲突，正文应保持原样；但声明本身有两个缺陷：链接指向分支 `docs/vision-02-art-direction` 的绝对 URL（合并或删分支后失效）；没有说明“【定】”硬规则作废后，其中哪些条款（真实字段、原文不改写、对比度、降级、测试诚实）作为产品要求继续有效。
3. C 组是**技术/发布门禁**（Three.js 隔离扫描、scene-studio 排除过滤器、视觉冻结测试）：方向上与宪章不一致，但它们是作者批准的许可/发布规则，本研究阶段不得改动，只能在实施阶段由作者另行批准新门禁。
4. 有 **10 份 Markdown 被 CI 哈希锁定**（见 §3.1）。哪怕只在顶部加一行声明，也会让 `pnpm test` 失败或使已批准的 P1 规则身份失配。它们都不含审美限制，必须原样保留。
5. 作者要求“剔除保守”时须注意：仓库里大多数“保守/克制”不是审美用语（`世界书_保守补全版.md` 是 Canon 来源文件名，被索引脚本按路径和 SHA-256 绑定；P6 报告的“保守误拒”、M3 的“保持 DENY”、CLOSEOUT 的“保守费率”是测试诚实或财务口径；问卷中的“克制”是受访者原话）。这些词不能删，也不能改名。
