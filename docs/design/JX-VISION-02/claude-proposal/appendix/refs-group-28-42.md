## 反复出现的主题

1. **单一参数驱动一切**：一个 t 或 x∈[0,1] 同时驱动颜色、光的位置、粒子形变、时钟、叙事事件，以及页面底色（CSS 变量 `--night`）。
2. **感知色彩管理**：
   - OKLab 分段插值，避免"死灰"；
   - 在 OKLab 中按明度取档，超出色域时降饱和度，得到 22 色受限调色板；
   - 昼夜之间用 4×4 Bayer 抖动逐像素切换，不混出中间色；
   - 叠加 ±0.75/255 噪点防色带。
3. **光是灵魂**：
   - 边缘光：周长参数加高斯衰减，两遍描边，暗色下用 lighter 叠加；
   - 菲涅尔"摄影棚"环境反射；
   - 液态玻璃透镜：1.24× 放大、外圈压缩、5% 色散；
   - 低分辨率光场：box blur、B 样条采样、滤色叠加；
   - 轮廓光，以及光从画框溢出到网页背景。
4. **物理手感**：
   - 跟手：直接跟随，或指数逼近（速率 34）；
   - 位移 <4px 视为点击；
   - 松手时做速度投射（系数 0.06 或 0.09）；
   - 临界阻尼弹簧 ω 9.5–10，减弱动效时提高到 16–30；
   - 欠阻尼挤压拉伸（k170、c11，ζ≈0.42），到端点再弹一下。
5. **控件即叙事**：
   - 一个二态开关承载一个 24 小时的故事；
   - 往回走的是另一条路（滞回），停住时时间仍在流逝；
   - 隐藏彩蛋：百叶后面的无人机拼出"下班"，只有透镜才能勉强看到；
   - 累计道具：纸杯 1→4 个、呆毛 1→3 根、积压的消息；
   - 乱拖惩罚：老板剪影掠过。
6. **像素美术工程**：
   - 192×112 的核心区，加 14px 余量供透镜窥看画框外；
   - 整数倍放大，用 k / k+1 规则（k+1 时裁切 ≤12%）；
   - 用坐标表逐个定位物件；
   - 统一比例尺 1px≈3cm；
   - 自发光像素在夜里点亮。
7. **无障碍与工程收尾**：`button role="switch"`、aria-checked、键盘操作、`prefers-reduced-motion`、页面隐藏时暂停绘制、URL 参数 `?t=` 方便截图、单文件交付。
8. **地域与文化写实**：陆家嘴"三件套"、东方明珠、外滩、黄浦江；中国职场梗，如枸杞保温杯、KPI 白板、打车排队人数、发黄的发财树。

## 需对照官方来源核实的 10 条关键主张

1. **OKLab 与 color-mix**（29、33）：
   - 核实 `color-mix(in oklab, …)` 和 `oklab()` 的规范与兼容性，重点是华为浏览器和 iOS Safari。
   - 核实"OKLab 分段插值可避免中间死灰"：互补色直线插值仍会穿过近灰，需要中继色。
   - 来源：CSS Color 4/5 规范、MDN、caniuse。
2. **WAI-ARIA 开关语义**（28、31、42）：
   - 核实 `role="switch"` 的语义与键盘约定：空格必需，回车可选。
   - 核实 aria-checked 的读屏播报方式，以及固定的 `aria-label="浅色模式"` 能否播报出"深色"。
   - 核实"方向键每步 4% + 五阶段播报"是否应改用 `role="slider"` + `aria-valuetext`。
   - 来源：WAI-ARIA 1.2 与 APG。
3. **Canvas 合成与模糊**（30）：核实 Canvas 2D `globalCompositeOperation='lighter'`、`shadowBlur`、`ctx.filter` 的行为，以及"每帧 90 段 × 2 遍模糊"在移动端的性能。来源：WHATWG Canvas 规范、MDN。
4. **devicePixelRatio**（28）：核实按 `devicePixelRatio` 缩放 canvas 的标准做法，以及"上限 3"的取舍。来源：MDN。
5. **减弱动效与暂停绘制**（31、32）：核实 `prefers-reduced-motion`、Page Visibility API（`visibilitychange`）的用法，以及后台标签页对 requestAnimationFrame 的节流行为。来源：MDN、W3C。
6. **WebGL2 与整数放大**（33）：核实 WebGL2 在目标设备上的可用性，尤其是鸿蒙浏览器和 iOS Safari；并对比整数倍放大与 CSS `image-rendering: pixelated` 的效果。来源：Khronos、MDN、caniuse。
7. **色域映射与 Bayer 抖动**（34）：核实 CSS Color 4 的色域映射算法（在 OKLCH 中逐步降低 chroma），以及 4×4 Bayer 有序抖动矩阵的标准定义。
8. **PDLC 调光玻璃**（36）：常见产品是"断电雾化、通电透明"，原文"通电雾化"疑误。来源：厂商技术资料。
