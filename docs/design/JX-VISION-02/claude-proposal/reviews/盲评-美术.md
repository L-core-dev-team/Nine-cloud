# 《九霄》四方向美术评审（独立艺术总监视角）

评审对象：甲·九霄长卷、乙·一线天光、丙·字境、丁·灵台，各含桌面 1600×900 与手机 390×844 帧，并对照现行线上画面。
评分锚点：1 = 比现行线上画面更差；3 = 合格但记不住；5 = 能在最好的艺术向网页游戏里被人记住。

## 先说基线

现行线上画面本质是一张“卡片仪表盘”：深蓝底、圆角卡片层层堆叠，内容是“状态回执 / accepted / prologue-v1-candidate”这类工程语言。导航条悬在页面中段，“跳到主要内容”链接压在正文上，手机端同样被它遮挡。背景里那张雾中牌坊被卡片完全盖死。它几乎没有画面，所以四个方向轻易就能超过它。下面的分数不要因此虚高：超过基线只说明这一版不是仪表盘，离“惊艳”还远。

所有帧的共同问题：
1. 没有一帧画出真实回合的完整形态，即三到五句叙述、需要澄清时的追问、状态增量（体力 95→92、线索 无→落石线索）。四个方向都只画了“第一眼”，没有画“读完、写完、等结果、看结果”这条链。文字 RPG 的主战场恰恰在这里。
2. 四帧都在“画一张海报”，没有一帧回答“第 40 回合时这个屏幕长什么样”。
3. 酉初（17:00）是日落点。四帧里只有乙认真处理了这个时刻；丙完全没有时间，丁也没有。

## 甲 · 九霄长卷

### 反例：模板感、借用与空心

- **这是“仙侠古风”最先会想到的那张图。** 青绿远山、斜入老松、雾带、一叶扁舟、蓑笠人撑篙、右上竖排题跋、朱印。从网易《绘真·妙笔千山》、《江南百景图》的过场到无数国风手游的加载图，这个组合已经被反复用过。作者的原话是“平庸传统”，这个方向正好落在这四个字上。
- **名义是绢本青绿，实际是扁平矢量。** 山是带渐变的三角形，峰顶插着圣诞树式的小松；雾是横向高斯模糊带；松针是一簇簇棕榈叶状的放射线；舟子和乘客是两根“棋子”；落石是一堆棕色低多边形；鸦群是对勾符号。没有皴、擦、点、染，没有矿物颜料的颗粒和覆盖力。文中说的“颜料受光、迎光坡暖金、背光偏冷”在帧里看不到，左侧主峰从上到下就是冷青渐变。
- **去掉雾和光，构图还剩什么？** 左山、右山、中间一条水平线，中段是空的。说它是“三远”太勉强：高远的主峰只占画心约三分之一高，根本“高”不起来；所谓平远，只是把一条淡蓝山脊放到了中间。
- **只能当海报。** 题跋、印章、松框都放在画面四角，这是一张完整的、构图已经封闭的画。所谓“展卷”，在帧里没有任何体现：画面左右两端都是封死的，看不出这是一卷长画中的一段。
- **对作者参考的态度是引用，不是吸收。** 01 号图里两棵树成门，在这里变成一棵松从左边斜插进来，只剩“前景有树”这一个外形。参考图里树是活的、会聚光；这里的松没有光，也不构成门。参考里强烈的色彩命题（09 的单色橙、14 的深蓝加一道暖线），在这里被调和成一片米黄加青绿的“国风安全色”。

### 分数

| 维度 | 分 | 证据 |
|---|---|---|
| 原创性／辨识度 | 2 | 青绿 + 松框 + 孤舟 + 竖排题跋，是这一品类的默认画面，换个游戏名同样成立 |
| 构图与叙事 | 3 | 舟→泥金虚线→落石的叙事方向清楚；但中段空，主峰不够高，画面四角都被元素占住 |
| 空间与尺度 | 3 | 人物够小；但山也小，像盆景，天地的大没有出来 |
| 材质与光 | 2 | 自称“颜料受光”，帧里是矢量渐变；太阳只是中景后一枚半圆 |
| 动态与声音潜力 | 3 | 展卷、时辰光扫过、“探索即上色”都可行，但本质还是视差卷轴 |
| 字体与阅读 | 3 | 竖排题跋的位置是对的；正文用的是普通宋体，标题是常见的毛笔字库，天头地头是深蓝色的网页导航条，和“装裱”无关 |

### 帧本身的错误

- 松干正好穿过副标题“第一日”的“一”字（约 x=105–130, y=160–175）。这是一眼可见的低级碰撞。
- 左侧水面倒影是一块灰色多边形，在 x≈780 处被斜线硬切，没有过渡。
- 渡口栈桥是一排黑色梳齿，泥金虚线终点落在栈桥上，没有落到落石上。规则解析出的目标是落石，画面却指向了别处。
- 手机帧**完全没有落石和鸦群**。本局的核心障碍在手机端消失了，而作者调查里有 75% 的玩家用手机。
- 手机帧里“芦花渡”标题直接压在山体上，山被挤到左侧，右半屏只有题跋。
- 天头和地头是深蓝色的网页栏，与米黄画心之间有一条细金线。这是“网页里嵌了一张画”，不是“装裱”。真正的装裱应有天头、隔水、惊燕带、轴头，并带有绫绢的质地。

### 最能提升的一处修改

彻底抛弃矢量形状，改用真正的笔墨与颜料材质（皴擦点染的笔触资产、石青石绿的颗粒与覆色，以及绢丝的透光）。否则不论加多少光效，它都是一款国风手游。

## 乙 · 一线天光

### 反例：模板感、借用与空心

- **最直接的借用。** 天海一分、地平线居中偏下、一条极细的暖色光刃，几乎就是杉本博司《海景》系列加作者参考图 14 的直译。左上字距拉开的标签块、右侧竖排小字、居中字幕，则是苹果产品页和 macOS 壁纸的语言。这一切“高级”是现成的，并不是为《九霄》发明的。
- **它在讲一个错误的地点。** 芦花渡是一条向东的河上的渡口，叙述写着“船底擦过沙洲，芦花没到膝”。帧里却是开阔海面，看不到一根芦苇；“落石堵住渡槽”被画成了远处海平线上的一座小岛。为了迁就参考图，它牺牲了真实的游戏事实。这是四个方向里最严重的事实背离。
- **去掉光效还剩什么？** 一张蓝紫渐变加一条线。它的构图之所以成立，靠的是极简本身：三分法放舟，光源偏右，留白很大。它确实能成立，但信息量太薄。连续十个地点都用“色场加一条线”，第三个地点起玩家就会觉得这是同一张壁纸换了颜色。
- **对作者参考的态度。** 作者偏好的“场 + 单光 + 小人”和“强色彩命题”，它是四个方向里命中最准的。但作者参考里同样重要的“门与框”和“活着的树”，它一样也没有；“人间烟火”（02 号灯笼树、07 号花田）它也没有。它只吸收了作者品味中最冷、最像海报的那一半。

### 分数

| 维度 | 分 | 证据 |
|---|---|---|
| 原创性／辨识度 | 2 | 杉本博司 + 苹果壁纸 + 参考图 14 直译，好看是借来的 |
| 构图与叙事 | 4 | 舟在左三分线，光在右，字幕、输入线、地平线三条水平线形成秩序；输入线即“第二条地平线”是真正的构图思想 |
| 空间与尺度 | 4 | 天占六成，人极小，尺度感最强；但这是海的尺度，不是渡口的尺度 |
| 材质与光 | 3 | 单一光源的逻辑正确；但水面是扫描线纹理，天空是均匀渐变，月亮有明显瑕疵 |
| 动态与声音潜力 | 4 | “镜头语法由事件类型决定”（观察推近、移动横移、交谈正反打、修炼延时）是四个方向里唯一一套能接到规则回执上的动态系统 |
| 字体与阅读 | 4 | 层级最清楚，手机帧最好读；但右侧竖排钩子和底部“体 92 灵 100”字号太小、对比太低 |

### 帧本身的错误

- 月亮是用一个比天空更黑的圆盖在亮盘上画出来的，黑圆在深蓝天上清晰可见（约 x=310–332, y=150–172）。而且月牙的亮面朝左下，太阳却在右侧地平线下方。娥眉月的亮边应该朝向太阳，这里方向画反了。
- 左侧陆地在 x≈448 处被垂直切断，像一块贴片。
- 地平线是一条贯穿全宽、亮度均匀的橙线。真实的余晖只集中在太阳方位，两侧应迅速衰减。设计说明里写了这一点，但帧没有做到。
- 鸦群站在一座“岛”上，落石的体量和门板高的巨石完全对不上。
- 酉初正是日落时分，帧里却已有星和高悬的月，天色像日落后四十分钟的蓝调时刻。

### 最能提升的一处修改

把地点画对：让芦苇的剪影成为前景的“门”，逆着那道光刃；让落石成为近景里一团压住河道的暗块；让河道有两岸。这样一改，它就从杉本博司的引用变成了“芦花渡”，同时补上了作者参考里缺失的“框”。

## 丙 · 字境

### 反例：模板感、借用与空心

- **最接近已有作品。** 用“山、石、岭、峰”等字堆出山，用“水”字排成水，这正是徐冰《文字写生》（Landscripts）的方法；整个世界由字构成、玩家的字能改变世界，国产独立游戏《文字游戏》（Word Game）已经做成了一款完整的游戏。“文字即规则”的玩法，《Baba Is You》也早有先例。如果作者没有看过这些作品，这个方向会显得非常新；看过的人会立刻认出来。
- **帧里的字山是“词云”。** 一种字体，同一字号范围，随机挑字，堆进一个三角形轮廓。这种做法是数据可视化和生成艺术里最廉价的手法，和书法毫无关系。一个以文字为主体的方向，却在字体上最不讲究：没有笔势，没有浓淡，没有书体变化。
- **没有光，也没有色彩命题。** 整张图是均匀的米色宣纸，唯一的颜色是朱砂虚线。作者的参考里没有一张是这种“无光的平面”。酉初的夕照完全缺席。
- **去掉文字飞行效果还剩什么？** 剩一张排版练习。它只在“正在发生的那一秒”成立，静止时既不是好画，也不是好读的页面。
- **但它握着四个方向里唯一一个真正属于这款游戏的想法：** 玩家写下的句子沿着弧线飞向规则解析出的真实目标，并在那里落定。这把“确定性解析器”这一工程事实变成了可见的诗意。对照调查中 62.5% 的玩家最想要“把我的话变成行动”，这是全包最有价值的一个交互母题。

### 分数

| 维度 | 分 | 证据 |
|---|---|---|
| 原创性／辨识度 | 3 | 母题有先例（徐冰、《文字游戏》），但“字飞向解析目标”是本游戏独有的 |
| 构图与叙事 | 2 | 左山右石，中间是一句巨大的灰色背景字，没有焦点；“舟”字成了画面里最大的物体 |
| 空间与尺度 | 2 | 只靠透明度做出前后，没有深度；舟比山还显眼，尺度关系是反的 |
| 材质与光 | 2 | 宣纸纹理尚可；无光、无时间、无色彩命题 |
| 动态与声音潜力 | 4 | 字飞、字裂、字沉积成地层、字重组成境界名，都是可以真正落地的动态语法 |
| 字体与阅读 | 2 | 同一句话画了两遍（背景大字 + 下方小宋体）；石堆是无法辨认的叠印；弧线上的字倒序排列 |

### 帧本身的错误

- 背景的大号行书“渡口那边本该有船”和紧挨着它的小号无衬线“渡口那边本该有船。”内容完全重复，互相削弱。
- 弧线上的字从输入端开始依次是“石头、堆、那、看、看、口、渡、去”。顺着飞行方向读是倒的，玩家要倒着读才能读出自己写的话。手机端尤为明显。
- “舟”字上方的两个“人”字悬在空中，和舟没有关系，像是排版漏了对齐。
- 落石处的“石”字叠成一团黑块，完全不可读。如果它本意是“堆”，也应该靠字的大小与重心做出堆叠感，而不是靠重叠。
- 底部说明文字“言出，法随：这句话正在落向它指向的地方”是在向评审解释设计。一个能成立的画面不需要旁白来解释自己。
- 水是一排排均匀分布的“水”“波”，像壁纸花纹，近疏远密的设计在帧里看不出来。

### 最能提升的一处修改

让光来决定墨色：用 `gameMinute` 驱动整张纸的明暗和墨的浓淡，让字山的笔画粗细、字号和墨色随光向变化，塑出体积；朱砂只留给玩家写下的字。这样它才会有光、有体积、有色彩命题，而不再是一张词云。

## 丁 · 灵台

### 反例：模板感、借用与空心

- **这是近五年最常见的生成艺术演示。** 卷曲噪声流场是 Processing 和 Art Blocks 的入门题，在 Tyler Hobbs《Fidenza》之后泛滥成灾；风场、洋流可视化（NASA《Perpetual Ocean》、earth.nullschool）早就是这个样子；中间那颗带黑洞心的金色漩涡，则让人直接想到《星际穿越》的卡冈图雅和《星月夜》。它“像艺术”，但不像《九霄》。
- **去掉发光效果还剩什么？** 一张等高线图加一个靶心。构图是正中央一个大圆，几乎没有设计可言。
- **没有地点，没有人，也没有尺度。** 芦花渡、望气台、折桂坪画成流场后会长得差不多。作者参考里的门、树、人间烟火，在这里一样都没有。
- **它是一个系统层，不是一个世界观。** 方向自身的风险评估也承认了这一点。

### 分数

| 维度 | 分 | 证据 |
|---|---|---|
| 原创性／辨识度 | 2 | 生成艺术的通用样式，换任何“能量／意识”题材都能成立 |
| 构图与叙事 | 3 | 金核、蓝河、红结三者关系清楚，叙事上读得出“河被石堵住”；但靶心式居中构图很平 |
| 空间与尺度 | 2 | 没有上下，没有地平线，也没有人，无法判断大小 |
| 材质与光 | 3 | 线密度和发光质感是四帧里技术完成度最高的；但这是“霓虹线”的通用质感 |
| 动态与声音潜力 | 4 | 4 秒吸、6 秒呼的呼吸交互，以及境界即物态（气→液→晶→生命→法域），潜力确实很强 |
| 字体与阅读 | 2 | 所有标签都被流线穿过，“岑九”几乎看不见，“落石·堵住渡槽”读不清 |

### 帧本身的错误

- “岑九”的标签和光点压在金色流线的边缘，字被线穿过，几乎消失（约 x=860–910, y=430–450）。
- “落石·堵住渡槽”的标签在红蓝流线交汇处，可读性为零。
- 代表修为的“周天”刻度圈只是一条 1px 的暗线，修为 0 的“空”根本无法被读出来。
- 红色湍流的形状偶然像字母“ON”，或像一张侧脸，这是噪声没有被设计约束的结果。
- 手机帧的金核碎成一团乱线，河、石、核三者的关系完全散了。

### 最能提升的一处修改

把它降为“开神识”的系统层：在真实场景上按住屏幕，才把世界翻成流场，松开即回到场景。只在观察和修炼时出现，不承担整个世界。

## 排名

1. **乙 · 一线天光**：构图、尺度和手机可读性最好；“输入线即地平线”和“事件类型决定镜头”是两个能真正接到规则上的想法。问题在于借用太直接，并且画错了地点。这两点都可以修正。
2. **丙 · 字境**：帧最弱，但握着全包唯一一个属于这款游戏的交互母题。
3. **甲 · 九霄长卷**：完成度看似最高，其实最平庸，正好是作者明确拒绝的“传统”。
4. **丁 · 灵台**：只适合当系统层。

## 主身份：乙，并只嫁接一个想法

**主身份选乙。** 理由：
- 作者参考里最稳定的语法是“场 + 单光 + 小人”和“一线光”，乙是唯一把它变成界面结构的方向：地平线、字幕线、输入线三线同构。
- 75% 的玩家在手机上，乙的手机帧是四帧里唯一不需要妥协的。
- 它的动态系统可以由规则回执驱动，而不是由 AI 发挥。
- 前提是两条硬要求：一、地点必须画真，河、芦苇、两岸、近景落石，用真实的地形取代海景引用；二、必须补上“门与框”。每个地点都要有一个近景框（芦苇、树、牌坊、石柱），而光从框里穿过。没有这两条，它就是一张苹果壁纸。

**嫁接（严格限制，只取这些）：**
- **丙的“字沿光飞向目标”，作为全产品的签名交互。** 玩家写下的句子从输入线升起，沿着那道光刃飞向规则解析出的目标剪影，落定后目标发生变化。这一个动作就把乙的“光”和丙的“言出法随”合成一个只属于《九霄》的时刻。丙的其余部分，包括字山、字水、字地层，一律不要。
- **丁的“境界即物态”，只留给修炼场景**，并且要等突破规则签署之后才做。它绝不能出现在地点画面里，也不能去暗示尚未实现的功能。
- **甲：什么都不嫁接。** “落印提交”和“墨未干”看上去很巧，但会把整个产品拉回古风模板。如果需要一个“未落定”状态，用乙的语言来表达就够了：光线没有走完，字停在半空。

**直接否决：甲。** 它正是作者已经否定过的“平庸传统”，资产成本又是四个方向里最高的（每个地点要一段画）。而且它的问题不在执行，在方向本身：无论画得多好，最好的结果也只是“画得很好的国风手游”。丁不完全否决，只因为它可以作为系统层保留。
