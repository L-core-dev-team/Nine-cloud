# 望气台新版 第二轮独立评审

## 1. 辨识度与艺术水准
- 对比基线：基线是面板堆叠的调试页（`observe.result…obstacle_rockslide` 直接外露，吸顶导航压住“当前地点”正文，“跳到主要内容”浮在内容上）。新版只用一屏场景、一段叙述、一行输入，克制、可信，跨了一个档次。
- 对比一般仙侠网页游戏（金边、祥云、立绘）：新版因为克制而有辨识度，但并不“仙侠”。画面是一片通用的湖面日落，没有画出“望气”的气，也没有国风笔触；把字换掉，就是《Firewatch》或《Alto's Odyssey》的配色剪影。
- 最接近的作品：《Kentucky Route Zero》（剪影加引线标注）、《Heaven's Vault》（词语是可操作对象）、《文字游戏》（字变成物）、《80 Days》（叙述加代价签）。
- 天空完成度高。地面仍是占位：折线、平涂、椭圆水洼，芦苇是程序画的线。关键物（落石、鸦群）在 1600 宽的画面里只占约 200×60 像素，画面六成是没有信息的水和天。

## 2. 回合链是否讲清
- 读和结果讲清楚了：右侧小账本“过一刻 05:15→05:30／体力 95→92／得 落石线索”与真实增量一致，细察后为 92→86，得鸦群线索，也一致。
- 写：输入线加建议签可用。
- 等待讲不清：按钮叫“落定”，状态叫“未落定”，同一个词既当动作又当状态。flight 帧里“落定”是灰的（3.0:1），玩家分不清是已经提交在等，还是还要再按一次。
- 追问（clarify）有缺口：只给“先下到芦花渡”“就在台上细看落石”二选一，没有“依次都做”和“改写”。第二项悄悄丢掉了“去渡口”。
- 新界面里看不到任务目标（清落石、通渡）和线索清单。线索拿到以后就无处可查，目标只在夜帧以“通渡 未完成”的形式出现过一次。

## 3. 手机
- result-phone 能读、能玩：叙述约 17px，一屏放得下，不用滚动。
- 问题：建议签丢了代价（桌面版有“一刻 体力−6”）；签高约 33px，低于 44px。
- 键盘态保住了目标词“落石”和解析预览“细察 落石 一刻 体力−6”。但叙述与预览之间空了约 200px，场景却被压到约 130px；状态行此时可以先收起。

## 4. 具体错误
1. 弧线压字：
   - flight 桌面帧：穿过“上一回合已收进今日长线”（约 175,731）和预览里的“一刻”（约 160,806）。
   - clarify 帧：穿过“先做哪一件”（约 250,641）和第二个选项框的左边。
   - 手机键盘帧：穿过“灰羽鸦在石上”（约 115,247）和预览里的“一刻”。
2. 同为 05:30，光照不一致：result 帧是满天橙色；flight／clarify 帧是深蓝天，高空还挂着一个圆盘。若圆盘是太阳，05:30 不该这么高；若是月亮，没有交代。
3. 画面与事实不符：
   - 标注写“灰羽鸦 几十只”，放大后石上只有 3 到 4 个鸟形。
   - “渡船”标注（flight 988,546、手机 160,375、夜帧）指向空地，没有画船。
   - 落石摆在岸边的芦苇里，看不出堵住了什么渡槽口。
   - 视点贴近水面，不是“俯瞰”。
4. 夜帧：
   - 天顶是棕红、近地平线反而更暗，渐变倒置。
   - 落石、芦花渡、渡船三处标注悬在纯黑上，引线指向虚空；灰羽鸦标注消失，叙述却没说鸦群飞走了。
   - 体力 86 从 05:45 一直不变到 17:15，经过 11.5 小时却没有动作，按现有规则到不了这个状态。
   - 账本显示的是状态，不是增量。
5. 暗示了未实现的功能：
   - 虚线下划线“可摘取为证物”，事实里没有证物系统，界面上也没有说明。
   - “今日长线可随时回看”，找不到入口。
   - “走礁石小径 两刻 体力−15”必须来自规则引擎，不能是估算。
6. 对比度：
   - 签上的代价文字约 3.6:1，字号约 11px，未达 AA。
   - “未落定”峰值约 4.5:1，小字的实际观感更低。
   - flight 帧里“上一回合…”一行偏暗。
7. 标点：“先做哪一件?”用了半角问号，应为“？”。
8. flight、clarify、夜帧左右两侧的黑竖条（树干）看起来像渲染的边框；到 12:00 又变成米白色。

## 5. 时间条
- 好的时刻：
  - 05:30 最好，地平线有橙光，水面有倒影。
  - 05:00 的深红很有冲击力，但偏“失火”。
  - 17:00 的暖褐可以用。
- 失败的时刻：
  - 08:00、12:00、16:00 都是深海军蓝，地面全黑，比黎明还暗，白天读成了夜晚。原因可能是曝光或色调映射按晨昏固定、没有随太阳高度调整（推测）；另一个原因是地面不受光，只有芦苇描了白边。
  - 17:15 的渐变倒置（同第 4 节第 4 条）。
- 其他：条带上没有标时刻，第 8 格空着。

## 6. 三条修改（按优先级）
1. 把回合语义做实：
   - 提交按钮与状态用不同的词（例如“落笔”和“待结算／已结算”）。
   - clarify 增加“依次都做”和“改写”。
   - 证物下划线和“长线回看”，要么实现，要么删掉。
   - 常驻一行目标，并加上可展开的线索清单。
2. 让画面服从事实：
   - 换成俯视构图，画出渡槽口被石堵住、搁浅的船、成片的鸦群。
   - 只给已经画出来的物体加标注；夜里标注改为“记得的位置”样式，或者隐藏。
   - 同一游戏分钟只用一套光照；修好白天曝光，修正倒置渐变。
3. 手机与无障碍：
   - 弧线避开文字区，或在文字后面断开；减少动态效果时改为直接高亮。
   - 小字对比度 ≥4.5:1。
   - 签高 ≥44px，手机上保留代价。
   - 键盘态把空白让给场景。
