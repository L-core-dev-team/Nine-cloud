## 二、修订后新出现的矛盾

1. **忆帧混合了两条互斥分支。** `ui-yi` 的长线在 05:15 标的是“移动”，缩略图却是“岑九 05:15”，人物栏也列了岑九。03:31 已规定交谈是另一条分支。
2. **“谈”标签违反入口规则。** `ui-you`、`ui-du` 在望气台，叙述写着“台上没有人”，仍显示“谈”标签。这违反 07:101，原因是 `ui.html:77` 无条件列出全部标签。
3. **05:15 仍在剧透。** `ui-tan` 撤掉了证物签，但任务行仍写“渡槽口被落石堵住”，建议签仍有“问鸦”“求他搬石头”，而落石与鸦要到 05:30 才获得。画面里有两轮问答，却只标“一刻”。

## 三、仍然最严重的问题

1. **推荐管线的成品样子没有展示。** 三张 CC0 帧里，远景是荒漠，鸦是浮在水上的蛋形，芦苇像纸条，岑九是锥体。界面帧和 README 首图用的全是被本方案否决的 AI 画面。
2. **门禁几乎提供不了证据。** 交谈帧的失败恰恰是落石被画成“坐着的人”，G3 对“a person sitting”只给出 0.001，判为通过；G2 则 12 帧全过。
3. **G-buffer 的改动没有贯穿全文。** 预算、R2 交付范围和 07 的打光说法仍是旧口径，方案无法据此执行。
4. **境界顺序悬而未决，神识支柱却已默认了一种顺序。**
5. **帧图仍违反方案自己的可见性与状态规则**（见第二节）。

## 四、总体判断

还没有形成一份内部一致、可执行、有明确主张的推荐。主张本身已经清楚：几何保证事实，AI 只做受控增强。但它只在 09 和 README 里成立，01、03、07、08、11 和界面帧仍按旧方案运转。

**仍交给作者、但本该由创作者决定的事：**

- 美术方向靠“作者盲选”来定（X1、X3），植被、人物、鸦的套件风格没有规格；
- NPC 的画法未定（02:75）；
- 线索名称（D7）没有给出提案；
- 建议签何时可见只裁了一条，没有通用规则；
- 03 §17 循环里的事件和证物推理的判定没有设计；
- 没有写出选项乙之下神识表怎样改。

境界顺序与 Canon 的空白确实属于作者的权限。
