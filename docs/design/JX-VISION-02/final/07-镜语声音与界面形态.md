# 07 · 镜语、声音与界面形态

## 1. 虚拟导演（支柱 3）

**定位**：导演层位于“权威结算”之后、“画面与声音”之前。它决定**怎样表现**一件已经发生的事，绝不改变**发生了什么**。

```
权威事件 + 可见性视图 ─▶ SceneSpec（场景：有什么、在哪里、什么光）
                         │
                         ▼
          Director(spec, event, prefs, seed) ─▶ DirectorPlan
                         │                         { mode, shots[], grade, audioCues[], uiCues[], durationCap }
                         ▼
                 渲染器 / 音频 / DOM 依计划执行，可随时跳过
```

### 1.1 输入与输出

| 名称 | 内容 |
|---|---|
| `SceneSpec` | 地点、地理锚点（`fact`、`ambient`、`omen` 三类）、光（太阳与月亮方向、天气、调色）、可用的机位族、文字安全区 |
| `event` | 最近一次结算的事件类型与 `stateDelta` |
| `prefs` | 玩家偏好：默认形态、减少动态效果、镜头时长倍率、是否允许 AI 导演 |
| `DirectorPlan` | 界面形态、镜头序列（机位族、景别、一个运动轴、时长）、调色、音频提示、界面提示、总时长上限 |

### 1.2 规则优先，AI 受控

- **默认是纯规则**：事件类型 → 镜头族（下表）；同一族内的变体用 `seed = H(存档, 回合号)` 选，可以回放。
- **AI 导演（可选，默认关闭，排在 R5；评审认为它在近期收益很小，同意延后）**：AI 只能对规则给出的候选镜头**排序或从中选择**，输出是一个候选的编号。校验器检查：
  - 必入画锚点仍在视口内；
  - 时长不超过上限；
  - 没有指向非 `fact` 的元素。

  任何一项不通过，就回落到规则结果。AI 永远不能生成新的事实、新的镜头目标或新的文字。

| 事件 | 镜头族 | 时长上限 |
|---|---|---|
| 环视 | 远望；同机位，长焦慢推 | 1.0 s |
| 细察 | 微距；浅景深 | 1.0 s |
| 移动 | 相机沿真实地理过渡，一镜一轴 | 1.2 s（跨尺度 1.6 s） |
| 交谈 | 两人景；说话的人受光 | 0.5 s |
| 战斗 | 2–4 拍快切 | 每拍 0.25 s |
| 修炼 | 延时 | 消耗刻数 × 0.3 s，≤ 2 s |
| 到达新地点 | 障—框—借三拍 | 2.4 s，可跳过 |
| 天黑、规则拒绝 | 不动镜头，只变光 | 0 |

### 1.3 机位族（每个地点都要有）

| 族 | 说明 | 本轮渲染的样例 |
|---|---|---|
| 远 | 远望、俯瞰 | 望气台台上远望、首屏俯瞰 |
| 中 | 平视的主要地点 | 渡口岸上 |
| 近 | 人物、两人景 | 交谈 |
| 微 | 微距、物件 | 石缝鸦巢 |

机位存在 `PlaceCameras` 表里，由地理数据自动生成初始值，再由美术人工调整。所有机位都要通过“必入画”和“文字安全区”的自动检查（见 11 的 X2）。

## 2. 光与调色

- **物理层**：太阳、月亮、天空由天文与天气决定（04）；在画板上用“时刻关键帧烘焙加插值”实现重新打光（09 §3）。
- **调色层**：每个地域的“色彩命题”（01 §2）作为单独的调色参数，例如暗部偏冷、亮部偏暖的程度；夜间单独有一套。调色只改色调，不移动光源。
- **事件调色**：只用于短时的情绪强调：撤退时去饱和 0.4 s；回忆时加颗粒、降饱和。开启“减少动态效果”时没有渐变。

## 3. 声音（支柱 3 的一部分）

依据：技术研究 §7。具体方法：

| 层 | 内容 | 技术 |
|---|---|---|
| 环境床 | 水、风、芦苇、远处的人声，随地点与时辰混音 | AudioWorklet 合成：风是滤波噪声加阵风包络；水是多层带通噪声；雨是颗粒合成。不用采样包，体积小，可以无限变化 |
| 点声源 | 鸦群、桨声（“远处有桨声。一下，又一下。”）、脚步、篙点水 | 短采样或合成；少数点声源用 HRTF 声像 |
| 空间 | 室内与崖壁的混响 | ConvolverNode 加短冲激响应 |
| 音乐 | 按地域与境界垂直分层（加减声部），按事件水平切段 | 分轨的循环片段；事件切换只在小节线上 |
| 静默 | 东瀚的无声雾、天劫前的一刻、入暮 | 有意的减法：环境床在 2 s 内退到只剩低频 |

**规则**：

- 默认静音；首次点击“入世”时才创建音频上下文。
- 环境、音乐、提示音三路独立音量。
- 一切有意义的声音都有文字或视觉的对应，例如“桨声”同时写在叙述里。静音时游戏照样可玩。
- iOS 的静音键与各种 WebView 的音频策略差异很大，必须在真机上验证（11 的 X8）。

## 4. 七种界面形态

七种形态共用同一份游戏状态、同一套解析与提交状态机、同一套 API。区别只在于画面与文字的比重和布局。

| 形态 | 何时 | 画面 | 文字 | 本轮帧图 |
|---|---|---|---|---|
| **游**（探索） | 默认；移动与观察 | 满幅天光画面 | 左下的书页安全区 | `frames/ui-you.webp` |
| **读**（卷宗） | 长叙述、回看；也可以设为默认 | 只剩页眉的一条天光 | 满幅书页 | `frames/ui-du.webp` |
| **谈**（人物） | 交谈 | 两人景 | 对话，说话人用自己的书体 | `frames/ui-tan.webp` |
| **斗** | 战斗 | 快切 | 结果与代价 | `frames/ui-dou.webp` |
| **观**（神识、修炼、阵法） | 修炼、使用神识 | 场的图像叠在画面上 | 读数与说明 | `frames/shenshi-tiers.webp` |
| **图**（万象） | 地图（R4） | 多尺度天图 | 地名与路线 | `frames/atlas.webp` |
| **忆**（一世浮生） | 历史、存档 | 卷宗与长卷 | 年谱 | `frames/ui-yi.webp` |

**入口规则**（按评审 A 更正）：

- 右上角的形态标签只列**玩家可以主动进入**的形态：
  - 游、读、忆：始终可用；
  - 谈：有人在场时可用；
  - 观：修炼规则已有，所以可用。炼体期的“观”只显示修炼的延时与身体感觉，不显示任何灵气层。
- “斗”由事件进入，不设标签。
- “图”在地图实现之前不出现任何入口（裁决 7）。
- 由导演按事件自动切换，玩家可以固定偏好。

**手机与桌面不用同一种结构**：

| 设备 | 结构 |
|---|---|
| 手机竖屏 | 画面在上，占 40–56%，书页在下；建议签可以横滑；键盘弹起时画面收成一条，只留目标物与解析预览 |
| 桌面 | 画面满幅，书页在左下的安全区；宽屏时，书页可以停靠在侧边 |

## 5. 无障碍（贯穿全部形态）

| 项 | 规定 |
|---|---|
| 语义 | 所有可读文字都是 DOM；画布标记为 `aria-hidden`；`altText` 由 SceneSpec 用模板生成，零模型 |
| 播报 | 每回合只播报一次结果（`aria-live=polite`）；提交后焦点留在输入行 |
| 对比度 | 文字框下的背景按每个时刻采样：小字 ≥ 4.5:1，大字 ≥ 3:1；不达标时由程序在文字下方局部压暗。本轮 8 个界面帧的实测见 13 §4（最低 4.82:1） |
| 目标尺寸 | 可点的区域 ≥ 44×44 px，包括画中的锚点 |
| 动效 | 开启 `prefers-reduced-motion` 时，没有视差、没有镜头运动，天空为静帧，按钮尺寸不变 |
| 声音 | 见 §3 |
| 缩放 | 200% 时可以重排 |

## 6. 帧率口径（统一上一轮的冲突）

| 情境 | 目标 |
|---|---|
| 空闲 | 0 fps（按需渲染） |
| 环境动画（水、云、芦苇） | 上限 30 fps |
| 交互、转场、言落 | 以 60 fps 为目标；中端安卓上 p95 ≥ 55 fps |
| 自动降档 | 连续 10 秒 p95 帧时 > 33 ms 时自动降一档；`visibilitychange` 时暂停 |
| DPR | 上限 1.5；T3 档可以到 2 |

上一轮写的“手机 30 fps 上限”指的是环境动画，“50–55 fps”指的是转场。两者本来不冲突，只是没有说清楚，这里统一口径。
