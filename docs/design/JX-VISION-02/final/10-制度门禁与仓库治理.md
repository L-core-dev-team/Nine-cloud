## 4. 哈希锁定文件的升级流程

适用于 P1 执行规格、P1-MAP、原创输入登记，以及另外 7 份规则包文件。

1. **原文件不动**。新内容写成新版本文件，例如 `…-v2.md`。
2. 生成新摘要，更新 `canon.registry` 或 `p1-rule-candidate-bundle.files.json` 中**对应的新条目**；旧条目保留。
3. **批准**：
   - 语义变更由原签署人批准；
   - 是否恢复“双作者签收”，取决于作者对 2026-11-07 决定的裁定，见 [12](12-风险成本与待授权.md)。
4. **测试同步**：
   - 新摘要的断言与新版本同一提交进入；
   - 旧摘要的回归测试保留，保证旧存档按旧版本回放。

**新发现的耦合**：`canon.registry.json` 在 P1 包的摘要清单里，所以 Canon 登记表每新增一条，都会让 P1 测试失败。本方案建议 P1 只钉住它实际使用的 Canon 切片，这需要作者裁定。

## 5. 新 CI：检查真正重要的东西

八类，每类都有可以直接实现的方法，详见 [appendix/governance.md](appendix/governance.md) §5。

| 类 | 核心检查 |
|---|---|
| 数据、规则、存档 | 存档黄金样本往返；事件回放的状态哈希；性质测试；契约快照；**画面 ⊆ 事实**；Canon 越权 |
| 安全与隐私 | gitleaks、依赖审计、发布物泄漏扫描（本机路径、私有原图、PII）、测试数据库隔离、响应头 |
| 资产权利与 AIGC | 全类型媒体清单（包括 `.ktx2`、`.glb`、着色器）；AIGC 隐式元数据；显式标识；字体许可；私有参考素材的拒绝表；**AI 资产的事实保持检查**（09 §4） |
| 无障碍 | axe、键盘、**按时刻采样的对比度**、减少动态效果与强制颜色、触控目标、读屏 |
| 渲染与降级 | WebGL2、软件渲染、无 WebGL 三种配置都跑完一回合；控制台零错误；上下文丢失后恢复；确定性截图 |
| 新视觉回归 | 版本化截图基线，只在新设计获批后建立；更新基线必须附批准记录 |
| 证据可靠性 | 写“PASS”就必须有 CI run 或 SHA；历史证据只增不改；锁定文件守卫 |
| 文档治理 | 离线链接检查；禁止分支 blob URL；效力与登记表一致；入口文件的体积上限 |

**性能是报告，不是门槛**：只有最低画质档设硬阈值（不得阻塞输入），高画质档只报告。这对应作者“设计和前端艺术质量优先于单一性能指标”的要求。
