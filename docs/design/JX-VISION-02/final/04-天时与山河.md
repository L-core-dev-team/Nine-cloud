# 04 · 天时与山河：天文、自然、演化与多尺度地图

## 1. 九霄历与标准时（候选扩展）

| 概念 | 定义 | 依据 |
|---|---|---|
| 九霄标准时 | 以天衍城观星台所在子午线的平太阳时为准 | 衍天宗“观星台”“周天星斗”（Canon 113、121、135 行）；“钦天监负责观测天象”（Canon 18 行） |
| 地方视时 | 地方视时 = 标准时 + 经度差 / 15°（时差方程 ≤ 16 分钟，第一版忽略） | 球面天文 |
| 一日 | 1440 游戏分钟 = 96 刻，1 刻 = 15 分钟；十二时辰各分初、正 | 兼容基线（`DAY_KEC_COUNT: 96`） |
| 一年 | 365.2422 日；以太阳黄经每 15° 为一个节气，共二十四节气 | 球面天文；节气名为公共文化 |

**序章兼容**：

- 规则写死了 05:00 开局（`SAVE_START_GAME_MINUTE: 300`）和 17:00 入暗（`DUSK_START_KEC: 48`）。规则自检会拒绝修改这两个常量。
- 本方案的解释是：芦花渡位于北纬 30°，在标准子午线以东 15°，序章发生在秋分前后（太阳赤纬 ≈ 0）。于是：
  - 地方视时比标准时早 1 小时；
  - 日出 ≈ 标准时 05:00，正午 ≈ 11:00，日落 ≈ 17:00。
- 这与规则完全一致，又与芦花“今年开得晚”的秋季吻合（芦苇在秋季开花）。
- 这只是**一个地点、一个季节**的结果，不是全局规则。其他地域与季节由下面的公式另算。

## 2. 日、月、星的计算（真实科学，低精度）

**太阳**（本轮渲染使用的实现见 [lab/astro.py](lab/astro.py)）：

- 黄经 λ ≈ 2π(d − 80)/365.2422（d 为年内日序；精度约 2°，用于画面足够）
- 赤纬 δ = asin(sin ε · sin λ)，ε = 23.44°（实现里用的是 δ ≈ ε·sin λ 的简化，在需要时改为精确式）
- 时角 H = 15° × (地方视时 − 12)
- 高度 sin h = sin φ sin δ + cos φ cos δ cos H
- 方位 A = atan2(−sin H, tan δ cos φ − sin φ cos H)，从正北顺时针计
- 昼长：cos H₀ = (sin(−0.833°) − sin φ sin δ) / (cos φ cos δ)，其中 −0.833° 包含了大气折射与日面半径

**验证**：Blender 天空节点的方位约定（0 = 正北，π/2 = 正东）是本轮实测得到的；秋分、北纬 30°、经差 +15° 时，标准时 05:00 的太阳高度为 0.0°，11:00 为 60.0°，17:00 为 0.0°。

**月亮**（候选扩展：九霄有一个月亮）：

- 朔望月 29.530588 日；相位角 ψ = 2π · (自上次朔起的天数 / 29.530588)
- 被照亮的比例 k = (1 − cos ψ)/2
- 月出时刻每日约推迟 50 分钟
- 月的赤纬近似为太阳赤纬沿黄道偏移 ψ 后的值（误差可达数度，只用于画面）

**星空**：

- 不使用真实星表。HYG 星表是 CC BY-SA，派生数据要同许可公开（技术研究 §2）。
- 九霄星图按世界种子程序化生成：约 6000 颗肉眼可见星，星等服从幂律分布，色温取 3000–30000 K 映射到 RGB。
- 星座由内容作者命名，候选是与“周天星斗无极大阵”对应的“周天”星官，Canon 只写了阵法，没有写星座。

**渲染**：

- 天空用 Hillaire 2020 的四张 LUT（透射率、多次散射、天空视图、空气透视），参数照搬论文里的移动端那一列；
- LUT 只在时辰或天气变化时更新；
- 离线画板用 Blender 的 Multiple Scattering 天空，即本轮渲染所用的模型，并与网页天空做色调比对。

## 3. 气候与天气（候选扩展，规则效应须另签）

**五域气候带**，取自 Canon 的气候描述，纬度是候选值：

| 域 | 纬度（候选） | Canon 气候 | 天气状态集合（候选） |
|---|---|---|---|
| 北境霜寒域 | 55–70°N | “终年飘雪，寒气彻骨” | 雪、暴风雪、晴寒、极光夜 |
| 中州天枢域 | 30–40°N | “土地肥沃，灵气醇厚均衡” | 晴、多云、雾、小雨、大雨、雷雨；万仞崖终年罡风 |
| 东瀚龙吟域 | 22–40°N（海岸与岛） | “水汽充沛” | 海雾、晴、风暴、潮；听潮阁所在岛常年“无声雾” |
| 西荒焚天域 | 25–40°N（内陆） | “酷热干燥，灵气狂暴且蕴含火毒” | 晴热、热霾、风沙；万丈渊有九天罡风与烈阳火毒 |
| 南疆万蛊域 | 10–25°N | “原始丛林，剧毒瘴气沼泽” | 闷热、阵雨、瘴、雾 |
| 洪荒妖林 | 万兽山脉腹地 | “灵气浓郁到化为实质的雾气” | 灵雾（常态）、雨 |

**天气模型**：

- 每个地域每天的天气是一条马尔可夫链，转移矩阵按节气插值。
- 随机数来自确定性的种子：`seed = H(世界种子, 地域, 日序)`，用 xoshiro256** 的子流。
- 一天之内，按时辰对云量与雾的浓度做平滑插值。
- 同一份存档、同一天，天气永远相同，可以回放。

**规则效应**（须作者另签，在签署之前只影响表现）：

- 雾与雨降低观察的可见范围；
- 大雨使移动耗时加 1 刻；
- 天气与修炼效率的耦合见 §5。

### 6.2 候选布局（非 Canon）

Canon 只说万兽山脉“横断东西”，把人族划分为南北两部分；中州在“大陆中央腹地”；东瀚“濒临无尽东海”；冰神宫在“极北”。没有说哪几域在北、哪几域在南。

**推荐候选布局**（见 [frames/atlas.webp](frames/atlas.webp)）：

- 万兽山脉东西横贯大陆中部，洪荒妖林在山脉腹地；
- 中州在山脉以北的中央，北境在最北；
- 南疆在山脉以南；
- 西荒在大陆西侧，东瀚在东侧海岸与群岛，这两域都跨越山脉的南北两侧。

这样既满足“南北两部分”，又满足“中州居中”。**需要作者裁定。**

芦花渡的归属（候选）：中州东缘的一处河口，下游通往东瀚。“渡口分舵”“不属于四海商会”等内容与此不冲突。也需作者确认。

### 6.3 数据结构（从 R1 起预留）

```
Place   { id, scale, parentId, geo: {lat, lon, elevation}, canonRef?, visibility }
Route   { id, from, to, mode: walk|river|sea|sword|teleport, distanceLi, baseKec, requires? }
Known   { characterId, placeId, via: visited|hearsay|common, since: gameMinute, sourceEventId }
```

- **路程耗时**：由 Canon 的交通能力推导，例如筑基御剑“一日千里”（Canon 826 行）、元婴“瞬息千里”（852 行）。具体数值属于规则，待签。
- **迷雾**：按 `Known` 渲染。
  - `visited`：画出全部细节；
  - `hearsay`：听 NPC 说过，只有地名与方位，画为淡墨；
  - `common`：常识，如五域的存在，只有轮廓。
- **地图上的事件**：天劫、天象、地域事件出现在地图上；只有角色能获知的才会出现。

### 6.4 万象的转场

尺度之间的过渡，就是相机沿真实地理升降：天下 → 域 → 地 → 景，一镜一轴，用时 ≤ 1.6 s。T0 档直接切换。

## 7. 万物有时：世界演化

| 尺度 | 推进粒度 | 内容 |
|---|---|---|
| 当前场景 | 刻 | 光、云、水、NPC 位置与作息、声音 |
| 当前地域 | 时辰 | 天气、市集、事件传播 |
| 远处地域 | 日 | 宗门、商路、资源的聚合结算 |

- **事件调度**：一个以游戏时间为键的优先队列。每个事件都有 `scheduledAt`、`seedStream` 和 `preconditions`。
- **惰性补算**：玩家进入一个地域时，从它的 `lastSimulatedAt` 推进到当前时刻。补算是确定性的，可以回放。
- **事件溯源**：日志里只存“种子与输入事件”，不存派生状态；所有随机数都来自命名的子流，禁止 `Math.random`。
- **离线**：
  - 默认关闭：没有行动，游戏时间就不流逝，这与现行规则一致。
  - 可选的“世事流转”打开后，现实中每过 1 小时，世界推进 1 个时辰的**事件**，但不给收益、不造成损失、不改变玩家角色的状态；上限 7 天；玩家可以关闭。
  - 依据：不能强迫玩家挂机，也不能制造离线焦虑。
- **玩家造成的长期变化**：例如通渡之后，渡口恢复每天一趟（“通了。明早第一趟。”）。这类变化写成一条世界事实，之后的作息与画面都要读取它。
