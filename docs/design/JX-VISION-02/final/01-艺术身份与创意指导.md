# 01 · 艺术身份与创意指导

## 1. 艺术身份

**九霄的身份是“受光的山河与会记事的书页”。**

统一全作的，不是一种颜色、一种字体或一种画法，而是三条始终成立的规则：

1. **光是真的。** 每一帧的光源、方向、色温都来自权威游戏时间、地点的天文条件和天气。画面里不存在“为了好看而放的光”。如需艺术化调色，作为单独一层“调色”参数显式存在，不能伪装成物理光照。
2. **物是真的。** 画面里每一个能被点名、能被行动指向的物体，都绑定一个事实。环境装饰、未知远景和伏笔可以存在，但它们不能被误读为已知事实（见 §6）。
3. **字是你的。** 屏幕上的文字只有三种来源：规则结算、AI 叙述（明确标识）、玩家自己写下的话。三者的排印永远可以区分。

## 2. 一域一色，再加一条贯穿母题

依据：艺术研究中《羊蹄山之魂》的分区调色与贯穿母题色、《GRIS》的色彩随阶段解锁、《英雄》按色彩分章叙事（见 [appendix/research-art.md](appendix/research-art.md) 的来源 S9、S16 与《英雄》一节）。下表是候选色彩命题，不是 Canon；“材质”一栏写的是画面质感。

| 地域 | 情绪 | 主色命题 | 材质与光 | Canon 依据 |
|---|---|---|---|---|
| 序章 · 芦花渡（凡间水口） | 清寒、人间、未知 | 淤黄水色 #6E5A34、芦花白 #E8E0CF、晨昏金 #E9A85A | 湿泥、朽木、蓑衣；晨雾里的逆光芦花 | 序章内容“渡槽淤了半尺，水发黄”“芦花今年开得晚” |

**贯穿母题**：

- **天光**：地平线或画面中轴上的一线光。这是参考图 10、11、14、15 的共同规律，也是一日时间的显形。
- **朱砂**：只属于玩家写下的字，以及玩家留下的印记。

境界突破后，“修为色”会在界面上解锁，依次为石绿、石青、泥金……（候选）。它只出现在神识与修炼界面，不改动世界画面的物理光。

## 3. 媒介谱系：统一身份，不统一形式

同一个世界，按情境使用不同的媒介。依据：作者“不同地域与情境可以有完全不同的艺术语言”。

| 情境 | 媒介 | 为什么 |
|---|---|---|
| 探索、远望、到达 | **受光的山河**：三维布局加 AI 重绘的画板，实时天空、水与光 | 空间与时间的真实感（支柱 1、2） |
| 交谈、交易 | 两人取景、浅景深、人物逆光剪影到半身像 | 关系与面孔（游戏评审：岑九需要一张脸） |
| 线索与物件 | 微距特写、景深、物件的质感 | 证据的分量（摘句为证与物件对应） |
| 阅读、回忆 | **卷宗**：纸、墨、排印；回忆的画面去饱和，带颗粒 | 文学的分量，长文可读 |
| 神识、修炼、阵法 | **场的图像**：流线、等值线、网络拓扑，像科学插图，又像墨光 | 让数学成为可感知的修为（支柱 6） |
| 地图 | **万象天图**：从地球般的天下浮雕到域、地、景；未探索的区域是淡墨布局 | 多尺度世界（支柱 7） |
| 天劫、大事件 | 全电影化：广角、体积光、声音的爆发与静默 | 情感峰值 |

## 4. 构图与镜头纪律（数值规定）

依据：参考图测量（大面积色场、单一强光源、强光集中在竖向中轴 x≈0.44–0.57，人物极小）；Marshall Adams“一镜一轴”；Adams 与 Slovis 的对称与广角俯仰；园林“障—框—借”（见艺术研究第四节）。

1. **一镜一轴**：一个镜头内的相机运动只有一个自由度（推、摇、移、升降，任选其一），不准一帧跳变。转场用叠化或匹配剪辑。
2. **障—框—借三拍**：到达一个新地点时，先“障”（近景遮挡，如芦苇、台柱），再“框”（前景框出主景），最后“借”（远景入画）。望气台的台柱框景就是第二拍。
3. **强光位置**：主光源或高光区落在画面横向 0.4–0.6、纵向黄金分割线附近；文字区避开它（DOM 布局查询 SceneSpec 中的“光区”）。
4. **尺度**：远景里人物高度 ≤ 画高的 6%。交谈镜头的人物高度为画高的 35–60%。
5. **安全区**：
   - 桌面：底部 34% 与左侧 46% 留给文字与输入；
   - 手机：画面在上，占 40–56%；
   - 必入画锚点不得落入文字区。
6. **时长**：
   - 环境镜头没有时长，静止即可；
   - 事件镜头的总时长 ≤ 1.2 s；
   - 修炼延时与消耗的刻数成正比，上限 2 s；
   - 一律可以跳过；开启“减少动态效果”时，改为直接切换。

## 5. 字体与书页

- **正文**：思源宋体（Noto Serif SC，OFL）。桌面 20px，行高 1.85，每行不超过 34 字；手机 17px，行高 1.8。
- **人物话语**：每位 NPC 可以有自己的书体（例如岑九用霞鹜文楷），保证读屏和朗读时可以区分说话人。篆书、隶书不用于正文。
- **玩家的字**：用朱砂色的下划线和印记表示“这是你写的”。玩家写下的原文永不改写。
- **AI 叙述标识**：AI 叙述在书页边上有常驻的“AI 叙述”小签，导出时保留，以符合《人工智能生成合成内容标识办法》，见 [08 §7](08-全栈架构与数据契约.md)。
- **字境的用法**：只在三处让“字”成为世界的一部分：
  - 功法与阵法的道纹，如天阶功法“并非文字，而是一幅图、一段音律或是一种意境”；
  - 稷下学宫的“以言为法，以字为兵”；
  - 卷宗与人生长卷中的书法化标题。

  其他场合，字始终是好读的正文。

## 6. 伏笔与“知者可见”

作者裁决 10：允许环境伏笔，禁止剧透。可执行的规则如下：

| 允许 | 禁止 |
|---|---|
| 远景里一片说不清是云还是雪的白（例如序章南边的山脊），不标名字，不可点 | 给它标上“那片白”或任何名字，或者让它可以被点击、被选为目标，除非 `text_south_white_hook` 已经投放 |
| 一个模糊的影子、一阵不合时宜的声音、光的异常 | 在画面里出现规则未授予玩家的物品、人物身份或剧情答案 |
| 镜头在某处多停 0.3 秒 | 用镜头直接暗示答案，例如推近到隐藏的线索上 |

技术上，SceneSpec 把画面元素分为 `fact`（绑定可见事实，可以标注、可以指向）、`ambient`（环境，不可指向）、`omen`（伏笔，不可指向，由内容作者登记，并注明它不泄露的事实 ID）三类。CI 检查 `fact` 元素集合必须是可见事实集合的子集（见 [08](08-全栈架构与数据契约.md)）。

## 7. 参考作品：取什么、不取什么

详见 [appendix/research-art.md](appendix/research-art.md)。这里只列与九霄身份直接相关的结论。

| 作品 | 取 | 不取 |
|---|---|---|
| 《对马岛之魂》《羊蹄山之魂》 | 让环境引路，界面极简；分区调色；用一个母题色贯穿全作 | 武士电影的直接引用 |
| 《风之旅人》 | 三幕式的情绪弧线；无文字的情感交流 | 用沙丘的形式代替山河 |
| 《GRIS》 | 色彩随成长解锁 | 去掉叙事，只剩美术 |
| 《塞尔达》BotW、TotK | 三角法则与兴趣链：地标、遮挡、发现 | 卡通渲染 |
| 《艾尔登法环》 | 远景巨物作为地标与目标 | 阴暗的通用奇幻语汇 |
| 《黑神话：悟空》 | 用实物扫描级的材质建立东方质感 | 照搬它的神魔造型与动作 |
| 《Heaven's Vault》《Outer Wilds》 | 知识即进度，没有失败态的理解 | — |
| 《哈迪斯》、RimWorld | 按状态加权的条件台词；“讲故事者”的节律 | 刷宝式循环 |
| 《绝命毒师》《风骚律师》 | 广角加俯拍、对称、延时摄影、一镜一轴 | 当代美国的色调 |
| 《星际穿越》 | 科学可视化并记录为可读性所做的删改（DNGR 论文） | 宇宙尺度直接套用到修仙 |
| 《英雄》 | 色彩分章叙事 | 武侠写意的直接引用 |
| Immersive Garden、Lusion、Active Theory | 预计算加运行时混合，分档降级；水彩揭示 | 作品集网站的炫技节奏 |
| 中国园林、长卷 | 障—框—借，步移景异；长卷开合；淡墨布局后逐层加密 | 古画的装裱图式（上一轮已否决） |

## 8. 明确不做的事

- 不做满屏玻璃、祥云、金边和“国风模板”式装饰；
- 不在画面上放没有绑定事实的可点物件；
- 不把可读文字画进画布；
- 不用自动推进的字幕代替可以控制节奏的阅读；
- 不让 AI 生成的图像未经事实检查与许可登记就进入发布。
