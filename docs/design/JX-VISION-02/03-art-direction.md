# 六种艺术原型与原创体验方向（不限制Claude）

用户要求“不要参考原来设计”的含义：不以旧布局、材质、配色、字体、框架为出发点；仅将旧版当作被否决的基线及功能兼容证据。可以从零设计，也可以在独立论证后保留真正好的东西。不是把每一屏都做成同一种宏大海报。艺术家可以提出更好的第七、第八种。

| 原型 | 空间/材质/交互 | 适合九霄的实际玩法 |
|---|---|---|
| A 天门与万象 | 云海、层叠地形、天穹、实际相机过渡；从远山到人物 | 首页不是菜单而是进入地点，天地与行旅相接 |
| B 活的东方山水 | 2D水墨、2.5D景深、3D植被与实时光场相融 | 地点、昼夜、天气、仙凡境界随权威世界状态变化 |
| C 灵境天体剧场 | 万有引力意象、星轨、粒子场、光线折射、抽象几何 | 修为、境界突破、秘境、天劫、世界地图和因果的可视化 |
| D 电影叙事 | 大远景、低角度、色彩叙事、景别转换、声音、停顿、镜头运动 | 不同NPC对话与事件拥有不同节奏；危机、突破、休息都可不同 |
| E 可触摸的世界 | 有光学行为的数字介质、空间导航、手势反馈、深度与材质；Apple/HarmonyOS研究 | 玉简不是卡片换皮；地图、物品、档案和人物关系具有可操作结构 |
| F 文学剧场与现实人间 | 剧情文字与人物、空间、声音、地图动态协作；精美编辑设计 | 长时间读写舒服，也可以随事件进入全屏沉浸或视觉叙述 |

优先推荐（只是GPT候选）：B作为连续世界、A作为进入世界、C用于进阶和奇观、D承担故事节奏、E承担交互物件、F承担长期剧情。六种不需要全部混合；Claude要提供本质不同的完整系统再取舍。研究《绝命毒师》《风骚律师》的环境构图、色彩符号、光线、镜头语言、叙事节奏与空间的戏剧功能；游戏研究《对马岛之魂》的风与导航融合、《黑神话：悟空》的东方世界表达、《Journey》《ABZÛ》《GRIS》《艾尔登法环》的尺度和空间体验；网站研究Awwwards原站、Lusion、Active Theory、Immersive Garden等。不要将游戏或影视资源直接移植，逐项查出处与许可。

## 体验主轴，不是只改首页
开场：从世界之外进入世界；建角：身份诞生而非表单堆叠；行旅：地点和事件有真实可视反应；修炼：状态改变具备明确结果和美术仪式；地图：地理、势力、路线、未知域；人物：肖像、关系、立场与记忆（遵循权限）；物品：材质、稀有度、来历和实际功能；酒馆/群聊：不同成员说话有身份、场景和上下文，保持真实顺序；世界书：可导航百科、图谱、历史；档案：从生活事件回望角色成长；设置：真正可理解的画质预设，艺术效果不锁死在一台设备；异常/空态/恢复也有设计。

## 设计验收（后续实施用）
首眼1秒/10秒/首次游玩10分钟的真实体验；相同数据/场景的旧版和候选A/B；桌面、手机竖屏、平板、触摸、键盘；滚动、转场、软键盘、长剧情、误操作恢复；核心场景至少提供可评审画面、故事板/动效时序和可实施路径。评价原创性、构图、空间、材质、色彩、交互意义、游戏反馈、长期舒适和统一世界观。性能做分档和预算，不用FPS或LCP单独替代审美判断。避免满屏廉价发光、随机粒子、假3D、全站圆角玻璃；它们并非禁用，而是必须具有明确艺术和交互价值。
