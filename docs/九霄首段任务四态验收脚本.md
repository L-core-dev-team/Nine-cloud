# 《九霄》首段任务：正常、失败、取消、无模型四态验收脚本

本稿把[首段剧情骨架](九霄首段剧情骨架与人物边界草案.md)变成作者侧可执行的任务验收输入，不是已实装功能，也不将测试占位物品、NPC 或地点加入 Canon。`S0/S1` 是规则指定的相邻起点与可达位置，`G` 是场景内引路岗位，`I` 是规则允许取得和使用的普通物品，`O` 是可绕行、交谈或基础战斗应对的阻碍，`Q` 是首个任务。合作者须在具体规则和角色卡定稿时分配稳定 ID 与可见文案；模型不得自行创造这些 ID 或结算结果。

| 共同前提 | 作者侧要求 |
| --- | --- |
| 进入方式 | 游客／本地存档可新建角色并从 `/lobby` 进入首段任务；不要求注册、付款或先配置 AI。 |
| 原设约束 | 起点属于正式 Canon 中的一个已定义地域；如选洪荒妖林，只能把新人样例放在外围，不把核心禁区写成安全教程。角色初始境界、地点和物品由存档／规则决定。 |
| 知情边界 | G 只知道公开 Canon、在场观察及已传播事件；玩家未做出的选择、远处事件和其他存档不能成为其“记忆”。 |
| 权威顺序 | 行动意图 → 规则结算 → 事件与状态投影 → NPC 可知信息 → 剧情表达。没有事件就没有地点、境界、物品、任务或伤亡的事实变化。 |

## 1. 正常完成

1. 玩家从 S0 看见当前目标与可操作入口，选择与 G 交谈；G 指出 S1 的已开放路径，玩家可拒绝引导而自行查看地图。
2. 玩家移动到 S1。界面与存档位置同步改变，叙事只说已结算到达的地点；返回 S0 仍能回看经过。
3. 玩家执行规则允许的行动取得 I，再选择使用、保留或放弃。物品栏变化先于叙事确认；G 不在场时不得凭空知道取得过程。
4. 玩家遇到 O，可以选择交谈、绕行或基础战斗中至少一种经规则支持的解决方式。结果及代价由事件给出，叙事说明后果而非替规则掷骰。
5. 玩家满足 Q 的完成条件后，任务列表给出明确完成状态；重复点击、刷新和叙事重试不再次发放奖励。导出或重新打开存档后，位置、物品、任务和已见剧情一致。

## 2. 失败但可继续

1. 在步骤 3 或 4 提交一个**规则可判失败**的有效行动，例如条件不满足的物品使用或未成功解决 O；具体失败条件由规则版本提供，不在本稿杜撰概率。
2. 玩家得到可理解的失败原因、已结算的状态变化和至少一个下一步（重试、换路线、求助或暂离，由规则提供）。Q 仍显示未完成或当前进度，不能由鼓励性台词宣称已完成。
3. 若失败产生伤势、消耗或关系变化，只认事件投影；再次叙事生成不得另加惩罚。若规则判定行动被拒绝且无事件，状态原样保留。

## 3. 取消与中断

1. 玩家在确认动作前退出、按取消或返回；没有提交的移动、使用、交易或战斗不得产生事件、消耗或奖励。
2. 如果动作已经结算而**只是叙事生成被取消／超时**，保留已提交的唯一事件和状态，再次打开时可重生成文字，不重复执行行动。
3. 刷新或重新打开存档后，UI 明确区分“尚未行动”和“行动已结算、文字待恢复”。G 的知情范围按事件状态更新，不受中断文案影响。

## 4. 无模型／断网

1. 不配置 AI 密钥，在本地或断网状态按正常路径完成 Q。关键行动有确定性文字与按钮反馈；模型失败不能卡住任务。
2. 世界设定仍能按地点查看已发布的相关 Canon；退出阅读层后回到同一剧情位置。待核原图缺口与私有 OCR 不显示为正式条目。
3. 场景海报、动效或声音加载失败时，行动、剧情、物品栏与存档仍可用；声音默认静音，静态回退不改变事件结果。
4. 恢复联网或稍后配置模型，只影响后续允许的叙事表达；不能回填、覆写或重新结算无模型期间已提交的事实。

四态验收需记录玩家输入、状态版本／幂等键、事件、投影、NPC 可知事件集合及玩家看到的文字。作者负责判定“此选择是否像九霄、结果是否讲得清楚”，合作者负责证明事件、重试、存档和回退可复现。具体角色姓名、台词、数值与奖励表仍须在实施任务中明确，但不得以缺这些实现细节为由让 AI 自己写权威状态。
