## 2026-09-25 本轮修复

- AI 调用记录从页内滚动改为独立可滚动原生对话框；不再把玩家带到旧配置迁移区域。
- 旧配置迁移改为状态、授权、读取动作分区；说明 `file://` 与网站来源隔离，旧存档 JSON 不含旧 `sessionStorage` 配置。只在当前来源检测并主动读取，不自动删除旧数据。
- AI 设定延用本地书法标题字体和宋体阅读面；标签改为同一衬线体系，正文保留清晰字重。全路由增加山门艺术图衬底，夜色/晴昼各用不同遮罩。
- 山门内新增“跳过设置”：有存档时直回最近一档，无存档时跳过 AI 配置而进入建角。AI/世界页关闭返回发起它的山门、建角或存档页。
- `/game/:id` 新增居中故事阅读区、从旧 `messages` 中提取安全可读文本、角色/情报/记忆面板、存档/补充资料工具和行动输入。行动仅写入本地 `pending`；暂不推进回合、不调用模型、不改权威状态。
- 游戏资料入口已去重：角色状态、综合情报、星记忆各只保留左侧/移动横向导航中的一个入口；切开面板只呈现内容，不重复写一遍相同栏目标题。E2E 对三个按钮分别断言唯一。
- 游戏区保存路径现在检查本地写入结果；浏览器存储被拒绝或写入失败时显示错误，不再误报已保存。旧待处理意图存在时，正文保留；不把旧对象结构静默覆盖成新草稿。
- IndexedDB v2 将存档修订与数据变更置于同一读写事务；只提交当前标签页实际改动的存档 ID。并发修改同一存档时返回冲突，不覆盖新版本；玩家可载入最新档或把旧分支另存。E2E 实测两边行动均留存。
- 行动意图以队列保存，页面刷新后继续显示；输入草稿按标签页写入 `sessionStorage`。新增恢复演练：删除 localStorage 镜像后重载，IndexedDB 仍能恢复存档并重建兼容镜像。
- 2026-09-25 用户提交的初代世界书已逐字节复制到 `docs/sources/世界书_保守补全版.md`，SHA-256 与源文件一致。其自述仍为“未入库”，且标有缺文、待确认及看不清内容；运行时仅检索 7 条独立登记来源的已审核地理条目。原稿所称 207 张图与旧待办提及的 182 条 OCR 是否为同一批尚无证据，不合并计数。
- 构建 manifest 现在区分 Git commit 与工作树状态，避免在有未提交更改时只显示 HEAD SHA 而让预览制品被误认成该提交的干净构建。
- 本地当前构建标记为 `stage=S2`、`sourceTree=dirty`、`dirtyPathCount=37`。这是可复现的工作树预览，不是该 HEAD 提交的干净制品或 G1 发布候选。
- 运行 Impeccable detector 后，移除列表悬停的 padding 动画并淡化玩家文本侧边强调。检测结果无剩余告警。
- 这是新路由与界面层的移植，不等于旧单 HTML 所有执行语义完成。真实 Canon、玩法裁判、GM 权限和失败恢复仍需独立工程与作者验收。

## 此前界面决策

- 修正 JSON 预览只列固定字段的问题，现在动态列出所有顶层旧档字段。
- 山门页只有“进入世界”；进入后才选择续档、新开、世界设定或 AI 设置，避免首页和游戏区重复承担入口职责。
- “九霄”作为唯一主标题；左上角改为“踏月过山门，天地任君行。”；标题与短句使用自托管的 Ma Shan Zheng 网页子集，随仓库附 OFL 文本。
- 加入夜色和晴昼两套主题，选项保存在当前浏览器，不进入游戏存档。移动端和桌面端都能切换。
- “进入世界”采用冷月银蓝双层描边、柔和外光和低频流光；粉色不再作为界面强调色。减少动态效果开启时，流光和场景动画一并停止。它是 Web CSS 效果，不是华为原生沉浸光感或游戏级实时光照。
- 首页场景由本地桌面/移动 WebP 艺术图和 CSS/SVG 运动层构成。它仍是分层网页场景，不是实时 2.5D/3D、光追、神经渲染或动态水体模拟。

## 尚存的重要缺口

1. **旧功能迁移：** 旧能力矩阵在 [旧功能对照与存档样本](九霄1.0旧功能对照与存档样本.md) 逐项区分已实现、部分实现和待后续阶段。当前游戏区仍没有规则驱动的剧情回合；面板显示的是迁入历史值/角色资料，不是权威动态状态。
2. **世界内容：** 当前世界书初代文件为来源副本，不是已发布 Canon。它的自述清点 207 张图（203 张相关、4 张开发讨论），并含多处断口/待确认；旧计划另记 182 条待校 OCR，两个统计口径尚未对齐。已发布 7 条是有限审核子集。需由 A/B 对来源清单、原图批次和剩余条目逐项对账后再扩充。
3. **AI 实测：** 页面包含五个岗位、五种青鸟候选、供应商/型号目录、多个协议适配器和连接测试。目录动态数据来自 OpenRouter，并非全球完整的厂商直连型号清单。当前未证明所有 API 变体、真实账号权限、各 Model ID、费用和跨域连接都可用；游戏回合也未接入岗位调度。
4. **存档：** 当前验证覆盖同档跨标签冲突、显式分支保存、刷新后草稿/行动队列恢复、IndexedDB 重建缺失镜像及此前的单个真实 JSON 样本。它不覆盖所有损坏档、配额耗尽、浏览器强制关闭时机、重复 ID 及任意旧版导出结构；云端冲突尚无业务 API。
5. **容器：** 本机 Docker/WSL 的服务链先前已启动验证：Compose 数据库、迁移、API readiness 和 Mailpit TCP/网页。当前仍无账号、认证邮件业务和存档 API。Docker MCP Gateway 是否在当前会话动态暴露，需以工具可调用性另行判断，不能从 Compose 成功推断。
6. **架构：** 存储和旧档解析已拆出，但 `main.tsx` 仍聚合多个页面；游戏视图应在后续拆出路由模块与可测试面板，保持状态和导航契约清晰。
7. **真实设备：** LYL 指定留待可玩网站完成后验收。本轮未把模拟视口写成设备通过。
