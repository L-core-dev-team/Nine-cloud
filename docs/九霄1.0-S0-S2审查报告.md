## 本轮修复和界面决策

- 修正 JSON 预览只列固定字段的问题，现在动态列出所有顶层旧档字段。
- 山门页只有“进入世界”；进入后才选择续档、新开、世界设定或 AI 设置，避免首页和游戏区重复承担入口职责。
- “九霄”作为唯一主标题；左上角改为“踏月过山门，天地任君行。”；标题与短句使用自托管的 Ma Shan Zheng 网页子集，随仓库附 OFL 文本。
- 加入夜色和晴昼两套主题，选项保存在当前浏览器，不进入游戏存档。移动端和桌面端都能切换。
- “进入世界”采用冷月银蓝双层描边、柔和外光和低频流光；粉色不再作为界面强调色。减少动态效果开启时，流光和场景动画一并停止。它是 Web CSS 效果，不是华为原生沉浸光感或游戏级实时光照。
- 首页场景由本地桌面/移动 WebP 艺术图和 CSS/SVG 运动层构成。它仍是分层网页场景，不是实时 2.5D/3D、光追、神经渲染或动态水体模拟。

## 尚存的重要缺口

1. **旧功能迁移：** LYL 已要求完整保留旧功能。随机开局、旧状态/情报/记忆面板、pending 行动、TXT 补充资料、旧单 AI 配置等能力不能因为目前未呈现而视为删除。应逐项补到功能对照表并按阶段实现。
2. **世界内容：** Bird 尚未交付 182 条 OCR 原图。当前公开页面不展示待校 OCR，这是正确的保守状态。原图到位后才可审核和发布 Canon。
3. **AI 实测：** 当前五岗位页面支持候选档、Model ID、Base URL、API Key 页面内存、Temperature、TopP、最大 tokens、超时、连接测试许可、日志保留及旧配置迁移。它只实现 OpenAI Chat Completions 兼容请求；真实 Model ID、账号权限、真实费用和服务商连接尚未验证，游戏回合也尚未接入 S3 规则/叙事链。
4. **存档：** 单个真实 JSON 样本迁移无损不覆盖其他导出结构、损坏档、重复 ID、超限、刷新中断或跨标签冲突。不得据此删掉旧档或原浏览器数据。
5. **容器：** 本机 Docker/WSL 已恢复；Compose 数据库、迁移、API readiness 和 Mailpit TCP/网页均实测通过。Mailpit 尚未由 API 使用；账号、认证邮件和存档接口仍未实现。Docker MCP 的 Codex 配置已登记，dry-run 报告本机 secret-store/backend API 不可用，因此当前会话无法实调 MCP 工具。
6. **架构：** 存储和旧档解析已拆出，但 `main.tsx` 仍聚合多个页面；下一步继续按路由/功能拆分，避免重新形成混乱入口。
7. **真实设备：** LYL 指定留待可玩网站完成后验收。本轮未把模拟视口写成设备通过。
