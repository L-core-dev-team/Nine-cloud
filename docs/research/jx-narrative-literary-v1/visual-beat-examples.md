# 《映界》剧情高潮识别样本集 V1

这是供编辑与画师练习的原创示范解读。本共享版仅含木场与擂台两个原创场景的六个节点，不含历史盲测原始回包或答案；这些示范不作盲测题。

**判断方法**　先找一个在前文成立的普通状态，再找改变它的最小动作和该动作已经发生的证据。给一幅图只选一个时刻、一个可成立的视点。情绪转折可以很轻，规则生效也可能毫无奇观；两者分开记。传言、条件、打算只够画说话的人。不可逆性要说清期限：压纹用掉在本夜不可再用，迟疑与改口则仍可撤回。

| 出处及位置 | 铺垫 → 冲突积累 | 生效时间、改变及可逆性 | 定格与画面边界 |
| --- | --- | --- | --- |
| 木一，初次报工 | 师父嫌响，却从不误领工钱 → 有人听一记便翻刨子 | 刃朝墙时，工匠已经着手收工；踏板还没修好。只是日常习惯。 | **不必出图。** 若作伏笔，只框翻过去的刨子。师父没有在场。 |
| 木二，撕下副联 | 渡客等候 → 夏秉问能否过去，得到的保证只关乎板 | 第一张副联被撕时，他已经动手处理退票；撕纸本身没有证明六个人钱已到账。 | **次选。** 用背风的拇指和票的背面写责任。此时不能画河已经通行。 |
| 木二，压纹落板 | 刨花先浮，踏板翘起 → 只一枚可用，娄青得用掉它 | “木头沉回石埂”才证实压纹发效；这枚本夜已用，渡板仍须接榫。 | **主选。** 低视点同时收下沉的板与上爬的刨花。不能画六人踏上板、满天木屋飞起或师父施法。 |
| 木三，梆留在膝上 | 渡板装好，人已绕行 → 夏秉想敲梆叫回乘客 | 娄青坐着等他掐绳头，解释两趟下坡，随后“她没敲”。她放弃这一次招呼；次日仍可敲。 | **余波，可选。** 磨平的梆木、两双闲下来的手。山腰人的神情不在现场视点内。 |
| 镜一，擂台失步 | 陶粒只看脚边 → 元蓁身子不动，袖子落在水镜上 | 镜暗是条件改变；靴尖磕在界外才证实失步。已发生的这次出界不可倒回。 | **主选。** 定格靴尖刚碰界外、镜上仍压着袖缘。不可画负伤、突破或下一场获胜。 |
| 镜一，台下再看 | 方才出界 → 下一对上台，师姐收袖 | 视线落在先亮的半面水上，说明陶粒改变观察对象。只证实她看到了。 | **可选静帧。** 画台下视线与半面水光。若篇幅只容一图，与上一行择一。 |
