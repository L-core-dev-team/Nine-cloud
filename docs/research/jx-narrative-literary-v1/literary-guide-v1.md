# 《九霄》原创修仙文学规范 V1

供作者、编辑与低成本模型研究使用。01 的质量标准解决了“后果是否延续”；本稿多问一句：读者从哪个字、哪件东西、谁的迟疑里，亲自读到了那个后果？以下短段是全文唯一的模型侧指导。其余是编辑手册。

## 给执笔者的短段

> 从眼下最难开口或最难动手的一件事写起。让人物用他懂的办法争取他在意的东西，也让另一个人有自己的算盘。沿用前文的物件、位置和本领；一项术法用在此处，别处就可能顾不上。把笔放慢在选择生效的那一下，下一场让别人碰到它留下的后果。心事可以直说一句，也可以留给动作。未见的结果留到能看见的人那里。把玩家下一步留给玩家。

## 人怎样开口，怎样被读者认识

- **声音来自责任。** 同看一块浮起的踏板，木匠先看旧榫，收渡钱的人先想到谁得走远路。同一句“舍不得”，一个肯刨掉亡师留下的木头，一个愿退钱才算说到了自己的痛处。删掉角色名后，仍能借决定认出说话人。无需给每人分配一句口头禅。
- **对白容得下没答的问题。** 一人问价，另一人问取货日期，读者就知道买卖卡在交期。若归属、时限关系到下一步，则用一句实话说明。每句都绕开问题，会把含蓄写成猜谜。
- **心理有视点。** 贴着当事人，可以写她原本想说的半句话。站在窗外，只能听到停顿或第二声。没有听见的人从何知道，要在场景中给出渠道。旁白偶尔直接点破念头也有效，尤其当人物正做出与念头相反的事。
- **找动作的差别。** 首轮拍灰，赶课时看见灰又沾回来却没再拍，两次相减，窘迫已有了去处。把袖口、指节、停顿轮流堆一遍，动作再细也会变成套话。相关历史对照保留在本地实验档，本共享版不附盲读材料。

## 修仙的物理、账目与人情

写术法之前，编辑先能回答三问：它能碰到什么，谁得付出什么，另一个人因此少了哪条路。正文只交代当场需要知道的部分。练习适合写一次可比较的偏差；交手适合写位置、先后或感知之中一项真变化；交易适合写实际交割和谁承担落空的风险。守住规则并不要求人物都谨慎：他可以赌错，也可以拒绝一笔划算买卖。别替玩家接受卖契、发誓或宽恕。

## 一条长线如何有松有紧

| 所在段落 | 写作者要做的事 | 何时可以停笔 |
| --- | --- | --- |
| 日常与伏笔 | 给物件一个此刻就需要的用途。读者即使猜不到它以后会做什么，这一场仍然值读。 | 谁在等、为什么多等一会儿已经可感。 |
| 积累 | 让不同人的利益挤在同一件事上。上场的损失在这场缩小了选择。经过重复的劳动可跳写。 | 只能顾一头，或有人改变了原先的判断。 |
| 高潮 | 在动作真正生效处给读者一个能看见、听见或摸到的证据。一个小动作也可能足够。 | 名额用掉、名字落纸、话被当事人听见；各写到其实际发生时。 |
| 余波与回收 | 把视点交给受影响的人。让他第一次按新条件做事，或仍按旧习惯伸一次手。 | 读者能感觉到生活哪里变了，无需人物再宣读主题。 |

安静结尾允许问题继续悬着。若上一场已经悬过，下一场至少要让等待有具体份量：少睡一刻、失去一次解释的机会、或第一次等到了原以为不会来的人。高潮之后可以直接切到次日的活计。

## 编辑删改顺序

先修实质矛盾，再找重复解释，最后才磨句子。检查时遮住最后一句：若删去“他终于明白了……”后，人物的选择依然清楚，就让正文停在前一句。若删掉后整场毫无变化，应补的是一次有后果的动作。C、D 保留为旧实验候选；这份手册没有取代 #119 的默认配置，实际模型效果待另验。
