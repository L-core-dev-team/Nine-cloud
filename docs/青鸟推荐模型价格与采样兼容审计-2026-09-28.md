# 青鸟推荐：价格快照与采样参数核验

**核验日期：** 2026-09-28
**适用范围：** 当前五套青鸟方案中已纳入成本估算的型号；不是全球模型全量清单，也不是服务商实时报价。
**实现：** `apps/web/src/ai-model-pricing.ts`、`apps/web/src/ai-model-compatibility.ts`

## 价格快照

下表以每百万输入 / 输出 token 计。人民币和美元分别呈现，不用汇率折算。估算只按输入输出 token 数计算；真实费用还受服务区域、接入产品、模型端点、缓存、推理档位、批处理、工具调用、免费额度和税费影响。

## 型号和请求参数修正

- 方舟当前公开名称为 `doubao-seed-2.1-pro`。此前青鸟方案填入的 `doubao-seed-2-1-pro-260915` 无法在当前官方型号资料中核实。现已统一修改预设、上下文限制、价格表和端到端断言。
- 方舟当前价目表把 CNY 6/30 列为常规在线推理价。先前 UI 将其标成“高优先级”没有官方依据，已删去该错误描述。低优先级档约为常规档一半；模型端点仍可能使用不同费率。
- DeepSeek 的现行直连价目表分别列出 `deepseek-flash`（V4.1 Flash）与 `deepseek-v4-pro`（V4-Pro-0813）。早先把 V4 Pro 视作 Flash 别名并套用 Flash 价格不成立，已拆开估算。
- Claude Opus 5.5、Claude Sonnet 5 对采样参数只接受默认值；传非默认的 `temperature`、`top_p` 或 `top_k` 会返回 HTTP 400。Gemini 3.8 Flash 的迁移文档要求从请求中移除三项参数。界面保留本地草案值以供切换其他型号时使用，但将对应控件禁用并注明请求必须省略。模型调度尚未接入；未来适配器必须复用兼容策略，不能只依赖 UI 限制。

## 边界与后续维护

1. 价格快照仅覆盖青鸟预设和有限目录中列出的型号；不能据此声称已覆盖某厂商全部可用型号或全球全部 API。
2. 推荐模型未使用《九霄》固定测试语料做盲测，因此“省用、合宜、旗舰、文风、多模”是可编辑起始组合，不是客观能力排名或保证结果。
3. 每次版本维护时逐个核实真实 API Model ID、部署区域、请求协议、上下文/输出限制、采样/推理参数、价格档和停用日期。模型不可用或信息冲突时，应显示“待核”并关闭精确估价，不得猜测别名。
4. 发布前再对用户计划选择的区域和 API 端点核价。BYOK 用户的最终计费以其服务商控制台账单为准。

## 自动同步模型目录与价格的可行性

自动更新可以实现，但不能把“实时”理解成一个能够覆盖所有厂商、所有接入区域和所有计费档位的统一官方价格接口。OpenAI、Anthropic、Google Gemini 和 DeepSeek 都公开了模型列表接口；这些接口可用于发现型号或读取部分能力元数据。它们各自的价格仍须按相应官方价目资料核对。OpenRouter 另有一个很有用的聚合目录接口，`GET https://openrouter.ai/api/v1/models` 同时返回它所路由的模型及其价格字段，可用来自动更新“通过 OpenRouter 调用”的子目录；它不代表这些厂商的原生 API 价格，也不能代表用户直连某厂商时的账户资格、地区、端点和账单费率。可行架构是聚合目录辅助覆盖、原厂公开资料作为直连价格依据，而不是把二者混成同一报价。

适合《九霄》的分层方案如下：

1. **目录发现。** 对有官方 Models API 的直连厂商，按厂商适配器读取精确 Model ID、能力字段、上下文与输出限制、创建/发布日期和分页游标。按用户配置的服务商与协议分开呈现；“公开型号”不等于当前账户、地区、项目或端点已经获准调用。
2. **价格采集。** 厂商若提供有版本和更新时间的机器可读价目源，按其更新并记录原始版本。没有结构化源时，仅监测官方价格页，保存页面摘要和内容哈希；解析结果先进入待审快照。不得把 HTML 抓取值直接覆盖已发布费率。
3. **差异审核。** 每次采集保留新旧值、厂商来源、核验时间、区域、接入产品、计价单位、缓存/批处理/优先级档、有效期和解析状态。型号消失、别名变化、币种或价格档不明时，标为“待核”；保留最后一份已核快照，不自动删除、不猜测替代型号。
4. **发布与展示。** 已通过校验的目录字段可以自动发布；涉及价格、型号退役或推荐方案变化时，先生成差异报告，再由维护者核准。界面显示“来源、核验时间、适用区域/档位、快照状态”；超过约定新鲜度时显示过期提示并关闭精确成本估算。成本始终是估值，实际金额以用户服务商账单为准。
5. **用户密钥边界。** 不把玩家 BYOK 密钥发送到《九霄》目录服务。若厂商允许浏览器安全直连且跨域策略可用，可由用户主动发起“检查此密钥可见的型号”，密钥只在本次请求内使用；否则提供手动填写 Model ID 的路径。服务端维护的公开目录与用户账户实际可用目录必须明确区分。

**本项目当前状态：** 当前是随版本人工核对的静态快照，没有定时同步任务、厂商目录代理、价格页面采集器、变更审批队列或价格新鲜度状态。因此不能称为实时同步。首版继续沿用已确认的“人工核价、版本发布、标明核验日期”策略；后续再按厂商逐项接入官方结构化目录，并对非结构化价目实行差异告警和人工发布。只有在定义并验证最大数据延迟、错误回滚和旧价保留行为后，才可对特定厂商承诺同步时效。
