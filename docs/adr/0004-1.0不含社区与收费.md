# ADR 0004：1.0 不含社区与收费

状态：LYL 已决定，2026-10-02。

## 决定与依据

LYL 提交并确认《九霄1.0全缺口验收记录表-2026-10-02.xlsx》。其中 `LYL-05 S6S7边界决定!C10:D10` 明确：1.0 不纳入社区和收费。此 ADR 固定该范围，关闭 G-07 与 BIRD-06 的本版动作。

1.0 不开放帖子、评论、社区投稿、套餐购买、计量收费、商户支付或退款。玩家自持 API Key 向供应商付费，不构成《九霄》向玩家收费。

## 工程边界

本轮检查 `apps/web/src/main.tsx` 及现有账号/设置入口，未发现玩家社区、购买、支付或退款入口。现存内部权益账本只作为基础设施，不证明商业服务已实现，也不允许据此开放收费。

不新增伪支付按钮或收费文案。本版生产条件中移除商户/退款账号待办；身份、云档、内容安全、隐私和部署条件仍须满足。

## 后续变更

如后续决定纳入，另写 ADR，明确运营主体、使用计量、权益、费用预览、支付/退款/对账、社区审核/申诉及专业审查。获准后再规划阶段与测试；不得用本 ADR 推导这些服务已经完成。

本记录关闭产品范围条件，不把整个 S0–S7 改成“完成”。证据和仍开放事项见[唯一缺口清单](../九霄1.0阶段缺口与人工交接清单-2026-09-29.md)。
