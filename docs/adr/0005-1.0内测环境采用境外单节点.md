# ADR 0005：1.0 内测环境采用境外单节点 Docker

状态：**LYL 已决定，2026-10-03。Bird 待签。** 取代 `docs/九霄1.0内测环境方案-境外-2026-10-03.md` 的执行部分，内容并入 `docs/九霄1.0环境方案-主索引与执行手册.md`。

## 决定

1. **1.0 内测期使用境外单节点 Docker 承载后端**，形态为：宿主反代 → `127.0.0.1:8787` → 现成的 `deployment/api-production.compose.yml`（`migrate` + `api`）+ 宿主机自托管 PostgreSQL。**compose 文件一字不改**。
2. **内测期默认不开放在线账号与云同步**（路线 A），玩家存档全部本地 + 手动导出/导入。
3. **内测环境没有任何 fail-closed 绕过开关**，且不接受跨 SHA 走查；每次部署只对应一个 RC SHA。
4. 若确需在线账号（路线 B），拓扑首选 **T1 同源路径反代**（前端零改动），并配真实发件域与生产 SMTP。
5. **测试凭据（路线 C）不得单独采用**：它不解决跨站 Cookie，且不得把测试值部署为生产凭据。
6. **开启邮箱登录必须排在云端回合验收之前**（见下「代码级耦合」）。

## 依据

### 代码级耦合（本 ADR 最硬的一条）

`apps/api/src/index.ts:31`：

```ts
const plugin = emailAuth ? await loadTurnPlugin(process.env.TURN_RULES_MODULE) : undefined;
```

`emailAuth` 来自 `createEmailAuthRuntime()`，而该函数在 `AUTH_ENABLED !== 'true'` 时**直接返回 `undefined`**（`apps/api/src/services/auth-runtime.ts:14`）。

因此：**不开启邮箱登录 ⇒ 规则插件不加载 ⇒ `runtime.rules` 为 `undefined` ⇒ 云端回合永久返回 `503 RULES_NOT_READY`。**

这不是配置偏好，是代码路径事实。推论：账号可以后置开启，但**云端回合验收不能排在账号开启之前**。若走路线 A，验收范围须显式限定为「本地玩法 + UI + 媒体 + 真机」。

### 术语更正

此前文档把「同源（same-origin）」与「同站（same-site）」混用。`apps/web/src/cloud-sync.ts` 使用相对路径 `fetch('/api/…')` 与 `credentials:'include'`，因此**同源路径反代是零前端改动方案**；本项目的卡点是「跨站」而非「跨源」——`jiuxiao.tld` 与 `api.jiuxiao.tld` 同站，`SameSite=Strict` 依然可用。

### 不可变量

- `deployment/api-production.compose.yml`、`docker-compose.yml` 不改。
- `TURN_RULES_MODULE` 只读挂载 + 本地绝对路径要求不放宽；请求体、URL、模型输出、环境变量中的 JS 字符串**永不被求值**。
- `LICENSE_PENDING` / `RULES_NOT_READY` / `CANON_RECEIPTS_PENDING` 三个门禁在内外环境一致生效。
- `ACCOUNT_DELETE_ENABLED` 默认 `false`，未经书面批准不得置 `true`。

## 工程边界

- **本 ADR 不销账任何 G 编号。** 阶段状态仍以 `docs/九霄1.0阶段缺口与人工交接清单-2026-09-29.md` 为准，签收仍以 `docs/FINAL_HUMAN_GATES.md` 为准。
- 本 ADR 不改变玩法、UI 或任何运行代码；只约束部署拓扑与身份形态。
- `AUTH_TRUSTED_PROXY_ADDRESSES` 必须按实际链路配置（逗号分隔、≤8 项、每项为合法 IP），漏配将导致 IP 限流失真。
- 运维脚本（`api-retention` / `api-account-expiry` / `verify-auth-mail` / `api-production-smoke`）均依赖 `apps/api/dist/`，须先 build；计划任务**不发邮件**，不得依赖邮件通知。

## 后续变更

- 迁往境内公测环境需另行启动，触发条件见主索引 §3 与 P8；其中**重新定稿出口公网 IP 并重申请模型服务商白名单**是不可省略的动作。
- 1.0 内不引入任何新登录方式（OAuth / 微信等）；若将来考虑，须先写新 ADR，且不得削弱 `HttpOnly` + `SameSite` 契约。
- 本 ADR 的执行细节以 `docs/九霄1.0环境方案-主索引与执行手册.md` 为唯一维护处；原内测环境方案文件转为只读历史件，不再单独维护。
