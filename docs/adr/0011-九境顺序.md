# ADR 0011：九境顺序

- 状态：Accepted（2026-11-26）
- 决策依据：作者授权“境界顺序 → Claude 核验原始材料后自主决定”。本 ADR 由 Claude 记录，不是作者签名。

## 决定

可玩的九境顺序是：**炼体 → 炼气 → 筑基 → 结丹 → 元婴 → 化神 → 合体 → 大乘 → 渡劫**（化神在合体之前）。

## 依据（已逐一核对）

1. `docs/acceptance/2026-10-02-LYL-decisions.json` 的 `rulesConflict`：签署的规则表（LYL-02 E5）是化神在前，Canon 原稿是合体在前，记录要求“作者明确裁决，不得静默改写签署输入”。
2. `docs/FINAL_HUMAN_GATES.md`：LYL 于 2026-10-03 明确更正为化神在前。
3. `docs/九境五域世界书依据表.md`：“原稿不回写，现行规则以作者更正为准。”
4. `packages/content/src/realm-order.ts` 已按更正实现。

所以这是确认作者在 2026-10-03 已作出的裁决，不是新的取舍。

## 后果

- Canon 1.0 正文与 2026-10-06 的签署回执**不改**。正文中“合体境”的单独提及（如“通往合体境的唯一法门”）不涉及顺序，继续有效。
- 存档里没有境界字段，境界由规则版本与修为推导；`isCharacterProfile` 继续拒绝 `realm` 键。
- 神识表采用最终方案 06 §1 的选项乙：最后两行（化神、合体）交换。
