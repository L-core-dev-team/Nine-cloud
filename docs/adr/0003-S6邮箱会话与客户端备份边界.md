# ADR 0003：S6 邮箱会话与客户端备份边界

状态：工程候选，待项目负责人审查。此记录描述当前实现，不代表生产隐私政策、保留期或商业范围已经获准。

## 技术选择

沿用 Hono/PostgreSQL/Drizzle，不引入另一套应用框架。采用邮箱一次验证码与随机不透明 cookie 会话；账户主体由服务端解析，不信任客户端 owner。认证默认关闭。验证码、会话哈希和账户位于独立新增表，既有游戏存档不迁移为账户身份。

当前候选采用六位验证码、十分钟有效期、五次失败上限；随机会话七天有效，显式刷新旋转并吊销旧值。邮箱验证码 HMAC 与 session token SHA-256 不作为明文凭据暴露。生产请求只走同源 HTTPS，所有写请求核对 Origin；跨账号对象不可读写。

## 游客与云档

游客继续本地操作，登录不会自动上传。用户明确选择备份后进入独立按账户分区的离线队列。退出/账号切换不删除任何本地档，也不把旧账号队列转给新账号。当前提供手动备份，不声称自动双向同步。

云档客户端备份标记为 local-untrusted-v1，上传复制时去除 AI 凭据但不改变原档。它不能成为服务端规则权威状态。恢复另存本地副本；修改现有云档必须 CAS，冲突不自动覆盖。删除只软删除并保存摘要备份，恢复必须校验摘要与当前版本。

## 生命周期边界

登录会建立邮箱账号，会话可刷新和退出；暂未开放邮箱变更、账户关闭、全量账户导出或永久擦除。现有“云档导出/软删除”不是这些账号功能。真实保留时限、备份清除与账户关闭政策需要产品和运营决定，不能由本候选默认七天会话期推导。

## 部署与回退

本地 Mailpit 与 CI 测试只证明隔离投递链；生产须另配 HTTPS Origin、发件域、SMTP、数据库和 AUTH_SECRET。不得把测试值部署为生产凭据。回退为 AUTH_ENABLED=false，保留本地档与数据库数据，不回滚删除迁移或静默清空队列。

最终证据关联 PR #33 的测试 commit、CI 原始结果与构建摘要；不替代 G-06 的真实部署验收。
