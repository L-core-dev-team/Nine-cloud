# ADR 0003：S6 邮箱会话与客户端备份边界

状态：LYL 已于 2026-10-02 提交验收表并确认下述产品基线。依据全缺口表 `LYL-05 S6S7边界决定!C4:D7`；脱敏记录见 [作者验收复核](../九霄1.0作者验收复核-2026-10-02.md)。批准基线不代表生产隐私政策、配额、保留期或永久擦除政策已获准。

## 技术选择

沿用 Hono/PostgreSQL/Drizzle，不引入另一套应用框架。采用邮箱一次验证码与随机不透明 cookie 会话；账户主体由服务端解析，不信任客户端 owner。认证默认关闭。验证码、会话哈希和账户位于独立新增表，既有游戏存档不迁移为账户身份。

当前候选采用六位验证码、十分钟有效期、五次失败上限；随机会话七天有效，显式刷新旋转并吊销旧值。邮箱验证码 HMAC 与 session token SHA-256 不作为明文凭据暴露。当前客户端采用同源请求；生产优先同源 HTTPS，所有写请求核对 Origin，跨账号对象不可读写。

Bird 的 0adda6a 已提供精确 Origin 的凭据 CORS、SameSite=Strict 默认与仅限 HTTPS 的 None 选项。该接口合同不是独立 API 域名的前端接入完成证明：现有客户端仍 same-origin，跨域须显式配置实际 HTTPS API Base URL 与 include，再验会话和浏览器第三方 Cookie 限制。不得自动把获准同源基线改成已批准跨站部署。

## 游客与云档

游客继续本地操作，登录不会自动上传。用户明确选择备份后进入独立按账户分区的离线队列。退出/账号切换不删除任何本地档，也不把旧账号队列转给新账号。当前提供手动备份，不声称自动双向同步。

云档客户端备份标记为 local-untrusted-v1，上传复制时去除 AI 凭据但不改变原档。它不能成为服务端规则权威状态。恢复另存本地副本；修改现有云档必须 CAS，冲突不自动覆盖。删除只软删除并保存摘要备份，恢复必须校验摘要与当前版本。

## 生命周期边界

PR #33 的 629349b7 候选新增邮箱双挑战变更、吊销会话、账户关闭、全量账户导出及受控在线擦除。相关实现位于 `apps/api/src/services/account-lifecycle.ts`、`account-export.ts`、`routes/account.ts` 与数据库迁移 0005–0007；不是本轮从零实现。

关闭需要明确 `ACCOUNT_DATA_POLICY_VERSION`；永久擦除另需 `ACCOUNT_DELETE_ENABLED=true`。默认政策版本未批准、擦除开关关闭，基线批准不自动开启。在线擦除覆盖已接入的账号数据，并保留受控审计证明；冷备、邮件与日志的清除边界、法定例外及保留期限仍须批准和验证。关闭、软删除与永久擦除各自独立；七天会话期不能推导数据保留期限。

## 部署与回退

本地 Mailpit 与 CI 测试只证明隔离投递链；生产须另配 HTTPS Origin、发件域、SMTP、数据库和 AUTH_SECRET。不得把测试值部署为生产凭据。回退为 AUTH_ENABLED=false，保留本地档与数据库数据，不回滚删除迁移或静默清空队列。

0adda6a 已交付 SMTP 连接预检、目标收件人接受判定和脱敏错误分类。预检不发送邮件，Provider 接受不等于收件箱到达；真实投递、生产会话、双账号隔离和恢复演练仍分别验证，沿用[认证后端交接步骤](../九霄S6认证后端交接-2026-10-02.md)。

最终证据关联 PR #33 的测试 commit、CI 原始结果与构建摘要；不替代 G-06 的真实部署验收。
