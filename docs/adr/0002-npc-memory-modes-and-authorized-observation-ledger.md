# ADR 0002：NPC 双记忆模式与授权观察账本

- **状态：** 提案，等待作者 A/B 对同一提交审阅
- **提出日期：** 2026-09-29
- **适用范围：** 新建存档、NPC 认知检索、事件到 NPC 记忆的投影；不改变现有已发布 Canon
- **关联材料：** [P0 双记忆契约与评审记录](../九霄1.0-P0双记忆契约与评审记录.md)、[玩法与双记忆实施方案](../九霄1.0玩法与双记忆模式分阶段实施方案.md)、[双作者分工与交付门禁](../九霄1.0双作者分工与交付门禁.md)

## 问题

项目已具备基础回合、事件回放和 NPC 观察纯函数，但现有存档没有记忆模式或分支身份。NPC 记忆目前主要保存调用方提交的摘要，缺少冻结的授权事实、可审计的知情依据和跨模式隔离。继续增加向量检索或提示词规则，不能补上这些权威边界。

本 ADR 要决定世界事实、NPC 知情、记忆检索、叙述摘要和外部记忆组件之间的写入权、读取权、版本与故障行为。

## 已确认的产品约束

1. NPC 只能永久记住或遗忘自己有权知道的事件。目击和转述须分别授权；全局事件日志不能绕过这一检查。
2. “存档与继续”对授权观察不做衰减。“真实遗忘”对同一类授权观察做可复现的检索衰减。
3. 遗忘不删除权威事件或授权观察。线索可以恢复来源支持的完整或部分事实；1.0 不生成错误归属或错误事实。
4. 衰减使用游戏时刻和该 NPC 收到的授权观察序列，不使用现实离线时长。相同存档分支、授权观察前缀、NPC、游戏时刻、检索线索和策略制品必须给出逐项相同的检索结果。
5. 存档创建时选择一个记忆模式并固定版本。模式迁移必须产生玩家明确选择的新分支。运行中禁止双写两个模式库或跨模式回退。
6. 世界事实只经 ActionIntent → 规则决策 → DomainEvent → 状态投影改变。模型、摘要、记忆检索和插件不能写入权威状态。
7. Mem0 与 UwU Memory 是职责参照和可替换适配候选，不是权威数据源或必需运行依赖。
8. 无模型时仍可用确定性词表、模板和规则行动。BYOK 只改善经授权叙事，不增加行动权限。

## 决定

### 1. 采用一份模式中立的授权观察账本

领域事件先由可见性与披露规则产生冻结的 NpcObservationGrant。授权器必须明确 NPC、授权原因、渠道和允许披露的字段。回合事务把事件、投影、回执和授权 outbox 一并写入同一个权威存储事务。

观察账本和 outbox 不含 continue 或 forgetting 模式。投影器只将 outbox 中冻结的授权事实送至该分支选定的一个模式存储。它不得延迟后按新规则重新授权历史，也不得用来源事件 ID 取回未过滤的原始事件负载。

对于“转述”，NPC 记住的是“某人告知了某项主张”，不是把转述自动提升为已证实的世界事实。目击、报告者归属、来源事件和授权策略都保留为证据。

### 2. 把两种模式建模为独立、版本化的检索策略

- **存档与继续：** 该 NPC 的授权观察不会因游戏时间、观察数量或检索次数而衰减。检索按线索返回来源支持的事实片段；上下文限制不意味着把所有历史塞进每轮提示词。
- **真实遗忘：** 输入与 Continue 同一授权观察集。检索可访问性只按游戏时刻跨度及该 NPC 自身的授权观察序列计算。匹配线索可按冻结算法提高候选可访问性。分数、阈值、线索词典、规范化规则和排序都由策略版本固定。
- **共同限制：** 检索是纯读操作，不因被查询而强化或改变记忆。遗忘返回明确的 abstain 或带 partial=true 的来源事实子集。叙事模型不得填补被省略的事实。

1.0 不宣称算法与人类遗忘在心理学上等价。可承诺的是检索衰减、线索召回边界及同输入可复现性。系数需要在固定的盲测样例上评估后再冻结。

### 3. 在建档和分支边界固定策略身份

新的存档封套应固定 memoryMode、policyVersion、schemaVersion、clockBasis、算法与词典哈希、可见性策略版本及分支谱系。Continue 和 Forgetting 使用独立适配器及独立存储命名域；初始化时核对存储自身的模式和制品哈希，任何不一致都关闭检索。

新建存档建议默认使用 Continue；Forgetting 由玩家明确选择。这保留当前“存档与继续”的预期路径，同时让遗忘成为可理解、可逆分支化的选择；默认值仍需作者 A 审阅。

本地实现可以使用独立 IndexedDB 数据库减少误路由，但这不是对同源恶意脚本的安全沙箱，也不是备份。云端实现必须在 S6 认证和逐存档授权签收后接入；数据库连接身份和约束必须将模式分开。任何数据库或索引都不得同时服务两种在线存档模式。

玩家切换模式时，创建新分支，记录源分支、分叉修订和转换制品；先预览可转换与不可转换项目。源分支只读保留。失败时不修改源分支，也不静默回落到旧模式。

### 4. 将 Mem0、UwU Memory 限制在候选检索适配层

角色档案和批准 Canon 由九霄版本化内容及结构化契约管理。Mem0 可在离线实验或可选 adapter 中提供语义候选，但九霄核心须用稳定来源 ID 重新读取、校验、授权；Mem0 的写入或向量结果不能决定事实。

剧情摘要与历史相关片段是派生物。UwU Memory 可作为摘要/检索质量的候选比较对象，但不能替代原始事件、授权观察、分支游标或回执。关闭任一外部服务后，规则回合、两种核心策略和存档重建仍须成立。

### 5. 1.0 暂不启用离线世界演化

已确认的安全约束是默认关闭，现实时间只能触发受游戏时间上限限制的推进，且离线不得造成 NPC 死亡、物品失窃或任务失败。工程建议进一步把可运行的离线模拟排除在首个 1.0 核心闭环之外，留作 P7 单独评估。这样首轮事实仍只来自玩家在线行动，不引入未验证的后台结算。

“最多七个游戏日”仅是候选值，不是需求或已批准上限。若 A 决定把离线模拟纳入 1.0，必须先由 A/B 确定严格上限、可推进字段白名单、禁止事件集、幂等补算、时间源回拨和崩溃恢复行为。未签署前，字段固定为 disabled，运行时不推进。

### 6. 明确旧档迁移不做静默策略映射

现有 exact-recall-v1 与 accessibility-v1 是检索原语，不是新的 Continue/Forgetting 存档模式。旧档 memoryPolicyVersion 不足以证明记忆记录具备新契约需要的授权来源、分支身份、冻结事实和线索制品。

导入时保留原档备份及旧版本标识。要求玩家显式选择新分支模式。仅当旧记录能逐条证明 NPC、来源事件、可见渠道和已披露字段时，才可转换为新授权观察；其余历史可保留为玩家可见的旧对话/档案，不注入 NPC 记忆。未知版本、未验证授权或转换失败均不得猜测为 Continue 或 Forgetting。

## 被拒绝的方案

| 方案 | 拒绝原因 |
| --- | --- |
| 让 NPC 直接查询全局事件日志 | 会泄漏未目击、未转述或未授权事实，破坏 NPC 知情边界 |
| 将 Continue 定义为“NPC 全知” | 与项目已有逐 NPC 授权逻辑冲突 |
| 让 LLM 直接写记忆或世界状态 | 不可确保规则、事实、重试和回放的一致性 |
| 同一存档同时写两套记忆库 | 两边会因故障或版本差异而分叉，也使模式隔离失效 |
| 把剧情摘要作为事件账本 | 摘要有损且可能合并主张与事实，不能证明事件顺序或来源 |
| 以现实离线天数衰减 NPC 记忆 | 离线时间不是游戏经历，破坏公平和复现性 |
| 直接把旧策略名改成新模式名 | 版本名不能补造缺失的授权证明、事实载体和分支谱系 |

## 代价与后续影响

该方案需要比“写一段摘要”更多的契约字段、授权 outbox、独立投影和迁移工具。它不能保证自由文本叙述没有隐含幻觉；首版应把可验证事实放在结构化回执中，叙事正文只在允许范围内改写，并对来源不足的断言降级为确定性模板。

索引、摘要和嵌入可以重建，但浏览器数据可能被清除或驱逐。因此“授权观察不衰减”描述游戏策略，不等于对设备损坏、用户删除或备份缺失作物理永久保存承诺。

## 审核与复审条件

此 ADR 仍是提案。作者 A 需审阅玩家模式文案、线索分类/残缺回忆样例、序章字段语义和离线模拟范围。作者 B 需审阅契约版本、事务与 outbox、迁移、隔离、失败行为和复现条件。两人须对同一提交给出明确结论；沉默不构成批准。

提交前不得据此声称双记忆已上线、P0 已签收或 1.0 已支持离线演化。若评测显示遗忘策略引入错误归属、未授权召回或不稳定输出，应回退为 abstain，而不是调高模型自由度。
