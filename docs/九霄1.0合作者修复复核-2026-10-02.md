## 4. 本轮发现并修复

### C-13：云档并发快照错误

复现三个失败单测：用户打开冲突后又编辑，旧“保留本地”确认仍获准；旧成功回执晚到，CAS 基线退回旧 revision；旧 409 晚到，将错误冲突写入已经成功的新队列。

修复 cloud-sync.ts：确认绑定 cloudSaveId、baseRevision、pending mutation 和所审冲突；成功回执不得回退已前进的 revision；失败回执仅能更新原请求快照。先失败后通过的三个回归保留在 cloud-sync.test.ts。

### C-14：队列连接和账号页面状态

IndexedDB 打开被阻塞后，调用方已收到失败，随后 onsuccess 仍留下连接。修复为关闭晚到连接并处理 versionchange，补 fake IndexedDB 回归。

CloudSettings 初始会话检查锁定操作，避免与登录竞争；登录/账号恢复从第一页加载；401 清除账号展示后不再加载旧账号队列。队列数据仍保留在原账号分区，不因退出或页面错误删除。

### C-15：数据库故障注入互相干扰

第一轮真实数据库集成出现 15 通过、1 失败：NPC 事务测试的注入触发器作用于全部日志，误伤同时运行的 server-turn 测试。触发器改为只匹配本测试 save_id，保留失败回滚断言。复测 7 个文件、16 个测试全部通过。

### C-16：测试环境两个不稳定因素

Mailpit TCP 可连，但 SMTP greeting 在测试网络延迟，导致验证码流程失败。按官方文档，在本地 Compose 和 CI 测试服务设置 MP_SMTP_DISABLE_RDNS=true；真实 SMTP 浏览器路径随后通过。生产 SMTP TLS 校验不变。

旧档 E2E 连续产生备份下载，出现浏览器自动下载限制。每个拒绝样本前改为重载页面并等待存档水合，再导入及逐字节检查备份。15 类样本在两个视口全部保留，未改为只验证少量样本，也没有用延长超时掩盖失败。另增加云档发送失败时的页面状态诊断，不输出验证码或凭据。

C-13～C-18 目前是审计分支已修复/本地复验，需合入后才能按本清单定义销账。

### C-17/C-18：并行新增提交的第二轮复核

9eac3ac 新增 TurnClient/TurnWorkspace、宿主注入 NarrativeScheduler 和规则版本占位；b55b8ab 新增 release 素材门禁。阅读这两次差异后又复现 4 个失败断言：恢复库晚到连接未关、已确认回执并发退回 unknown、接受和拒绝回执可使用与原请求无关的 revision。修复连接释放、原子 confirmed 检查和回执版本绑定；7 个回合客户端测试通过，四视口恢复/取消/重试通过。

全仓 typecheck 在新增 Vite .mjs 门禁导入处报 TS7016。补媒体门禁类型声明，未用 ignore 或放宽类型检查。验收包生成脚本增加 CI/run ID 和当前 commit 校验，防止本地调用或旧构建被标为 CI 通过；本地拒绝路径已实测，完整包生成由 CI 检查。

新增调度器以合成宿主适配器验证顺序、克隆、预算、有限重试/备用及取消。还未连接真实厂商配置。许可门禁只核结构、摘要和回执登记，权利真实性仍需人审。正式 release 当前因 LICENSE_PENDING 被阻止；审核预览可构建。
