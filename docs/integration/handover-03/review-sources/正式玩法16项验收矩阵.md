# 正式玩法16项验收矩阵

2026-10-15｜验收设计，**16项当前均BLOCKED（正式接线未获批、未实施）**。前次独立PG/页面测试只作组件证据，不视为本表PASS。

## 测试共同约束

授权后使用独立真实PostgreSQL、真实本地认证会话、实际玩家API及已批准非生产规则。合法行为必须经过现有NLU；不得补造拾取/领奖映射。两进程并发须使用独立连接/服务实例，不能只用单进程Promise模拟。模拟模型故障可以注入，但数据库、事务、回执必须真实。

受测最终SHA/dirty状态、完整规则批准聚合值、schema版本、renderer版本、测试命令/退出码、请求与响应、数据库前后快照和失败日志必须绑定同一候选。使用脱敏测试身份；不记录真实令牌或玩家私密原文。

记号：R=turn_requests，E=turn_events，C=narrative_context_snapshots，G=narrative_generation_requests，A=narrative_attempts，S=narrative_sources，P=narrative_publications，O=narrative_outbox。每个计数限定owner/save/request，不能用全库总数。另保存存档revision/state、记忆journal、授权/遗忘投影。归属metadata为待实现协议，当前无表名可假定。

验收前按旧基线冻结合法输入、预期事件及状态差值；测试必须验证具体内容，不只验证HTTP 200或行数。新增metadata的精确查询需随获批schema补齐后才可执行。
