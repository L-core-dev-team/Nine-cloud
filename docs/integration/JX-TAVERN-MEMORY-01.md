# 角色卡关键历史引用

角色卡沿用当前账号、会话的成功请求记录。普通历史能完整进入模型时仍走原路径。发生历史裁剪时，服务端检查已完成回合，从承诺、目标、关系三类各取最新的一项。每条引用随附会话 ID、请求键、修订号、发言来源和完整原文。模型收到的是 user 素材中的 `untrusted_history_quotes`。来源为 character 表示角色曾这样说过，不证明这句话描述的世界事实为真。

## 书写与更正

| 场景 | 合成例子与含义 |
|---|---|
| 单人 | 角色单独回复“我承诺：七夕归还铜铃。”，或玩家提交“目标：找到渡口。”。支持行首的中文明确声明，包括“我答应…”“我们约好…”“我的目标是…”“我们的关系是…”。 |
| 更新同类 | “更正承诺：中秋归还玉笛。”或“承诺改为中秋归还玉笛。”。更正输入当轮就停用旧引用。新内容只在该回合成功提交后才可被后续引用。 |
| 撤回 | “撤销承诺”“完成目标”“解除关系”清空对应类别。“更正：以前的记录暂不采用。”这样的无类别显式更正会暂停三类旧引用，直到重新声明。旧回合保留原文。 |
| 群聊 | 只有玩家明确写出的“共同承诺：…”“共同目标：…”“共同关系：…”可跨窗口引用。更正和撤回也以“共同”开头，例如“共同更正目标：…”。角色自己的发言和未声明共享的玩家行动不进入群聊长期引用。 |

同一类别只保留最新声明，优先同回合的玩家声明。包含问号的输入不作为声明。正文内嵌的暗示、复杂转述、自由文本更正以及多个并行同类约定均未作语义推断。旧历史正常可见时仍展示真实的原始对话。既有群聊历史是公共会话记录；现有表只有发言者，没有私密消息收件人。真正的私聊与个人知情记忆需独立可见性依据，本次没有新增该通道。

## 预算与可复核结果

每条完整来源文本最多 512 个 UTF-8 字节，带来源信息的引用数组最多 1,024 字节。问题点名的类别优先，其余顺序为承诺、目标、关系。先算原基线预算，再用同一预算器容纳引用；只可让出较早的普通回合，保留基线已容纳的世界书与最近两轮（不足两轮时全部保留）。卡片、Persona、当轮行动和可信指令沿用原路径。尺寸过大的新声明不会截断或使旧声明重新生效。

宿主的模型输入可检查 `recallDecisions`（included、in_history、withdrawn、unquotable、budget），此诊断不进入供应商消息，也不另写数据库。最终送达以供应商请求正文为准。重放已知请求键沿用已有结果，不重新生成。无数据库迁移、摘要模型、原生 NPC 账本或新记忆副本。

定向验收入口为现有 `tests/integration/card-real-play.mjs`，使用全新临时 PostgreSQL、真实浏览器登录会话和回环模拟协议。第 1、56 轮及更正均通过实际接口，普通过渡回合用合成数据填充。验收区分 INPUT_PASS、PERSISTENCE_PASS；真实模型理解与创作未测试。
