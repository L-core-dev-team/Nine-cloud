## 3. 特别避免误读的历史确认

1. 用户在此前对话中明确确认 S0、S1 完成。本清单如实保留该确认，不把它改写成“未签”。
2. S0 关闭的是旧功能范围决定；后来发现的行为迁移差异仍要在 S2 的矩阵中逐条解决。该差异不要求用户重新决定“保留全部原功能”。
3. 共同 G1 是旧功能迁移和导航在同一构建上的联合验收；它与用户先前的 S0/S1 阶段确认不是同一个签字。
4. `file://` 旧页面的 `sessionStorage` 不能被新 HTTP 来源直接读取。旧设置需要在原页面导出/用户手动带入；此前一次真实临江仙 JSON 无损样本通过，不代表所有旧档、损坏档都通过。
5. OCR 审核暂停是用户已给出的时序决定。等 Bird 提供材料后再按来源清单处理；当前不要求 LYL 先去检查原图，也不以照片文件名或生成图片代替原始证据。
