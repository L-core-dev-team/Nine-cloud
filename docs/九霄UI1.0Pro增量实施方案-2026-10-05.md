# 九霄 UI 1.0 Pro 增量实施方案

> 状态：实现候选；逐项状态和本轮验收证据见第 6.1、6.2、8 节。
> 基线代码：`codex/ui-beginner-mode-20261005`，`69471c749a1624ba13109352abaf8b76577e6d3d`。
> 方案性质：在现有九霄网站、既有 UI 1.0 方向和已确认核心边界上增量实施，不推翻重做。
> 线上版本：本次审阅时为契约 v1；本分支本地预览为契约 v2。分支代码不等于线上部署。

## 1. 设计读法与目标

九霄是水墨山景背景上的长篇文字冒险游戏。玩家主要阅读、查看状态、决定行动，再理解世界回应。UI 的首要工作是让玩家容易进入、阅读、行动和恢复，而不是增加视觉技巧。

本方案延续既有设计语言：夜山、宣纸色正文、思源宋体族、有限使用的品牌手写字、可降级的动态场景、本地优先存档。设计增量集中在信息层级、移动阅读、AI 首配、状态可理解性、交互可靠性和设计令牌。

“Pro”表示严谨的体验与工程规范，不表示增加专业术语或特效密度。核心体验应当务实、易读、诚实、可恢复。

## 2. 适用范围

- 玩家页面：首页、大厅、建角、游戏阅读、世界设定/图鉴、AI 设置、画面与声音、存档入口。
- AI 设置允许新增新手流程，但专业编辑页的现有布局、字段、操作和能力必须保留。
- UI 整理不得更改游戏存档 schema、权威规则、事件含义、NPC 记忆授权、AI provider/router、价格快照语义或 Canon 内容边界。
- 不新增 UI 框架或组件库。不为本方案引入全站动画依赖。
- 不新增 `localStorage` 键。模式状态沿用既有 AI 配置的 `sessionStorage` 存储。
- 不在源码、注释、日志、示例、测试固件或截图中放入真实 API Key。测试使用虚构占位符，且必须明确不可调用。
- 不把某个模型型号或价格写成唯一正确答案。保留现有模型/价格快照和来源、时间、未知状态。
- 保留场景层 WebGL2 → WebGL → Canvas2D → 静态画面的降级路径。
- 保留“本地优先 · API 密钥不写入存档”的准确承诺。
- 不把模拟视口、浏览器触摸模拟或绿色 CI 表述成 iPhone、鸿蒙实机验收。

## 4. 不可破坏的产品与视觉前提

### 4.1 视觉身份

- 保留水墨夜山、宣纸色正文和思源宋体族。
- 品牌手写字体用于“九霄”题字、世界内的地名/作品名等少数身份内容；不一刀切删除。
- 功能页标题、按钮标签、表单字段和状态说明优先使用可读衬线栈或系统 UI 字体。
- 夜间与昼间主题分别检查。昼间主题已有专门覆盖，不将其误称为简单反相。
- 场景动效只在层级、叙事或操作反馈确实需要时出现。长篇阅读优先稳定。

### 4.2 AI 配置

- 新手入口给出少步骤路径、服务商选择、五岗预填、必需 API Key 说明和准确的下一步。
- 预填不代表启用；高级剧情默认关闭的状态、影响、启用方式和费用边界须明确。
- 新手模式重组现有能力，不删除 provider、岗位、价格快照、日志、参数或故障恢复能力。
- 专业编辑页保持现有字段、视觉和能力。若“完全不变”被定义为连进入方式也不能增加一步，则“进入时选择模式”和“不改变进入交互”逻辑冲突；实施只把专业编辑器本体视为不变，新增模式入口视为用户已要求的外层路径。
- 配置已保存、连接已测试、游戏真实调用是三种不同状态，永不互相冒充。

### 4.3 游戏和事实边界

- 当前行动仅进入待处理队列，规则结算尚未接入。完整回合仍标为 `BLOCKED`。
- 不在 UI PR 中编造游戏规则、状态变化或 NPC 记忆事件。
- 游戏状态只呈现已有可信事实。推断、候选内容和待审核内容须保留来源标签。

### 阶段 2：AI 首配与世界书

- 逐项验收新手模式 3 步路径、供应商预填、Key 安全说明、可跳过高级剧情、精确完成状态。
- 专业页面不改字段、表单次序、价格机制和固定操作栏。
- 世界书分类/搜索/按需展开/顶部返回/恢复阅读位置保持 Canon 来源与审阅边界。

### 阶段 3：设计令牌、对比和状态

- 按 B1–B7 与 B3 表实施，避免一次性大替换。
- 审核按钮四态、空态、错误、连接超时、键盘焦点、触控区和日夜主题。
- 优先 WCAG AA；叙事正文和核心行动在可能情况下争取更高对比度。

### 阶段 4：动效和性能

- 仅实现有明确反馈目的的低强度动效。
- reduced-motion、省流、无 backdrop-filter 和静态场景下，关键任务仍可完成。
- 不引入新的动画库、不做滚动劫持、不假设原生平台材质。

### 必须暂停并报告的情况

- 需要修改专业模式编辑器的字段、布局或操作才能完成新手流程。
- 需要新增 `localStorage` 键、修改存档 schema 或存入真实 API Key。
- 需要猜测游戏规则、伪造连接成功、状态变更、Canon 事实或价格。
- 发现目标分支代码与本文记录不符，或远端分支 HEAD 已被他人推进。
- 需要新场景美术、字体授权、供应商真实凭据或生产部署批准。

### 五页截图判据
