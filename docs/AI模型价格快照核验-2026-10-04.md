## 估算边界

- GPT-6 Astra、GPT-6.1 Sol、GPT-6 Luna 的单次请求输入超过 272K tokens 时，按官方规则对整次请求应用输入 2 倍、输出 1.5 倍价格；代码测试覆盖三个准确 API ID。
- Gemini 3.8 Flash 的此处价格是促销价，仅适用于 2026-12-31 UTC 结束前；从 2027-01-01 UTC 起停止用此快照估算，待重新核验新价。
- 当前价格快照索引日期为 2026-10-05，于 2027-01-03 UTC 到期；各条价格保留各自核验日期。到期、未来系统时钟、未列型号和型号/区域不匹配均显示待核价，不把未知值当零。
- DeepSeek 峰/非峰与缓存命中价不同；阿里云及火山方舟存在区域、接入点、缓存与阶梯差异。这里的估算只适用于表中列出的价格档。
- “12 个预填型号加 `gpt-6-sol` 兼容报价已核价”不表示 25 家厂商目录已完整，也不意味着全球模型全集。当前目录与 OpenRouter 聚合快照均不是全球全集或实时行情；其余模型必须逐源核验后才能显示可估价格。
- 用户实际账单还取决于账号可用权限、实际 API 型号、地区、Token 计量规则、服务条款和当时价格。调用前应以控制台报价为准。
