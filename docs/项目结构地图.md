## 真实构建依赖（已抽查）

- 根 package.json 的 test 显式执行 work/core-regression.cjs，不能整体排除 work。
- pnpm build 先执行 worldbook:runtime:check，再构建非 scene pilot 包和生成清单；scripts/build/write-manifest.mjs 读取 Canon runtime 并复制 drizzle 迁移。
- apps/web/vite.config.ts 调用 scripts/audit/media-release-check.mjs；scripts/build/pages-preview.mjs 读取 docs/audit/public-demo-media-approval.json、apps/web/public/scenes/candidate/asset-manifest.json 与 pages-preview-media/fallback-manifest.json，按许可和哈希复制媒体。
- scripts/build/write-closeout-packets.mjs 读取 docs/FINAL_HUMAN_GATES.md；ADR 与审核证据不可随意改路径或内容。
- API Dockerfile COPY 根工作区配置、packages、apps、scripts，然后构建共享包及 API。
- CI 还验证合成 PG、卡片升级、恢复、媒体、浏览器、审查包和待签 T1 组合。

## 数据与状态边界

玩家输入 → Web/请求契约 → 业务路由/服务 → 已批准规则与权威状态/事件 → 叙事及前端投影。实际分支可能存在本地或云端路径；不能用概念图替代调用链核查。模型文本、作者 Canon、权威结算与发布许可必须区分。
