# 《九霄》九境 × 五域 × 行动：作者侧玩法语义矩阵

这是 Canon 1.0 的**玩法意义与验收输入**，不是世界书原文，也不替代合作者的规则契约。每次行动须先由规则结算并形成事件，叙事只能表达结果。九境与五域按本表组合，而不是为 45 种组合臆造原图没有写出的距离、胜率、耗时、费用或通行门槛。妖域另列，不算“第六人族修真域”。来源事实见[九境五域世界书依据表](九境五域世界书依据表.md)。

## 九境：每境的代表路径与反例

“代表路径”是需要合作者制作并让玩家走通的内容方向；进入、消耗、失败恢复等可执行细节还须落在规则版本中。模型不能因文字提及某种修行就直接把角色升到该境。

| 境界 | 代表路径的意义 | 必须保留的边界／失败样例 | Canon 来源 |
| --- | --- | --- | --- |
| 炼体 | 以呼吸、药浴或体能锤炼表现修行起点。 | 训练叙述不等于自动取得灵力或突破炼气。 | `system_cultivation_realm`；原073 |
| 炼气 | 引气入体、周天循环；初级法术成为可理解的玩法能力。 | 施法条件与消耗由规则决定，不能仅凭模型描述取得未登记法术。 | 同上；原074 |
| 筑基 | 从炼气十层大圆满迈向筑基，理解筑基丹辅助与失败伤及经脉的风险。 | 不能写成必然成功或固定伤害；失败也应保留可继续的状态与后续选择。 | 同上；原075—076 |
| 结丹 | 以液态灵力凝为固态金丹，并面对心魔风险。 | 不把旧转写在裁页上缘补出的过程当作原图；不得跳过结算宣称金丹已成。 | 同上；原077—078 |
| 元婴 | 体现“碎丹成婴”及神魂、肉身关系的变化。 | 肉身受毁后可能遁走是本境原设，不得推广成所有角色无条件复活。 | 同上；原079—080 |
| 合体 | 元婴、神魂与肉身融合，开始触及空间法则。 | 此境在原稿位于化神之前；不能套用其他作品的常见顺序。 | 同上；原081—082 |
| 化神 | 与天地法则共鸣、形成法域。 | 法域表现需要已结算的能力和范围，不能用描写直接改写场景事实。 | 同上；原083—084 |
| 大乘 | 所修大道臻于凡间圆满，为飞升作准备。 | “准备飞升”不等于进入下一境或取得未记载的新寿元、规则。 | 同上；原085 |
| 渡劫 | 面对雷、火、风、心魔等飞升大劫。 | 渡劫结果、死亡与飞升必须有权威事件；剧情不能为戏剧效果跳过失败后果。 | 同上；原086、补025 |

## 五域：每域的代表体验与禁越界事实

表中“代表体验”是可用于设计任务的内容方向，不是新设的固定开局、通行路线或地图坐标。同一玩家在不同境界进入同一地域时，世界事实保持一致，行动是否可行则依规则与当前状态判断。

| 人族修真域 | 代表体验 | 禁止的误写 | Canon 来源 |
| --- | --- | --- | --- |
| 中州天枢域 | 宗门、商会、皇朝与修士社会的交汇；让玩家理解世界秩序和不同修行道路。 | 不能把四海商会的物价、传送网络当成每个城池自动可用。 | `region_zhongzhou_tianshu`；原002、原003、补022 |
| 东瀚龙吟域 | 临海文化与东瀚势力的探索、交谈及资源选择。 | 不凭“临海”就默认玩家有船、海兽坐骑或跨海许可。 | `region_donghan_longyin`；原002、原172、补021 |
| 西荒焚天域 | 在原设的炎热环境和势力文化中安排风险与抉择。 | 不把圣火教等势力的特殊能力推广为全域居民能力。 | `region_xihuang_fentian`；原002、原160、补020 |
| 北境霜寒域 | 雪原、部族与寒属性环境下的生存、信息和行动反馈。 | 不因背景下雪就自动造成固定伤害，也不把所有北境人写成同一部族。 | `region_beijing_shuanghan`；原002、原150 |
| 南疆万蛊域 | 在原设地域与势力背景中体现毒、蛊相关风险及求知。 | 不把某宗门秘术写成所有南疆修士通用；不臆造毒性百分比。 | `region_nanjiang_wangu`；原002、原132—134 |

洪荒妖林作为**独立妖域**另行测试外围、内围与核心区的叙事区分，不能用五域表格暗示其属于人族五域，也不能从描述推导固定进入等级或成功率。依据 `region_honghuang_yaolin`，原002、原103。

## 行动系统：必须由事件给出的事实

| 行动 | 作者侧期望的玩家反馈 | 失败、取消或重试时的边界 |
| --- | --- | --- |
| 移动／探索 | 说明所见与已到达位置，允许玩家辨认当前地域。 | 不可达时解释已知原因；没有移动事件就不能改变地点。 |
| 修炼／突破 | 告知尝试、已结算结果及原设允许的风险。 | 未满足条件、失败或取消时不能用叙事偷升境界；恢复路径由规则与状态给出。 |
| 获得／使用物品 | 物品来源、归属及数量与投影一致，使用后能查看变化。 | 取消、超时和重试不复制物品；未结算不宣称已取得或消耗。 |
| NPC 交谈 | 回答受其在场、关系、传播链和记忆模式限制。 | 对未知事实保持未知，传闻不升格为目击；详见[NPC 认知样例](世界书剧情禁则与NPC认知验收样例.md)。 |
| 战斗／冲突 | 先反馈判定结果，再由叙事表达代价与后续选择。 | 失败不靠模型改写胜负；伤亡、伤势及奖励只从事件取得。 |
| 任务 | 明确目标、完成条件及下一步，能在档案里回看。 | 同一事件或幂等键不得重复完成、重复领奖；放弃与失败分支须可继续。 |
| 交易／经济 | 以现有正式价格资料和交易规则为依据显示报价与实际结算。 | 原图缺失的物价行保持未知；不得把五条作者补充反推成原始价格。 |
| 死亡／特殊恢复 | 说明权威规则已记录的生死和特殊能力后果。 | 元婴或特定功法的例外不可普遍化；叙事重试不得复活已死亡角色。 |

## 组合验收方式

合作者可用每个境界与每个地域的代表路径制作**至少一条可执行任务及一条越界反例**，再对行动表中的结算、失败、重试进行交叉抽样。完整 9×5 组合均应保持境界顺序、五域归属和事件权威不变；不要求每个组合在 1.0 使用完全不同的文学剧情。若某组合没有已定义通行／战斗条件，测试应证明系统明确拒绝或说明未知，而不是模型临场填数字。作者需审查具体路径、台词和结果是否仍有九霄的语气；本表本身不证明长局、双记忆或所有 45 种组合已经实现。
