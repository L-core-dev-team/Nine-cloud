# 《九霄》Canon 1.0 剧情禁则与 NPC 认知验收样例

这是作者侧交给游戏实现方的**叙事边界与验收输入**，不是新增世界书正文，也不是规则引擎实现。以下“甲、乙、玩家”均为测试占位角色，不属于 Canon 人物。单局事件的发生、传播、遗忘和状态后果必须由游戏的权威事件及记忆系统给出，不能由这份文档或模型文字直接决定。

## 全局剧情禁则

| 禁则 | 叙事应怎样处理 | 可核对的依据 |
| --- | --- | --- |
| 不改九境顺序 | 叙述突破与身份时沿用炼体、炼气、筑基、结丹、元婴、化神、合体、大乘、渡劫。此顺序为 LYL 2026-10-03 更正；原073—086 的相反次序和突破前置条件不得继续用于结算。境界变化须等待事件。 | 作者更正；`system_cultivation_realm` 为冲突原稿 |
| 不混淆五域与妖域 | 中州、东瀚、西荒、北境、南疆是五个人族主要修真域；洪荒妖林另列为妖之领域。故事可以涉及妖域，但不能把它称作第六个人族修真域。 | `world_jiuxiao`、六个地域条目；原002 |
| 不把描述性风险写成通用数值规则 | 筑基失败可能伤及经脉等是世界书描述；未经规则版本定义，模型不能写出固定成功率、耗时、伤害或必死结果。 | `system_cultivation_realm`；原075—076 |
| 不普遍化特殊能力 | 原稿写元婴可在肉身毁后遁走，不代表一切境界、一切角色都可无条件复活。特殊功法效果也不能扩大成世界通则。 | `system_cultivation_realm`；原079—080 |
| 不凭空定价或补缺页 | 物价表仅使用已发布的原图行；黄阶上品与玄阶下品已有补图价格，超出原图的报价仍须标为推算，不能冒称原设。 | `system_prices`、`resolvedSourceGaps` 的 `gap_price_table_rows` |
| 不把缺字补成硬设定 | 原先六处缺口已有直接图证；其他仍带省略号的局部残字不得凭常识补成规则。五条旧 `author_addition` 已停用，不再作为玩家权威内容。 | `canon.registry.json` 的 `resolvedSourceGaps`、`author_20260927_019` |
| 不让叙事越过结算 | 模型可以描述已结算的移动、物品取得、伤亡、任务与关系变化；不能仅凭一句剧情文字就新增物品、跨域、升级、复活或改写旧事件。 | 双作者交付门禁 G2 的 ActionIntent／DomainEvent 边界；此项是产品禁则，不声称原图给出了引擎实现 |
| 不让 NPC 全知 | NPC 只表达其现场所见、被可信渠道告知且尚可检索的事；无法获知的玩家秘密和远方事件不得写成其确定记忆。传闻应明确保持传闻语气。 | 双作者交付门禁 G2 的 NPC 认知要求；原图没有提供普适传播速度或所有 NPC 的关系网 |

## NPC 认知样例

样例只规定**给定输入时可以怎样说**。地点、在场名单、事件传播链和记忆策略版本由实现方的测试夹具提供，不把示例占位角色写入正式 Canon。若输入缺少证据，默认“不知道”，不能让模型用世界书常识补出单局经历。

| 编号 | 测试输入 | 允许的叙事 | 应拒绝的叙事 |
| --- | --- | --- | --- |
| N1 直接目击 | 事件 E1 记录玩家在场景 S 取得物品；NPC 甲与玩家同时在场且可观察。 | 甲可以说自己看见玩家取得该物品；物品名称、归属和数量依 E1 投影。 | 在 E1 未结算前先说玩家已经拥有它，或擅改数量、品阶。 |
| N2 不在场 | E1 已发生；NPC 乙不在 S，传播链中也没有收到 E1。 | 乙可说“不清楚”，也可只谈自己已有的 Canon 常识。 | 乙准确复述 E1 的过程、物品或玩家意图。 |
| N3 有传闻 | 乙收到与 E1 有关的传闻 R1，但没有直接目击；R1 的来源与可信度已记录。 | 乙可以说“听说……”，并保留 R1 的不确定性。 | 把 R1 升格为亲眼所见、无条件真相或 Canon 新事实。 |
| N4 记忆差异 | 同一历史事件 E1 保存在权威事件日志；记忆策略 A 可检索，策略 B 当前不可检索。 | A 模式下依可检索记忆回应；B 模式下承认想不起细节。两种模式的事件历史与物品状态一致。 | 为表现“遗忘”删除 E1，或在 B 模式凭模型常识补回被过滤的细节。 |
| N5 世界知识与私人知识 | 甲知道更正后的九境顺序；玩家另有只写在私人状态中的计划 P，甲不在知情链。 | 甲可谈化神先于合体的现行次序，对 P 保持未知。 | 甲因为“懂世界书”就知道 P，或把 P 当作公开世界设定。 |

验收时分别保存：提供给模型的可知事件集合、模型输出、权威事件／状态投影，以及判定理由。N1—N5 中任一条出现未授权获知、事实越权或来源混淆，应作为 G2 阻断样本；修复后用同一输入复测。这里不指定 NPC 全局传播时限、关系分数或遗忘阈值，原图与当前作者交接均没有这些硬数值。

## 尚待作者单独定稿

世界书中的宗门职位与少量人物信息不足以推导完整的**关键人物身份、欲望、动机、关系和“不可说之事”**。本文件没有为他们编造原设人物经历；另有[首段剧情骨架草案](九霄首段剧情骨架与人物边界草案.md)与[四场景内容选择](世界书四场景内容选择与资产缺口.md)供审查。具体人物卡、最终台词、素材及作者产品签字仍待完成。本文件的禁则与认知样例可作为合作者开始实现、测试 G2 边界的输入，但不能代替这些产品签字或真机验收。
