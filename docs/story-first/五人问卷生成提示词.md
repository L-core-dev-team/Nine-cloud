# 五位陌生玩家：问卷生成提示词

将下面代码框的全部内容复制给你使用的问卷生成工具。上线前先填写候选版本和可访问的隔离测试地址。不要把生产 Route A 当作隔离剧情环境。问卷用于收集证据，不用于宣传。

```text
请生成一份中文的《九霄首次游玩观察与体验问卷》，面向5位从未玩过九霄、不懂编程的参与者。使用手机、平板或电脑均可。只记录匿名编号P01—P05，不收集姓名、手机号、账号密码、家庭住址。不要预填答案，不要把未完成自动记为成功，不要以“精美”“沉浸”等词暗示评价。

表单开头：
“这是一个开发中的文字冒险候选，可能失败或中断。我们测试产品，不考你。你可以随时退出；请不要填写私人经历或敏感信息。没有做成的事情与批评同样重要。”

填写前先核对：测试日期、参与者编号、候选版本、测试地址、环境类型（隔离真实剧情/公开本地角色体验/不确定）、设备类型、型号和浏览器、是否首次接触、是否看过项目演示、是否懂编程。后两项若是，则标为熟悉度不符合，保留记录但不能算作五名陌生玩家之一。环境不确定时单独标记，不与隔离真实回合合并统计。

请将表单分为“测试前”“独立试玩后”“恢复后”“观察者专用”四部分。不要在试玩前展示后续的按钮、任务答案或具体行动示例。试玩时只展示一句任务：
“请尝试开始玩九霄，并完成一段剧情。”
给予最多10分钟；前三分钟作为独立观察窗口。观察者不指出按钮位置、不念出可执行命令。参与者可以自发求助，逐次记录；如果无法继续、出现不适或故障，可以停止。超过3分钟未成功不等于禁止继续，须保留真实时间和失败。

独立试玩后问题：
1. 用自己的话说说，这是什么游戏？你刚才想完成什么？（开放题）
2. 你实际完成了哪些步骤？（每行单选：独立完成/求助后完成/尝试但未完成/没有尝试/环境未提供/记不清）行包括：找到开始入口、创建角色、找到文字输入位置、提交一次有效行动、理解行动结果、独立继续下一回合。
3. 你第一句话写了什么？你希望发生什么？实际看到了什么？（三项开放题，提醒不要填写敏感信息）
4. 你认为刚才的行动有没有改变世界？为什么？（有/没有/不确定+原文解释；不要给标准答案）
5. 你现在知道下一步可以做什么吗？请写下你准备做的下一步。（知道/不确定/不知道+开放题）
6. 你觉得建议行动能不能修改？你实际有没有尝试修改？修改后发生了什么？（分题，不暗示正确答案）
7. 遇到不理解或未执行的行动时，页面是否帮助你继续？（没有遇到/帮助了/部分帮助/没有帮助+具体反馈原文）
8. 哪一处最让你困惑？哪一处最想继续？（两个开放题，均可填“没有”）
9. 你是否愿意继续玩？（愿意/不确定/不愿意）为什么？（开放题）
10. 故事是否让你感觉自己的选择产生了后果？（1完全没有—5非常明显，另列无法判断）请举一个实际看到的例子。没有例子可如实填无。
11. 有没有人物提到你之前做过的事？（有/没有/不确定）若有，请写出原话或截图编号。不要把重复台词自动算作记住玩家。
12. 操作是否遇到遮挡、按钮点不到、输入丢失、重复提交、等待无提示、滚动跳动、文字难读？（逐项无/有/未验证+具体情况，设备问题另记）

完成首次试玩后再展示恢复任务：
“请离开当前游戏页面，再尝试找回刚才的故事并继续。”
不指示菜单位置。恢复后记录：独立完成/求助后完成/失败/未尝试；是否找回同一个角色、完整可见故事、物品与进度、未提交文字（每项找到/部分/没有/未验证）；哪段丢失或重复；是否能继续一次有效行动。区分重新载入状态与完整故事恢复。

观察者专用（不交给参与者猜测秒数）：
以首次首页可交互为t0，记录开始入口、文字输入框、首次服务端确认的有效行动、下一有效回合、退出、恢复完成的时间点，精确到秒；每个时点允许“未发生/无法观测”。有效回合必须由测试运行记录确认accepted及状态变化，不能只凭玩家说点击了发送或出现文字。公开本地草稿环境的该项填“环境未提供”。
逐项记录错误点击（时间、点了什么、想做什么）、求助（时间、参与者原话、观察者是否给提示及原话）、停止原因、实际完成的剧情段、键盘遮挡和后台恢复结果。设置可重复添加的事件表，不把错误点击与页面故障混为一类。
记录参与者原话必须逐字记录，解释与观察者推断放在另列；不得生成或润色玩家引语。录屏或截图必须另取得同意，拒绝录制仍可参与；截图先检查无私人通知。

最后输出：适合问卷工具导入的题目、题型、选项、跳题逻辑与必填说明；另附一张观察记录表。对失败原因不要强制归咎于用户。开放题允许“不知道”。不要计算总体满意率替代各项成功率，不要把5人样本推广为全部玩家，不要在无数据时生成结论。
```

## 执行与判定

- 五人分别使用全新测试档案或浏览器配置，避免看见上一个人的故事；测试使用隔离数据库，不要求真实手机号或生产账号。不要清除任何参与者个人浏览数据。
- 试玩前只给通用任务；问卷后半段只在相应阶段展示。主持人不能一边教一边算“独立完成”。
- 保存候选 SHA、设备/浏览器、每人的原始表单、观察时间线与对应测试日志编号。精确时间以观察者计时为准，回忆估时单独注明。
- 隔离玩法核心指标：3分钟内首个有效回合人数/5、独立连续两回合人数/5、独立恢复人数/5；另列求助、错误点击和拒绝继续的原话。公开体验单独判断3分钟能否理解并完成实际开放内容，不将草稿算作回合。
- 问卷发出≠真人通过；未收到原始记录前一律 `HUMAN_REQUIRED`。小样本用于发现问题，不做统计代表性承诺。
