# 《九霄》首段剧情骨架与人物边界（作者侧草案）

本稿是供 1.0 游戏任务设计审查的**新增剧情草案**，不属于原图世界书，也不自动进入 Canon 或现有存档。它确定玩家首段应经历的戏剧与操作顺序，不指定原图没有给出的山门名称、固定人物姓名、境界数值、物价或跨域路程。上线前须由作者审查具体台词、起点和角色卡，再由合作者把行动接到权威事件与状态投影。

## 首段体验目标

玩家在无 AI 密钥、无账号的情况下，也应能完成一次“入世—认路—交谈—行动—承担结果—回看”的闭环。玩家可以自由行动；这条骨架只是首个可复现的任务路径，不宣称所有开局都必须同一剧情。

| 节点 | 玩家看见及可选择的事 | 剧情承担的作用 | 事件与验收边界 |
| --- | --- | --- | --- |
| 1 入世 | 山门画面只说明玩家即将进入九霄；新局确认后显示角色、当前位置与当前目标。 | 从“看风景”转为“我在这里做什么”。 | 建角字段和起点由存档／规则给出；序章文字不替玩家创建境界、灵根或物品。 |
| 2 认路 | 玩家查看附近可到达的地点，任选一次已开放的移动或观察。 | 让五域世界从背景变成可探索空间。 | 只能展示规则判定为已知、可达的路径；不能从世界书地域段落推断瞬移或固定距离。 |
| 3 交谈 | 一名场景内的**引路角色**说明当前能尝试的行动；玩家可追问、拒绝或离开。 | 让第一个 NPC 具有明确目的：帮助新人认清眼前选择，同时保留其个人知识边界。 | “引路角色”只是待定的剧情岗位，不是新增 Canon 人物。其姓名、所属势力、动机、关系与台词要另行审定；未在场的事不得知道。 |
| 4 首次取得与使用 | 玩家通过一次可验证的行动取得一件由规则允许的普通物品，并有机会使用、保留或放弃。 | 让行动带来可检查的结果，而非只有模型称赞。 | 物品 ID、数量、归属与用途由事件结算；未结算前剧情不得宣称到手或消耗。 |
| 5 阻碍与抉择 | 玩家遭遇一个可交谈、绕行或基础战斗解决的低门槛阻碍；失败也要有恢复路径。 | 首次表达“修行有代价，选择有后果”，但不强迫单一路线。 | 阻碍的种类、成功条件、伤害和恢复只由规则定义。不得凭文案直接突破境界、杀死或复活角色。 |
| 6 收束与回看 | 系统明确告知首个任务完成或保留未完成分支；玩家能查状态、事件与存档，再继续自由行动。 | 让玩家理解自己的经历已被世界记住。 | 同一任务不可重复发奖励；返回剧情时事件、物品、位置保持一致。无模型时仍有确定性结尾。 |

这条骨架允许接到中州或其他已定义地域，但具体起点需要与建角、地理和当前任务实现一起签定。若使用洪荒妖林外围作野外场景，应遵守 `region_honghuang_yaolin` 的外围／内围／核心区分；不能为了序章节奏把高危核心区改成新人试炼场。

## 人物边界卡：引路角色

| 字段 | 本稿可给出的边界 | 尚需作者决定 |
| --- | --- | --- |
| 身份 | 首段场景内、能被玩家接触的引路岗位；不预设宗门、种族或修为。 | 姓名、外貌、所属势力、与玩家过往关系。 |
| 当下目的 | 让玩家知道眼前可做的事；如有更深私欲，必须另写人物卡，不能由模型临场编成 Canon。 | 个人欲望、冲突、不可说之事与长期弧线。 |
| 可知信息 | 公开的当前 Canon，以及事件日志允许其目击或获知的单局经历。 | 具体在场范围、传播渠道、记忆策略与可信关系。 |
| 不可知信息 | 未目击且未传播的玩家私密行动、其他存档的事件、未发布原图缺口的“真相”。 | 若剧情需要其提前知晓，必须建立可审查的事件或关系依据。 |
| 禁止行为 | 替系统判定移动、战斗、奖励、突破、死亡；把传闻说成亲见；在遗忘模式中凭模型知识补回过滤的信息。 | 与合作者规则和记忆实现联调。 |

在具体人物未定稿前，UI 可使用明确的功能性称呼，但不能把这张岗位卡包装成“世界书已有关键人物”。正式角色卡至少需补齐身份、当下欲望、与玩家的关系起点、能被检索的所知、隐瞒或误解，以及失败分支中的反应。作者审定后，再为具体人物分配稳定 ID 和来源类型；新写人物应标记为作者原创剧情，不伪称原图。

## 与合作者的验收样例

1. 无密钥建角后，玩家能沿 1—6 完成首个任务；拒绝引路或首次行动失败仍能继续，不能卡死。
2. 同一事件只结算一次。重试叙事、刷新或重复提交不能复制物品、奖励或任务完成记录。
3. 引路角色只复述自己在场或收到传播的事件；换一个不在场 NPC，不应获得同样的单局私密信息。具体反例见[NPC 认知验收样例](世界书剧情禁则与NPC认知验收样例.md)。
4. 玩家查世界设定时能看到相关 Canon，返回后仍在同一剧情位置；AI 叙事或剧情提案不能回写世界书。
5. 序章如出现画面和声音，关闭动效、静音或资源失败时，同一任务仍可完成。

本稿只冻结**需要审查的叙事结构**。它不声称关键人物已定稿，也不代表合作者已实现任务、完成长局测试或取得作者的最终产品签字。
