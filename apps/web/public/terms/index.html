用户协议

本协议是你与《九霄》（以下简称「本游戏」）之间关于使用本游戏所订立的协议。开始使用即表示你接受本协议。

一、服务内容

本游戏是一款修仙世界文字冒险游戏，提供剧情阅读、角色创建、回合制探索与存档功能。

当前版本提供：

  • 本机游玩——存档默认保存在你的设备上，无需账号
  • 云端存档——需登录，用于多设备同步
  • 游客模式——无需邮箱即可体验，但云档在丢失浏览器数据后无法找回

二、你的账号

注册

你可用邮箱验证码注册，也可直接以游客身份进入。

游客账号的限制

游客身份仅由你当前设备持有。清除浏览器数据、使用无痕窗口或更换设备后，云档无法找回。若你可能丢失数据，请先绑定邮箱升级为正式账号。

账号安全

请妥善保管你的邮箱与验证码。我们永远不会向你索要验证码 —— 任何人以索要验证码为名联系你，都不是我们。

三、使用规则

使用本游戏时，你不得：

  • 违反法律法规使用本游戏
  • 通过自动化脚本、外挂或漏洞获取不正当利益
  • 对本游戏进行反向工程、反向编译或反汇编（法律允许的除外）
  • 删除、修改、遮盖本游戏中的版权或权利声明
  • 将本游戏用于商业目的而未获授权

你的内容

你在游戏中创建的存档属于你本人。我们仅在提供同步与导出服务所必需的范围内处理它。

《九霄》的世界观设定（九州地理、门派、境界体系等）属于虚构创作。游戏中的地名、人名、门派名与相关符号均为本游戏设定的一部分，不指向现实中存在的任何组织、机构或个人。

你可以在个人非商业使用范围内游玩并导出自己的存档。未经书面许可，不得复制、修改、传播或用于商业用途。

五、AI 功能

如果你启用 AI 功能，需要自行提供模型服务商的 API 密钥。

你与该模型服务商之间建立独立的服务关系，其内容政策、数据处理与费用由服务商决定。我们不代理、不中转该调用，也不查看你提交的提示内容。

密钥保存在你设备的本机安全存储中，不写入存档、不传输到我们的服务器。

六、中断与终止

你可以随时终止

通过关闭账号即可。关闭后有 30 天恢复窗口，详见隐私权利。

我们可以中止服务

出现下列情形时，我们可中止你的服务并保留相应责任追究权：

  • 违反本协议或法律法规
  • 攻击、干扰或破坏服务稳定性
  • 长期不使用导致账号进入清理队列（90 天无活动）

七、免责与责任限制

本游戏按「现状」提供。在法律允许的最大范围内，我们不对以下情形承担责任：

  • 因不可抗力（自然灾害、战争、电信故障、网络中断）导致的服务中断
  • 你自行清除设备数据导致的存档丢失
  • 你使用第三方模型服务商产生的费用与内容
  • 未使用云同步时多设备间的进度差异

若你使用的是免费服务，我们不承担因服务中断、数据丢失产生的间接损失。

我们可能修改本协议。发生实质性变更（服务内容、数据使用方式、费用）时，会在游戏内或本页面显著提示并更新版本号与生效日期。

你在变更生效后继续使用本游戏，即视为接受新协议。
