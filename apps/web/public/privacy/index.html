一、我们是谁

《九霄》是一款修仙世界文字冒险游戏。本政策说明我们在你使用游戏时收集哪些信息、如何使用，以及你如何行使权利。

我们遵循最小必要原则：只收集提供服务所必需的信息，不收集与你使用游戏无关的内容。

二、我们收集哪些信息

信息类型收集内容用途是否必需
邮箱地址 你主动填写的邮箱地址 用于邮箱验证码登录、账号找回，以及接收邮件事件通知（如投递失败） 登录时必需
游戏存档 角色设定、剧情进度、事件链、记忆策略版本 提供云端存档与多设备同步 否，可只存本机
会话凭据 不透明随机会话标识（服务端仅存哈希） 维持登录状态与退出撤销 登录时必需
邮件事件记录 事件类型、腾讯云消息 ID 的哈希、收件地址的 HMAC 摘要 识别退信、排查验证码未送达问题 否

我们不收集的信息

我们没有申请或收集以下信息：

  • 设备标识（IMEI、OAID、IDFA 等）
  • 精确或粗略地理位置
  • 通讯录、短信内容、通话记录
  • 相册、相机、麦克风、剪贴板
  • 你的行为分析画像与广告标识

我们不集成的第三方 SDK

本应用未集成任何第三方统计、广告或行为追踪 SDK。

模型服务

如果你在设置中使用 AI 功能，需要你自己提供模型服务的 API 密钥。我们不内置、不代理、不转发任何模型服务调用。该密钥保存在你设备的本机安全存储中，不写入游戏存档，不会传输到除你指定模型服务商之外的任何服务器。

三、我们如何使用信息

  • 提供登录与账号功能——验证邮箱归属、维持会话、防止未授权访问
  • 提供云端存档——同步你的游戏进度
  • 排查故障——当验证码未送达时，通过邮件投递记录定位原因
  • 履行法定义务——配合依法提出的合法请求

我们不出售你的个人信息，不用于广告投放，不用于自动化决策。

四、存储方式与期限

数据存储位置保留期限
邮箱、会话、存档自有服务器数据库账号存续期间；删除后按下方规则清理
邮件事件记录自有服务器数据库（仅哈希，无原文）用于排查投递问题，随账号数据清理
本机草稿存档你设备的浏览器存储由你控制，清理浏览器数据即删除

关于手机号

当前版本未启用手机号登录。你主动绑定手机号之前，我们不会收集手机号。

六、你的权利

依据《中华人民共和国个人信息保护法》，你享有以下权利。完整的操作路径见 隐私权利 页。

  • 知情权——本政策即为告知
  • 访问权——查看你的账号信息与存档
  • 更正权——修改你的邮箱地址
  • 删除权——删除账号与关联数据
  • 可携带权（导出）——导出你的存档数据
  • 撤回同意权——停止某项数据处理
  • 投诉举报权——向我们或监管部门反映问题

七、账号的关闭与删除

你可以随时申请关闭账号。关闭后有 30 天恢复窗口，期间登录即可恢复，数据保持不变。

恢复窗口结束后，数据进入受控清理队列。我们不会立即执行不可逆删除，以便在技术故障或误操作时仍可挽回。

永久删除当前可能处于关闭状态。受数据政策与合规要求约束，我们保留这道闸门。它需要在获得合法审批后才能开启。因此「立即永久删除」暂不可用，这是事实而非疏漏。

永久删除在法律上属于不可撤销操作。请在确认前导出你的存档（见隐私权利）。

八、我们如何保护信息

  • 会话凭据使用 HttpOnly; Secure; SameSite=Strict Cookie，不写入浏览器本地存储
  • 验证码摘要使用 HMAC-SHA256，不保存明文
  • API 密钥保存在设备安全存储，不写入存档、不传输到我们的服务器
  • 服务端日志不记录验证码、完整邮箱、完整手机号、Cookie 与密钥
  • 写请求校验来源，不接受客户端自行提交的账号标识作为授权依据
