# 原设恢复与待核对记录

2026-09-19 的世界设定页曾只展示 7 个地理条目，遮蔽了修仙体系、势力、资源、功法、物价、妖兽等原始资料。这是展示范围错误，不代表原图设定被用户授权删改。

现已在空白版与临江仙存档版中恢复原图目录，并开放全部 182 份去重截图文字的查看和全文搜索。原始 OCR 文本直接取自 HTML 内已有的 `MATERIALS.sources`，未压缩成摘要，也未改动 AI 请求、检索与存档结构。目录分组只用于导航，不代表 OCR 文字已审核通过。原始图片路径与 OCR 状态仍保留在 `outputs/设定OCR数据.json` 中。

## 审核边界

- 先前整理了 7 个地理区域的摘要；它们虽曾对照部分图片，仍属整理文字而非逐字原文。现在作为辅助内容放在原始资料之后，不能代替原设全文。
- 尚未逐字核对：182 份 OCR。部分专有名词、数字和表格有明显识别错误，正式设定须以原图为准。当前界面明确标记「OCR 待校对」。
- 目录里「经济体系」的正文在现存可辨截图中尚未确认，页面保留该原标题及缺口提示，没有自行编写经济规则。
- 原图的章节连续顺序尚未全部确认，`世界书原图索引.json` 是工作索引。正式入库前需要逐图核对、拼接跨图段落，尤其是宗门传承、修炼境界和物价表。

## 防止再次删减

构建程序校验 182 个来源 ID 在目录中各出现一次，且必须与原 OCR 集合完全相同。构建两份 HTML 时保留原有 `MATERIALS` 和 `selectSources()` 代码原文；新界面只改变世界设定的展示。
