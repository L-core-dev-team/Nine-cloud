# 世界书交付目录

当前可供审阅的完整正文是[《九霄》世界书 Canon 1.0 正式阅读版](九霄世界书_Canon1.0_正式阅读版.md)，逐条来源和残缺边界见[来源审核表](九霄世界书_Canon1.0_来源审核表.md)。这两份文件从现行 `canon.registry.json`／`canon-runtime.json` 生成；修改原设时先改登记册，再运行 `node scripts/build-canon-runtime.mjs` 与 `node scripts/build-worldbook-reading-edition.mjs`。

本目录原有的 `01_地理与区域_*`、`世界书入库数据.json`、`世界书原图索引.json`、`原设恢复与待核对记录.md` 是早期阶段快照，供追溯旧版页面和首批地理整理，不再代表完整世界书或当前审核状态。尤其旧文件中的“182 份 OCR 待校对”“经济体系无正文”已被后续核验和补图取代；旧 JSON 不应用作 1.0 游戏数据输入。现行内容与状态以 `packages/content/src/canon.registry.json`、`canon-runtime.json` 及 `docs/世界书Canon1.0交付说明.md` 为准。

正式阅读版保留原图裁断处的省略号。六处曾列入待审队列的缺口已有后补图恢复，但其他局部残字并非全部可还原；不要将省略处视为确定设定。作者本人终审签收与游戏真实回合接入仍需分别验收。
