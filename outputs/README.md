# 试玩产物与资料区

`outputs/` 存放当前试玩产物、历史说明、世界书资料与验收索引。它们的用途和审核状态不同；此目录不是统一的 1.0 发布目录。

## 当前试玩版

`九霄WEB-1.0/` 含空白版、临江仙迁移验证版、预览 HTML、测试页面、使用说明和 `source/` 源码镜像。HTML 由 `work/build_v1.py` 生成；世界书 UI 还会经过独立后处理。相似文件名可能属于不同构建阶段，发布前必须比较哈希并运行功能回归。

- [空白版](九霄WEB-1.0/九霄_WEB_1.0_空白版.html)：用于从零开始试玩。
- [临江仙版](九霄WEB-1.0/九霄_WEB_1.0_临江仙存档版.html)：用于旧快照迁移验证，含历史存档内容，按私有资料处理。
- [试玩验收与恢复指南](九霄WEB-1.0/试玩验收与恢复指南.md)：当前试玩操作和已知限制。
- `九霄WEB-1.0/source/`：交付源码副本，不是唯一开发源。

## 世界书与来源证据

- `九霄世界书/`：已整理的世界书数据、原图索引及转换审核记录。文件位于这里不代表所有设定已经通过审核。
- `设定OCR数据.json`、`设定截图OCR汇编.md`：OCR 结果与汇编。182 项需与用户提供的原图逐张核对；未审条目保持私有待核。
- `九霄WEB-1.0/世界书截图/`：原型截图目录。目录存在不等于原始截图齐备，待作者提供原图后核对。
- `九霄运行结构分析.md`、`游玩回合索引.txt`：审计与回合索引，不是玩家运行时数据 API。

## 大型与可再生成材料

`outputs/` 根目录可能有被 Git 忽略的历史 ZIP试玩包，文件体积较大。重新生成前先检查脚本的输入、输出路径和哈希。不要上传未审角色存档、私人截图或密钥。重复测试材料需在证据盘点后判断去留；不要仅凭文件名相似删除。
