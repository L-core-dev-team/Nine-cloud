## §1 首要问题：域名在公网尚不存在（阻塞）

### 实测证据

```
RCODE = 3 (NXDOMAIN)   ← Google DoH
RCODE = 3 (NXDOMAIN)   ← Cloudflare DoH
a.dns.cn → 无该域名记录   ← .cn 注册局权威
b.dns.cn → 无该域名记录
c.dns.cn → 无该域名记录
e.dns.cn → 无该域名记录
```

对照组 `baidu.com.cn` 正常返回 4 条 NS，**排除本地解析器故障**。

### 这意味着什么

Cloudflare 控制台里 `juxiaogame.cn` 显示"待激活 / Pending"，**不是操作错误，是注册局层面还没建立 NS 委派**。

腾讯云截图显示"域名接管已开启，DNS 服务器 = ns1/ns2.dnspod.net"，
但 `ns1.dnspod.net` 直查同样返回 NXDOMAIN —— 说明**腾讯云控制台已写入，
CNNIC 注册局的委派同步还没落地**。这是新注册 `.cn` 域名的正常延迟。

### 你现在不需要做的事

- ❌ 不用反复点 Cloudflare "继续添加"
- ❌ 不用担心 DNSPod 记录丢失（接管后记录仍保留，只是不再生效）
- ❌ 不要把示例 NS（`example.ns.cloudflare.com`）填进任何地方

### 唯一要做的

**等待注册局同步。** `.cn` 通常 10 分钟 ~ 24 小时。等待期用下面的脚本自查：

```bash
bash "D:/九霄 WEB/outputs/cloudflare-onboard/cf-check.sh"
```

返回 `✓ 委派已指向 Cloudflare` 即表示可以进入 §3。

## §2 现在就能做完的事：填 Cloudflare DNS 记录

Cloudflare 已分配好该 zone，只是缺记录。**现在配好，等 NS 一生效立刻可用**，
不用等。

### 入口
Cloudflare 控制台 → `juxiaogame.cn` → **DNS** → Records → Add record

### 关键判据：源站在哪？

你的 `D:/九霄 WEB` 目前状态是 `PUBLIC_API_BASE_URL_PENDING` ——
部署文档明确写了「正式公开 API Base URL 尚无实际资源」。
**所以现在还没有可解析的源站 IP。** 两种情况：

#### 情况 A：还没部署，想先用 Cloudflare 兜底（占位）
添加一条 A 记录先占坑：

| 类型 | 名称 | 内容 | 代理 | TTL |
|---|---|---|---|---|
| A | `@` | `192.0.2.1` | 🟠 已代理 | Auto |

> `192.0.2.1` 是 RFC 5737 文档保留地址，纯占位，**不要当真实源站**。
> 源站就绪后回来改内容即可。

#### 情况 B：已有 VPS / Pages，直接填真实地址
把 `192.0.2.1` 换成实际 IP。同理加 `www`：

| 类型 | 名称 | 内容 | 代理 |
|---|---|---|---|
| CNAME | `www` | `juxiaogame.cn` | 🟠 已代理 |

### 代理（云朵）怎么选

| 记录 | 云朵 | 原因 |
|---|---|---|
| `@` / `www`（网站） | 🟠 橙 | 走 CDN + 隐藏源站 IP |
| 任何 MX / TXT / SSH | ⚫ 灰 | **邮件和 SSH 必须灰**，否则失效 |

## §3 NS 生效后：把腾讯云 NS 改成 Cloudflare 的

⚠️ 这一步**现在做没有意义**（注册局还没委派，改了也传不上去），
等 §1 通过后再做，或者现在就做、等同步时一起生效 —— 后者更省时间，
因为腾讯云改 NS 和 CNNIC 同步是并行等待。

### 取 Cloudflare 分配的两条 NS
Cloudflare 控制台 → `juxiaogame.cn` → **概述** → 右侧「分配的名称服务器」
记下形如 `xxxx.ns.cloudflare.com` 的两条。

> 每个 zone 分配的 NS 不同，**必须以你控制台显示的为准**，
> 网上教程里的示例 NS 一律无效。

### 在腾讯云改
1. 腾讯云控制台 → 域名注册 → `juxiaogame.cn` → 管理
2. **DNS 解析** → 点「修改 DNS 服务器」
3. 选「**使用非腾讯云 DNS**」（不是"使用 DNSPod"）
4. 填入两条 CF 的 NS，保存
5. 弹身份验证就按提示过

> 腾讯云文档原文：「非腾讯云 DNS 服务器域名不能是自建的 DNS 服务器域名，
> 必须是解析商的权威 DNS 服务器域名」—— `*.ns.cloudflare.com` 符合。

### 注意事项

- **DNSSEC**：截图显示未开启，无需处理。若曾开启，改 NS 前先关，改完再开。
- **不要留旧 NS**，只保留 CF 两条。
- **不要把 NS 填成 A 记录**。

## §5 SSL 设置（NS 生效后）

Cloudflare → `juxiaogame.cn` → **SSL/TLS** → Overview：

| 项 | 建议值 | 说明 |
|---|---|---|
| 加密模式 | **完全（Full）** | 不要用"灵活"（可被降级劫持） |
| 边缘证书 | 始终使用 HTTPS | 开启 |
| Minimum TLS | 1.2 | 别用 1.0/1.1 |
| HSTS | 先不急着开 | 确认稳定后再开，避免回退困难 |

如果源站还没有证书，用 **Full (strict)** 之前先在源站装好证书，
否则会 526。
