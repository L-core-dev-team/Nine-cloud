作品简介

《九霄》是一款以东方修仙世界为核心的开放式文字角色扮演游戏。玩家并非沿着固定剧本前进，而是在一个持续运转的九霄大陆中自行选择出身、修行道路、阵营与目标：入宗问道、独行江湖、炼丹炼器、探秘遗迹、争夺天材地宝，或在诸域与各大势力之间留下自己的名字。 世界中的境界、灵根、功法、法宝、资源、宗门、妖兽、经济与地域规则共同作用；人物关系与事件会随着时间推进而变化。AI负责扮演世界引擎、主持人、NPC群体与规则裁定器，玩家则始终拥有自由行动权。
