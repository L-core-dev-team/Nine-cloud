# 1.0 剩余工作与验收标准

截至2026-09-13，当前是功能开发预览，不是正式1.0。框架测试不能替代真实模型的剧情质量和长局一致性验收，不用测试条数换算完成百分比。

## 已有基础

已有手机适配页面、建角、自由行动、建议选项、多存档、导入导出、旧临江仙快照迁移、输入草稿、未结算正文恢复、损坏存档保护、STM/LTM、五岗位配置与调度、辅助失败回退、字段校验、世界事件与伏笔、档案审阅建议和调用日志。

基础测试41项，AI调度测试34项；真实HTTP联调使用本地模拟接口。未调用真实厂商模型。已有390×844界面检查，不等于iPhone Safari真机验收。

## 正式1.0需要补齐的六组工作

| 工作 | 当前缺口 | 完成标准 |
|---|---|---|
| 1. 真实AI接入与剧情调优 | 只有模拟返回，未检验实际型号、网关、跨域、长篇JSON和文风 | 使用作者实际接口跑通单AI、多AI、导演、状态和档案；长篇正文与状态提取稳定；故障可恢复。实际Model ID需作者核对，密钥在游戏设置填写，不提交仓库 |
| 2. 原卡权威资料整理 | 182张去重截图仍主要是待校OCR；模板、旧局与原卡有冲突 | 校订关键世界规则、地域/势力、境界、功法等，保留来源及冲突；模型检索区分已核对事实与待校资料，不擅自统一偃师府/傀师府等差异 |
| 3. 状态规则完整性 | 当前以结构、数值、ID、引用和局部语义检查为主 | 补齐库存/货币收支、境界变化、关系/生命状态、势力等规则与一致性用例；合法临时生成内容归本局，错误字段有可解释处理，不能只靠模型自觉 |
| 4. 时间与年龄 | 仅累计分钟和导入时间标签，未联动历法、生日、闭关年龄 | 从原卡确认历法规则；缺失时明确约定后实现，不自行假设每月天数。验证跨日、跨年、长闭关及旧局时间迁移 |
| 5. 长局记忆实玩 | 六回合归档和25回合档案调度已实现，但未用真实模型跨周期游玩 | 建议至少连续30回合，跨过多次STM归档和一次档案审阅；检查长期承诺、旧人物重逢、秘密、伏笔、资产与时间，覆盖断流/换模型/导入再续玩 |
| 6. 手机交付与发布回归 | 尚未iPhone真机测试，也未确定实际手机访问入口 | Safari键盘、安全区、滚动、切后台、刷新、草稿、导入导出、设置操作通过；确定局域网或部署入口；发布包含清晰版本、说明、恢复方法，无真实Key或默认测试接口 |

上表中真实接口和真机环节需要作者提供实际环境或亲自验证；其余代码、校订、用例和打包可以继续在本地推进。当前不能据此给出可靠的具体完成日期。

## 新增任务书的后续增强

自动记忆压缩、档案建议的人工审阅与可撤销采纳、复杂度评分进一步校准、更多原生API Adapter和流式显示尚未完成。其中原生Adapter/流式是可选扩展；自动压缩属于任务书P2。

我建议首发先保留“不自动删记忆”的可靠路径，把自动压缩作为后续增强；如果要求新增任务书全量交付，则P2仍要完成，不能宣布全部做完。此处是排期建议，不是擅自删除需求。

## 接下来的顺序

先整理关键原卡规则及状态校验用例，同时接入作者实际API；随后跑跨记忆周期长局，按结果修复剧情/状态问题；最后完成真机与发布回归。每批修改仍先保存源码与恢复记录，再做下一批。

## 本轮增量

修复未结算长正文被再次作为玩家输入计入上下文预算的问题。上下文中的行动只发送id/text/gm，正文由状态岗位单独接收，不带入本地错误等元数据。新增两项回归测试，原存档和正文不删除。
