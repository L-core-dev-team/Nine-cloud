# 九霄0号试玩反馈

每个问题单独填写；不要求懂开发，改进建议也欢迎。

- **类型**：无法继续／存档／剧情设定／人物或物品状态／界面操作／建议
- **设备与系统**：手机型号、系统版本、浏览器或安装版
- **试玩版本**：文件名或界面标识
- **AI模式与模型名**：单AI或多AI，相关岗位Model名称；不要填写API Key
- **所在回合与场景**：
- **操作步骤**：依次写出点击或输入的内容
- **预期结果**：
- **实际结果**：
- **出现频率**：每次／偶尔／仅一次；刷新或重试后是否恢复
- **补充材料**：截图、出错前后存档、脱敏调用记录；不要附密钥

设定问题可补充与哪条原设定不符。觉得不好玩时也可以直接说哪里拖沓、难懂或缺少选择，不必提供技术诊断。
