# 多 AI 接入与调度预览

在现有页面、世界资料和存档体系上增量接入，未替换原卡，未带入开发者 API Key。

## 配置

右上角设置支持单 AI / 多 AI。五岗位分别填写 Base URL、API Key、Model、Temperature、最大回复 tokens、超时秒数，独立启停和测试。Base URL 可到 API 版本路径（如 `https://你的服务/v1`），也可填写完整 `/chat/completions` 地址；服务需要允许浏览器跨域请求。主剧情岗位同时是单 AI 模式的模型。

配置仅保存在当前浏览器会话；刷新保留，关闭会话后可能需要重填。密钥不写入游戏存档或分享包。“君煜推荐配置”填入任务书提供的型号与岗位启用状态，保留已有 URL 和密钥，保存后生效。预设不是已核验的可用型号清单，请按服务商实际 Model ID 修改。

当前支持非流式 OpenAI-compatible Chat Completions。Claude、Gemini 原生协议未单独适配，需要兼容接口。不限制厂商或模型名，暂不支持流式显示。

## 回合流程

- 普通：主剧情 → 状态与记忆。
- 重要：剧情导演 → 主剧情 → 状态与记忆。
- 重大：高级剧情 → 主剧情 → 状态与记忆；高级导演失败时尝试普通导演，普通导演失败后由主剧情自行规划。

复杂度是程序启发式评分，参考行动关键词、提及的已知人物数量、关联重要伏笔，不额外调用AI分类。它不是对剧情的完整理解，需要实玩校准。

正文生成后先保存为待处理草稿，再做状态提取与校验。状态岗位失败或返回不可用JSON时，主剧情岗位补做结算。两次都失败则保留“待结算正文”和行动，状态、回合数不推进。修复配置后重试复用正文；未结算正文也支持切换单/多模式后恢复。

部分字段非法时保留原值并记警告，正文和其他合法更新仍能提交。校验覆盖数量、时间、重复ID、关系数值、简单境界跨度及已知死亡状态。摘要或六回合归档缺失时保持未结算，避免破坏记忆周期。

这些检查不能证明全部剧情语义正确。复杂功法、未知地点、人物身份和旧局扩展境界仍依赖原卡校订与模型遵循。模型临时生成内容只属于本局，不能成为Canon。勾选GM允许本局覆盖，不修改原卡。

## 记忆、世界事件与档案

复用STM/LTM，每轮选取相关长期摘要、当前相关人物、近期剧情、世界事件和有限伏笔。近期消息设为0时不带聊天历史。字符容量保护不是精确token估算。

新增可选存档字段 `foreshadowing` 和 `worldEvents`，旧存档兼容。伏笔支持active/resolved/abandoned/hidden，hidden不在公开面板展示；世界事件按ID去重。

档案默认每25个已结算回合审阅，可改周期。只读取有界片段和相关待校资料，超容量或失败则跳过，下个周期再试。建议在综合情报中查看。当前不会自动采纳建议、压缩或删除长期记忆，不允许模型重写权威原卡。

## 日志与用量

设置页显示本次页面打开期间的最近200条调用日志，刷新清空；页面累计用量不受日志裁剪影响。记录岗位、模型、阶段、时间、耗时、成功/失败、回退及提供商返回的usage。未报告显示未知，不当成零，不估算人民币价格。

调度报告随对应事件写入存档，最新报告在综合情报展示。报告usage是该次结算尝试的已报告用量，不等于完整账单：刷新前失败尝试及独立档案调用不一定包含在该报告内。配置密钥不进入请求正文；错误中的已配置密钥及常见Bearer信息脱敏。

## 源码

最新校验补充：伏笔和世界事件的人物引用必须存在于旧存档或本轮合法新增NPC中，主角用保留ID `player`。错误引用仅拒绝对应条目；已有世界事件不能用同ID改写内容和地点。达到回复长度上限的失败调用仍统计服务商返回的usage；负数usage按未知处理。

`source/ai-provider.js`：配置、统一调用器、错误、日志。

`source/ai-router.js`：分岗位提示词、复杂度、回退、状态提案、档案。

`source/ai-settings.js`：设置、预设、连接测试、用量界面。

`source/v1.js`：现有游戏、存档与调度接入。

执行 `python source/build.py` 独立构建。用Python静态服务运行本目录后访问 `tests.html`、`ai-tests.html`。测试使用独立内存对象，不调用真实API、不写玩家存档。不要重复执行开发目录中的一次性update/integrate脚本。
