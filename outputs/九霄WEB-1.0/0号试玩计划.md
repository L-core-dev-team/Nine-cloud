# 0号试玩版：范围与两阶段计划

以用户最新要求为准：下周目标是0号试玩版，交给试玩者提意见，再根据反馈制作正式1.0。不是下周完成“完美1.0”。本文件优先于先前的1.0剩余工作估算。

## 本周：可玩的共同主体

1. 按用户iPhone示意图统一阅读、输入、状态面板和设置页，保留夜景背景与修仙文字阅读风格。
2. 补齐开局、行动、正文/状态结算、断流恢复、存档导入导出等阻塞问题，保持单AI与多AI兼容。
3. 整理直接影响试玩的关键规则；不把全面OCR精校、完整历法或自动记忆压缩作为0号交付的前置条件。
4. 准备真实API联调和试玩问题记录。实际密钥由作者在游戏设置输入。

## 下周：试玩验收与安卓、鸿蒙移植

1. 跑真实模型连续回合，验证记忆归档、资产、人物、接口回退和换模型。
2. 验收iPhone实际操作，以及安卓、鸿蒙目标设备的键盘、返回、前后台切换、存档文件和请求行为。
3. 先确认安卓/鸿蒙设备型号及系统版本，再核对对应工具链、构建签名和真机测试条件，落实各自的安装与分发方式。
4. 安卓与鸿蒙分开记录验收结果；不能因为共同网页能打开就标记原生移植完成。尤其不能假定一份安卓安装包覆盖所有鸿蒙系统。
5. 交付0号试玩包、各平台运行说明、已知问题及反馈模板。

设备型号和系统版本目前待作者补充。可以继续开发共同主体，但在确认前不承诺具体安装包已经可构建、可安装或已通过真机测试。

## 本轮已完成

- 手机主界面从相互独立的固定位置改为按可用空间分行布局，阅读、工具栏和输入框不重叠。
- 短屏按可视高度收起底部导航，保留阅读与输入空间；这属于网页适配，不是真机软键盘验收。
- AI设置内容独立滚动，“保存／调用记录／关闭”按钮保持可见。
- 工具按钮保持至少44px触控高度，设置输入字体16px。
- 390×844、360×640、320×568、360×440布局检查通过；刷新恢复未发送草稿通过。
- 增加安全随机ID兼容路径，适应缺少randomUUID但支持getRandomValues的嵌入式浏览器。

## 版本与保存

外发文件名为“九霄WEB-0号试玩开发包.zip”，界面标记“0号试玩 · 开发中”。目录、HTML文件名和存档schema沿用历史名称以保持兼容，不代表正式1.0已经发布。

不要求一次用尽额度。每个可验证改动后同步源码、页面、文档和ZIP，接近限额时保留收尾余量。没有设置自动定时开发；用户继续任务时从当前续接点恢复。
