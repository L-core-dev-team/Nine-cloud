# 0号试玩：验收与恢复

## 打开与更新

解压整个开发包，打开「九霄WEB-1.0.html」。HTML、仙山夜景.png、manifest.json 保持在同一目录。文件名沿用旧名，当前不是正式1.0。

更新前在旧版导出存档，打开新版后导入。不同浏览器或文件打开方式可能使用不同存储空间；找不到旧局时先回到原来的浏览器，不要清理浏览器数据。

## 不配置接口也能检查

1. 菜单载入临江仙快照，查看角色、库存、综合情报、星记忆和世界资料。
2. 导出这一局，重新导入；菜单中的存档列表应保留两局，逐项对比资料。
3. 新开角色，接口未配置时应保留角色与待处理行动；切回旧局应保持原资料。
4. 在没有待处理行动的局输入文字后刷新，检查输入草稿是否恢复。
5. 打开、关闭设置与各面板，确认按钮能操作。配置仅在当前标签页会话保留，游戏存档不含 API Key。

## 失败恢复

- 提示另一个标签页已更新存档：程序不会覆盖另一页的新进度，并会自动载入浏览器存储中的最新版；刚才的操作需要重新执行。若仍需保留旧标签页中尚未提交的文字，先复制输入框内容。尽量只用一个标签页推进同一局。

- 正文已生成、状态未结算：点「继续 / 重试此回合」，沿用正文完成结算。
- 格式整理失败：展开保留的模型原文；重试会优先复用已保存的整理结果。
- 取消生成：保留已有正文和待处理行动；需要改行动时再选择放弃待处理行动。
- 提示保存失败：先复制输入内容并导出存档；存储写入失败时不继续覆盖原存档。
- 提示存档库损坏：原文保留，可通过菜单导出原始恢复备份，不必清空浏览器。
- 导入被拒绝：原有存档不受影响。保留待导入文件和错误提示，交回排查，不要手动删除记忆字段。

## 已完成的自动检查

当前 82 项回归（核心 28、AI/JSON 54）覆盖真实临江仙旧 HTML 迁移、旧 HTML 非内容块隔离、30回合模拟推进、逐回合保存/读取/导入、5次短期转长期归档和第25回合档案审阅。还覆盖空/畸形 JSON、关键 ID 冲突、多标签页旧写入阻断与最新版载入、取消、重试、关系字段保留、存储异常、JSON兼容和辅助岗位回退。所有 AI 响应均为模拟数据，不能证明真实模型剧情质量。

开发者可在 source 目录运行 `node core-regression.cjs`（Node 20或更新版本，无需额外包），使用实际游戏函数和随包附带的临江仙旧档进行检查；界面仍采用最小 DOM 替身，不代替网页按钮和手机验收。

## 仍待外部条件

真实接口由作者暂缓。UI截图回归因浏览器控制受限尚未完成；手机键盘、安全区、前后台恢复需要实机检查。Android和鸿蒙原生移植需要明确目标系统和构建签名条件，共同网页不等于原生安装包。

全面OCR校订、完整历法年龄、自动记忆压缩仍属于后续1.0增强，不在本次0号核心稳定性修复中冒充已完成。
