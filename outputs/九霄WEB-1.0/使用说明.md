# 九霄 WEB 1.0 · 开发预览

最新说明以同目录「试玩验收与恢复指南.md」为准。下文按时间保留历史记录，旧测试数量、旧库存迁移缺口不代表当前状态。当前为0号试玩开发版，未完成真实接口和真机验收。

这是可以打开和配置接口的开发预览，不是已经完成全部原设校订与真实模型验收的正式发行版。

## 打开

将“九霄WEB-1.0.html”和“仙山夜景.png”保留在同一文件夹，用浏览器打开 HTML。更稳定的方式是在该文件夹运行 `python -m http.server 8765 --bind 127.0.0.1`，再访问本机 http://127.0.0.1:8765/ 。该地址只在本机有效，不是 iPhone 可远程访问的网址。

## 体验

- 通过“新开一局”创建角色，每行一项天赋，最多三项。
- 右上角设置填写服务商提供的完整 Chat Completions 地址、模型名和密钥。接口需要允许浏览器跨域调用，并能按提示返回 JSON。
- 首次没有接口时角色与待处理行动仍会保存，配置后点击“继续 / 重试此回合”。
- 菜单可载入临江仙最后一回合快照。这是原游玩内容，不是新生成剧情。
- 多存档在菜单中切换；新开局不会清除其他存档。存档仅保存在当前浏览器，建议定期导出 JSON。
- API 配置只保留于当前标签页会话，不随游戏存档导出。

## 已验证

恢复开发后重新运行14项逻辑测试，全部通过。另通过实际本地HTTP接口验证开局提交、刷新恢复角色与资产、服务断开保留待处理行动、服务恢复后重试只增加一个回合、短期记忆同步。

本地服务的回复明确标为 DEV ONLY，不代表真实模型能力。正式游戏文件不自动启用测试接口，不内置测试密钥。

## 仍待完善

真实模型连接与长局质量尚未验证；原设OCR尚未全部校订；日期与年龄联动、旧局结构化迁移、完善上下文预算尚待开发；没有上线公开网址。状态校验目前主要保证数据结构、数量与回合提交，不能保证全部自由叙事语义一致。

背景由内置 imagegen 生成，文件为“仙山夜景.png”。生成要求：竖版九比十六、深蓝黑仙山夜景、瀑布、桃花、月色、楼阁，中央低对比留白，无文字、标识、控件或边框。
