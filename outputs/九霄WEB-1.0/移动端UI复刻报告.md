# 《九霄 WEB》移动端 UI 复刻报告

完成时间：2026-09-15

## A. 修改文件

- `work/ui-replica.css`：重写手机主界面、资料面板和 API 配置弹窗的最终覆盖样式。
- `work/v1.css`：整理通用控件、设置页、弹窗与短屏样式，删除互相冲突的历史覆盖规则。
- `work/v1.js`：为资料页一级折叠面板加入单项展开交互；未改游戏状态和存档语义。
- `work/ai-settings.js`：在 API Key 输入框旁加入“显示/隐藏”按钮；未改接口请求和配置结构。
- `work/build_v1.py`、`source/build.py`：构建时仅保留模板结构基础样式，移除模板内多代旧视觉覆盖，避免级联冲突重新出现。
- `mobile-tests.html`：扩展为四种目标手机尺寸、短屏、折叠面板长内容和 API Key 显示切换测试。

## B. 主要视觉差异修复

- 主界面按手机视口重新定标：剧情卡约占屏宽 68%，工具条约占 80%，输入区约占 82%，各区域保持独立间隔。
- 剧情区改为单一固定玻璃卡片，使用深蓝黑半透明底、柔和灰蓝描边、顶部粉色高光、内阴影和适度背景模糊。
- 顶栏重新设置 Logo、标语、模型选择器、菜单和设置按钮的尺寸与间距，控件统一为轻描边玻璃样式。
- 四个功能按钮统一高度、圆角、描边和图文对齐，最后一个省略号按钮保持较窄。
- 输入区改为独立圆角玻璃容器，发送按钮使用柔和浅色渐变及克制的粉色光晕。
- 底栏固定在视口底部，四项等宽，加入淡分隔线及 `env(safe-area-inset-bottom)` 安全区。
- 背景叠加暗色遮罩、上下渐变和局部雾化，保留仙侠场景辨识度。
- 资料页和 API 配置页改为手机底部面板；内容区独立滚动，固定操作区始终可见。

## C. 组件关键值

- 正文字体：`Songti SC / STSong / SimSun`，13.2px，字重 400，行高 1.9，字距 0.025em。
- UI 字体：`-apple-system / BlinkMacSystemFont / SF Pro Display / PingFang SC / Hiragino Sans GB / Microsoft YaHei / sans-serif`。
- 主剧情卡：宽度 68%，最大宽度 294px；圆角和玻璃参数由统一 CSS 变量控制。
- 工具条：宽度 80%，高度 36px。
- 输入主体：宽度 82%，输入容器高度 52px；连同提示行总占位约 77px。
- 底栏：46px 加 iPhone 底部安全区。

## D. 折叠面板问题与根因

旧模板同时包含多代样式，其中 `.mini` 被限制为固定最大高度并允许内容溢出。长篇角色状态实际高度超过 1200px，却只为后续栏目保留约 440px，导致“综合情报”“星记忆”等标题压在正文上。

构建流程现会剔除这些历史覆盖。资料页内容改为正常文档流：一级栏目一次仅展开一个，内部信息块可继续独立展开；长文本自然撑开父容器，整张面板统一滚动，不再使用负边距、绝对定位或固定正文高度。

## E. API 配置页

- 手机端使用接近全屏的底部面板布局。
- 标题区固定在顶部，配置内容在中间区域滚动，保存/关闭操作区固定在底部可见区域。
- API Key 默认以密码形式显示，右侧按钮可切换显示和隐藏，并同步更新按钮文字及无障碍标签。
- 没有修改 AI 请求地址、模型选择、路由、JSON 解析、配置存储或回合逻辑。

## H. 仍存在的差异

- “九霄”使用系统楷体/书法字体回退，字形无法与参考图中的定制 Logo 素材完全一致；印章也是网页文字效果。
- iPhone 状态栏、QQ 浏览器白色文件栏和 Safari 浏览器栏属于系统或浏览器界面，网页无法控制。
- 内置测试浏览器不能模拟真实 iPhone 的状态栏与 Home Indicator；页面已使用安全区变量，最终偏移仍需真机复核。
- 背景图裁切会随设备长宽比和浏览器工具栏高度略有变化。
