# P6 → P3 数据契约需求清单

日期：2026-10-13。状态：待临江仙统一审计的接口提案；不构成正式API、数据库迁移或生产修改授权。代码草案见../contracts.ts；固定正式源及候选SHA见接入准备报告。

## 已有权威与需要新增的绑定

正式TurnReceipt已有idempotencyKey/saveId/requestFingerprint/branchId/rulesVersion/clockMinute/decision/events/resultingRevision。P3候选提供只读receipt recovery；unknown不是行动未执行证据，必须保留原key继续查询，不能换key重做。

正式outbox已有grantId、save/branch/NPC、eventId/eventRevision、observedAtMinute、channel、memoryClass、authorizationPolicyVersion、精确authorizedFields/Facts、summary及supersession。尚无任意生成原文sourceId/SHA/UTF-16段偏移与grant字段的现成映射。P3内部attemptId及生成状态已有，但received返回只含text/source，尚未提供完整publication元数据。

## Port契约

verifySaveSession只由可信服务端实现；本原型只允许root，不能自行推演未批准branch lineage。

readConfirmedReceipt(scope,key)返回confirmed+完整正式receipt，或unknown。完整回执必须通过正式schema，saveId/branchId/idempotencyKey与可信scope、key相同；accepted决定行动已结算。正文attachment存回执canonical JSON的SHA256，读取时重新核对可信回执摘要，不用缓存代替。

readBoundary(scope,audience)返回ServerReadBoundary或undefined。policy含memoryMode/memoryPolicyVersion/正式SaveMemoryPolicy；memoryPolicyHash对应正式policyArtifactHash，policySurface明确。asOfRevision不得高于服务端边界，gameMinute不得来自客户端。

readAuthorizedSegments(boundary,query)返回complete、AuthorizedSegment[]及AuthorizedRecallObservation[]，或undefined。complete=false保留BLOCKED而不是无记忆。原型一次最多10000个片段/观察，超限BLOCKED；真实分页＋完整快照方案仍待设计，不能静默截断以伪造完整性。

每段至少sourceId/sourceSha256/segmentId/startUtf16/endUtf16/grantId/grantField/grantEventId/observedAtRevision和三个epoch/hash。偏移以JavaScript UTF-16 code units计，正文SHA以完整原文UTF-8 bytes计；不能切开代理对。绑定须证明该片段等于真实grant的authorizedFacts[grantField]，字段在authorizedFields内，NPC、事件、知情revision和快照一致。后来reported只能在实际知情后读，不回写成早期知情。

同一个原文可以拥有多个授予时点和片段。段映射发布策略及数据结构由权威方设计；本提案不单方面增加P3表或改变outbox。玩家可见片段也必须由可信port提供，不默认读取所有正文。

## 统一证据与防幻觉返回

SourceLink提案串联scope、sourceId、回执摘要、eventIds/resultingRevision、attempt、生成版本/来源、正文SHA。实际Evidence返回包含source/segment、revision/asOfRevision、精确UTF-16偏移与原句、正文SHA、回执key/摘要、attempt/version/source、authority与authorization。scope由已验证请求及SourceLink定位；Evidence本身不重复全部scope字段，客户端不能脱离该上下文复用。

authority.narrative为original-prose-only或unverified-claim；confirmedRuleFacts只含经RULES回执确认且NPC获准的字段，unknownFields显式说明缺口。原文命中不等同所有叙事内容的事实真值。完整证据不足返回insufficient/unknown/conflict/forgotten/blocked之一，generatedAnswer=null；预算不足拒绝整段，不删除不得转卖等限制条件。

状态接口分别提供actionSettled、narrativeState、bodyPersisted、npcMayRead和descriptionRuleConfirmed。发布返回npcMayRead=unknown、descriptionRuleConfirmed=false；它不能把持久化成功升级为NPC授权或规则成立。当前原型为只读证据，没有正式剧情记忆写回或NPC模型提示词接入。

## 两个需要先裁定的设计点

1. P4/P5：保留显式回忆与叙事各自语义，还是批准跨面统一。前者要求携带surface和不同计数证据，后者需要新的策略身份与全套遗忘回归；不得直接改旧hash。
2. 原文授权发布：规则先授权事实，怎样合法发布某段生成原文的授权。必须审计信息量、否定条件、转述来源与时序；不能只因字符串相等或NPC参与就扩大知情范围。

## 真实接入验收清单

真实账户间sourceId猜测与scope伪造；跨存档／分支；正文公开与私密片段；在场未听见；后来转述与历史查询；当前撤权及缓存竞态；同revision多观察与遗忘阈值；同回执多attempt/version；正文、receipt或偏移损坏；未确认回执与叙事timeout/cancelled；原文修辞／谎言与RULES字段隔离；预算不足；数据库提交后ACK丢失和授权事务竞态；分页缺页与超限拒绝。离线结果不得代替真实验收。
