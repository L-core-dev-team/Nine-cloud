# 九霄 WEB

《九霄 WEB》修仙 AI 文字游戏的当前开发工作区。游戏以可在手机浏览器打开的单 HTML 文件为交付形式。

## 打开游戏

- [空白版](outputs/九霄WEB-1.0/九霄_WEB_1.0_空白版.html)
- [临江仙存档版](outputs/九霄WEB-1.0/九霄_WEB_1.0_临江仙存档版.html)

下载本仓库后打开对应 HTML 文件。详细操作和当前限制见 [试玩验收与恢复指南](outputs/九霄WEB-1.0/试玩验收与恢复指南.md)。API 密钥需由玩家在本机配置，仓库不提供密钥。

## 文件结构

- `outputs/九霄WEB-1.0/`：当前游戏页面、资源、说明及交付源码。
- `outputs/九霄世界书/`：世界书入库数据、原图索引和审核记录。
- `work/`：开发脚本、页面模块、测试和世界书构建基底。
- `outputs/` 根目录：运行结构分析、OCR 数据和游玩回合索引。

根目录中的历史 ZIP 交付包未纳入 Git；其解包后的项目文件仍保留在仓库中。本仓库包含临江仙存档内容和世界书原始转写资料，请保持私有，除非完成内容审核后决定公开。

当前仍是试玩开发版；真实模型长局效果及原设 OCR 校订尚未完成。不要将现有世界书整理结果视作已全部人工核准的最终原设。
