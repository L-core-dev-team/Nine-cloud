# 九霄 WEB

《九霄 WEB》是修仙 AI 文字 RPG 的私有开发仓库。仓库保留可运行的单 HTML 试玩原型，并逐阶段建设 1.0 工作区。

> **当前状态：** 现有 HTML 是 0 号试玩开发版。`apps/web` 是 S2 局部工程切片，已具备独立首页、建角、世界占位页、本地继续和旧档导入边界；玩法规则、IndexedDB 迁移、完整 AI 设置、账号、云档、社区、动态场景和商业化尚未迁入。

## 仓库结构

| 路径 | 内容 | 维护规则 |
| --- | --- | --- |
| `docs/` | 现状记录、设计记录、长期路线与 1.0 执行文件 | 先看 [文档索引](docs/README.md)，区分原型记录与新目标 |
| `work/` | 当前单 HTML 原型源码、构建工具、测试、资源、OCR 辅助材料 | 见 [工作区说明](work/README.md)；脚本可能会改文件 |
| `outputs/` | 原型 HTML、测试页面、历史记录、世界书与交付材料 | 见 [产物区说明](outputs/README.md)；不要手改生成 HTML |
| `.github/` | GitHub 维护配置 | 发布和分支规则以 GitHub 实际设置为准 |
| `apps/` | 1.0 Web 工程切片与 Hono API | 当前为 S2 局部能力；玩法和在线服务仍未完成 |
| `packages/` | 共享契约、未启用规则、数据库 schema | 只有已签玩法规则才能增加结算能力 |
| `scripts/`、`tests/` | 基线审计、构建清单与合成样本 | 不放私档、密钥和未审原图 |
| `PRODUCT.md`、`DESIGN.md`、`SECURITY.md` | 产品与设计约束、安全边界 | 以新版总方案和阶段证据判断完成状态 |

现有原型构建大量使用固定相对路径。1.0 迁移完成之前，不要为视觉整齐擅自移动它们。新分层应用按 [AI 执行清单](docs/九霄1.0分阶段实施与AI执行清单.md)逐阶段建立。

## 本地与私有材料

本地工具和视觉审查目录保持原位，不进入发行包。世界书原图、临江仙存档、OCR 转写和调用记录按私有资料处理；OCR 未经作者逐图审定不得作为玩家可见 Canon。不要把真实密钥写入仓库。

## 原型构建说明

当前原型开发源码位于 `work/`。`python work/build_v1.py` 构建基础试玩产物；`python work/build_worldbook_ui.py` 会另行处理世界书 UI。目前两条脚本路径尚未统一为新的 1.0 构建流水线。构建、验包和存档恢复脚本可能覆盖输出，执行前先核对目标路径和 Git 状态。

## 1.0 工程预览

需要 Node 24 与 pnpm 11.19。全新克隆运行 `pnpm install --frozen-lockfile`、`pnpm build`、`pnpm typecheck`、`pnpm test`、`pnpm test:integration`、`pnpm test:e2e`。本地用 `pnpm dev:web` 打开 `http://127.0.0.1:5173`，另开终端用 `pnpm dev:api` 启动 `http://127.0.0.1:8787/health`。开发数据库和测试邮件服务见 [S1 工程基线](docs/九霄1.0-S1工程基线.md)。新构建不会覆盖 `outputs/` 里的旧试玩产物。
