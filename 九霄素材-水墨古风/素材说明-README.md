## 一、项目与风格定位（依据 `README.md`、`PRODUCT.md`、`DESIGN.md`）

《九霄 WEB》是一款修仙 AI 文字 RPG。视觉北极星为 **“月下入界山门”**：夜山是持续存在的世界画布，**月、雾、山、水、梅、朱印** 构成视觉语法。

本素材包统一采用 **中国水墨画 · 写意夜墨 · 古风** 风格，并与项目既有色彩令牌对齐：

| 角色 | 色值 | 用法 |
| --- | --- | --- |
| 深夜渊 `night-abyss` | `#030a11` | 画面基底、深底 |
| 夜山烟青 `night-soft` | `#071421` | 稳定深色面 |
| 月纸白 `moon-paper` | `#f1ece5` | 题字、高光、正文 |
| 桃月微光 `peach-light` | `#efa8cb` | 极少焦点/花瓣光感 |
| 朱印红 `seal-red` | `#a73846` | 仅作印记 |

共性笔法：水墨浓淡干湿、留白、远山如黛、云雾以淡墨晕染，带生宣纸洇散肌理与飞白笔痕；强调色（桃粉、朱红）因稀少而有效，不承担大面积底色。
