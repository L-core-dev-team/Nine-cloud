# 九霄水墨风格候选素材

这组文件包含四处场景的桌面与手机构图，以及书法题字、印章、梅枝、横卷和背景纹理。它们目前是**候选视觉素材**，尚未接入 Web 构建，也未被计入 S5 完成验收。

## 文件核验

- 场景图：4 个地点，每个地点各有桌面版 `2730×1536` 和手机版 `1536×2730`。
- 品牌与装饰图：书法题字 `3547×1182`；横卷 `3128×1340`；印章、梅枝各 `2048×2048`。
- 氛围与纹理：云雾、浅色宣纸、深色夜墨各 `2730×1536`。
- 文件内容是 JPEG；原来的 `.png` 扩展名与编码不符，现已改为 `.jpg`。改名时逐一验证 SHA-256，图像字节未改变。
- 文件带有 AIGC APP11 元数据。清单只记载元数据字段名和文件哈希，不复制元数据值。

## 发布状态

素材来源、生成/编辑链、许可范围和 LYL/Bird 的逐张确认尚未登记。请在确认来源与商用/分发权限后，再决定哪些素材可以接入发布包。`manifest.json` 记录每张图的尺寸、哈希和待审核状态；变更素材后运行：

```powershell
pnpm assets:manifest:check
```

此目录留存候选原件，不是运行时媒体目录。场景分层、动画、环境声、移动端裁切质量和弱设备降级仍需分别验收。
